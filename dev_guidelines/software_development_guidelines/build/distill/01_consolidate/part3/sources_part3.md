# Source register, part 3: sources of the principles sent by the JavaScript guideline

New sources REG-1501 to REG-1579, one row per source of the JavaScript guideline's source register that the part 3 rows cite and that part 1's register (`../sources.md`) does not hold. `replaces` names the JavaScript register id as `JS-SRC-nnn`. Tier and verdict are as audited in the JavaScript guideline (`../../../../../javascript_guidelines/build/audit/source_register.md`); they were not re-audited here and the urls were not re-read. `authoritative on` carries the JavaScript register's restriction for the source: an `admit-restricted` source may ground only what that text states. Author or body is not recorded as a separate field in the JavaScript register; see the title.

Four sources are cited outside a claim table: JS-SRC-082 (grounds ASYNC-C05 and RUNTIME-C37 of JS:CONTROL.LIFECYCLE) and JS-SRC-083, JS-SRC-088, JS-SRC-195 (named by the origin on JS:RUNTIME.MEASURE); they come from the JavaScript source register directly.

- New sources: 79. Reused from part 1: 7 (second table).
- Ids: REG-1501 to REG-1579.
