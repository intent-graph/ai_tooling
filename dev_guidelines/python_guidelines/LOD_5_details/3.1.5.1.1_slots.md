> Memory optimization for classes.

## Basic Usage
<!-- Lines 17-30 -->

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y

# No __dict__, lower memory
p = Point(1.0, 2.0)
p.z = 3.0  # AttributeError: no __dict__
```

## With Dataclass
<!-- Lines 33-42 -->

```python
from dataclasses import dataclass

@dataclass(slots=True)
class Point:
    x: float
    y: float
```

## When to Use
<!-- Lines 45-49 -->

- Many instances (thousands+)
- Memory-constrained environments
- Performance-critical hot paths
