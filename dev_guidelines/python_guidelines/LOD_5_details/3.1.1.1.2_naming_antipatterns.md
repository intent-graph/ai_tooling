> Names to avoid.

## Generic Names
<!-- Lines 16-29 -->

```python
# BAD
data = fetch()
result = process(data)
temp = transform(result)
info = get_info()

# GOOD
user_records = fetch_users()
validated_users = validate(user_records)
formatted_output = format_for_export(validated_users)
```

## Misleading Names
<!-- Lines 32-42 -->

```python
# BAD: Name doesn't match behavior
def get_user():  # Actually creates user
    return User.create()

# GOOD
def create_user():
    return User.create()
```

## Shadowing
<!-- Lines 45-57 -->

```python
# BAD: Shadows builtin
list = [1, 2, 3]
id = 42
type = "admin"

# GOOD
items = [1, 2, 3]
user_id = 42
user_type = "admin"
```
