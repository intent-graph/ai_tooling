> Standard library context manager helpers.

## @contextmanager
<!-- Lines 17-30 -->

```python
from contextlib import contextmanager

@contextmanager
def timer():
    start = time.time()
    yield
    print(f"Elapsed: {time.time() - start:.2f}s")

with timer():
    do_work()
```

## suppress
