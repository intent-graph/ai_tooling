> Protecting database queries from injection.

## The Vulnerability
<!-- Lines 18-26 -->

```python
# VULNERABLE
user_id = request.args.get('id')
query = f"SELECT * FROM users WHERE id = {user_id}"
# Input: "1 OR 1=1" → Returns all users
# Input: "1; DROP TABLE users" → Deletes table
```

## Parameterized Queries
<!-- Lines 29-43 -->

```python
# Safe: DB-API style
cursor.execute(
    "SELECT * FROM users WHERE id = %s",
    (user_id,)
)

# Safe: Named parameters
cursor.execute(
    "SELECT * FROM users WHERE id = :id",
    {"id": user_id}
)
```

## ORM Usage
<!-- Lines 46-54 -->

```python
# SQLAlchemy
User.query.filter_by(id=user_id).first()

# Django
User.objects.filter(id=user_id).first()
```

## Dynamic Columns
<!-- Lines 57-67 -->

```python
# If column must be dynamic, allowlist
ALLOWED = {'name', 'email', 'created_at'}

def order_by(column):
    if column not in ALLOWED:
        raise ValueError("Invalid column")
    return f"ORDER BY {column}"
```

## IN Clauses
<!-- Lines 70-82 -->

```python
# Safe with tuple
ids = (1, 2, 3)
cursor.execute(
    "SELECT * FROM users WHERE id IN %s",
    (ids,)
)

# SQLAlchemy
User.query.filter(User.id.in_(ids)).all()
```
