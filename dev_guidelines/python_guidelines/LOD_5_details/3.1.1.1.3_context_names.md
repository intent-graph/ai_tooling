## Narrow Scope = Short Names
<!-- Lines 17-29 -->

```python
# OK in list comprehension
[x * 2 for x in numbers]

# OK in lambda
sorted(users, key=lambda u: u.name)

# OK in short loop
for i, item in enumerate(items):
    print(f"{i}: {item}")
```

## Wide Scope = Descriptive Names
<!-- Lines 32-43 -->

```python
# Module-level: be explicit
DEFAULT_TIMEOUT_SECONDS = 30
MAX_RETRY_ATTEMPTS = 3

# Class attributes
class Config:
    database_connection_timeout: int
    api_rate_limit_per_minute: int
```
