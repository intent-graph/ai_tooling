> Standard verbs for function names.

## CRUD Operations
<!-- Lines 17-25 -->

```python
create_user()      # Create new
get_user()         # Read single
list_users()       # Read multiple
update_user()      # Modify existing
delete_user()      # Remove
```

## Query Operations
<!-- Lines 28-35 -->

```python
find_by_email()    # Search with criteria
filter_active()    # Subset by condition
exists()           # Check existence
count_by_status()  # Aggregate
```

## State Changes
<!-- Lines 38-46 -->

```python
activate()         # Enable
deactivate()       # Disable
reset()            # Return to initial
validate()         # Check validity
process()          # Execute workflow
```

## Transformations
<!-- Lines 49-56 -->

```python
to_dict()          # Convert format
from_json()        # Parse from format
format_()          # Render output
parse()            # Extract structure
```
