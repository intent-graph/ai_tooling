> Understanding asyncio's event loop.

## What is the Event Loop?
<!-- Lines 19-21 -->

Scheduler that manages async tasks. Runs coroutines, handles I/O callbacks.

## Getting the Loop
<!-- Lines 24-32 -->

```python
# In async context
loop = asyncio.get_running_loop()

# Outside async
loop = asyncio.get_event_loop()
```

## Running Code
<!-- Lines 35-47 -->

```python
# Modern (Python 3.7+)
asyncio.run(main())

# Low-level
loop = asyncio.new_event_loop()
try:
    loop.run_until_complete(main())
finally:
    loop.close()
```

## Scheduling Callbacks
<!-- Lines 50-63 -->

```python
loop = asyncio.get_running_loop()

# Call soon (next iteration)
loop.call_soon(callback, arg)

# Call later
loop.call_later(delay, callback, arg)

# Call at specific time
loop.call_at(loop.time() + delay, callback, arg)
```

## Running Sync in Async
<!-- Lines 66-75 -->

```python
# Run blocking code in thread pool
result = await loop.run_in_executor(None, blocking_func)

# With custom executor
executor = ThreadPoolExecutor(max_workers=4)
result = await loop.run_in_executor(executor, blocking_func)
```

## Debug Mode
<!-- Lines 78-84 -->

```bash
PYTHONASYNCIODEBUG=1 python script.py
```

Shows slow callbacks, unawaited coroutines.
