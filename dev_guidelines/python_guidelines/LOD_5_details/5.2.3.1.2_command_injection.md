## The Vulnerability
<!-- Lines 19-26 -->

```python
# VULNERABLE
filename = request.args.get('file')
os.system(f"cat {filename}")
# Input: "file.txt; rm -rf /" → Disaster
```

## List Arguments (Best)
<!-- Lines 29-37 -->

```python
import subprocess

# Safe: No shell interpretation
subprocess.run(["cat", filename])
subprocess.run(["convert", input_file, output_file])
```

## shlex.quote
<!-- Lines 40-48 -->

```python
import shlex

# If shell=True unavoidable
cmd = f"echo {shlex.quote(user_input)}"
subprocess.run(cmd, shell=True)
```

## Avoid Shell Entirely
<!-- Lines 51-67 -->

```python
# Instead of shell commands, use Python
# Bad
subprocess.run(["cat", filename])

# Good
with open(filename) as f:
    content = f.read()

# Bad
subprocess.run(["ls", directory])

# Good
files = list(Path(directory).iterdir())
```

## Path Validation
<!-- Lines 70-81 -->

```python
from pathlib import Path

def safe_path(user_input):
    base = Path("/app/data").resolve()
    target = (base / user_input).resolve()
    if not target.is_relative_to(base):
        raise ValueError("Invalid path")
    return target
```
