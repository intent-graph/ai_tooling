> Correct patterns for mutable default arguments.

## The Problem
<!-- Lines 19-29 -->

```python
# BUG: List shared across calls
def add_item(item, items=[]):
    items.append(item)
    return items

add_item(1)  # [1]
add_item(2)  # [1, 2] - Unexpected!
```

## Fix: None Sentinel
<!-- Lines 32-40 -->

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## Fix: Conditional Expression
<!-- Lines 43-50 -->

```python
def add_item(item, items=None):
    items = items if items is not None else []
    items.append(item)
    return items
```

## Fix: Walrus Operator (3.8+)
<!-- Lines 53-59 -->

```python
def add_item(item, items=None):
    (items := items or []).append(item)
    return items
```

## Dataclass Fix
<!-- Lines 62-70 -->

```python
from dataclasses import dataclass, field

@dataclass
class Container:
    items: list = field(default_factory=list)
```
