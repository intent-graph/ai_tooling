> Python's Global Interpreter Lock.

## What is the GIL?
<!-- Lines 19-21 -->

A mutex that allows only one thread to execute Python bytecode at a time.

## Why It Exists
<!-- Lines 24-28 -->

- Simplifies memory management
- Makes reference counting thread-safe
- Simplifies C extension integration

## Impact
<!-- Lines 31-40 -->

```python
# CPU-bound: GIL limits parallelism
def compute(n):
    return sum(i*i for i in range(n))

# Two threads won't run in parallel
# Use multiprocessing instead
```

## When GIL is Released
<!-- Lines 43-50 -->

```python
# I/O operations release GIL
response = requests.get(url)  # Other threads run
data = file.read()            # Other threads run
cursor.execute(query)         # Other threads run
```

## Workarounds
<!-- Lines 53-60 -->

| Workload | Solution |
|----------|----------|
| I/O-bound | threading (GIL released) |
| CPU-bound | multiprocessing |
| Numeric | NumPy (releases GIL) |
| C extensions | Can release GIL |

## Checking GIL
<!-- Lines 63-68 -->

```python
import sys
print(sys.getswitchinterval())  # Default: 0.005s
```
