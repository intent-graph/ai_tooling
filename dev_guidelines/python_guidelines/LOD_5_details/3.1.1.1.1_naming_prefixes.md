> Standard prefix conventions.

## Common Prefixes
<!-- Lines 15-31 -->

```python
# Private (internal use)
_internal_helper()
_cache = {}

# "Really" private (name mangling)
__secret_key

# Dunder (magic methods)
__init__, __str__, __eq__

# is_ / has_ for booleans
is_active = True
has_permission = False
```

## Avoid
<!-- Lines 34-46 -->

```python
# BAD: Hungarian notation
strName = "Alice"
lstUsers = []
intCount = 0

# GOOD: Let types speak
name = "Alice"
users = []
count = 0
```
