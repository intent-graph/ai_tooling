> Effective multiprocessing pool usage.

## Basic Pool
<!-- Lines 21-28 -->

```python
from multiprocessing import Pool

with Pool(4) as pool:
    results = pool.map(func, items)
```

## imap for Memory
<!-- Lines 31-40 -->

```python
# map: Consumes all items, returns list
results = pool.map(func, huge_list)  # Memory heavy

# imap: Iterator, memory efficient
for result in pool.imap(func, huge_list):
    process(result)
```

## imap_unordered (Fastest)
<!-- Lines 43-49 -->

```python
# Results in order of completion
for result in pool.imap_unordered(func, items):
    process(result)  # May not match input order
```

## Chunking
<!-- Lines 52-57 -->

```python
# Process in batches for efficiency
pool.map(func, items, chunksize=100)
```

## Initializer
<!-- Lines 60-69 -->

```python
def init_worker():
    global db_connection
    db_connection = connect()

with Pool(4, initializer=init_worker) as pool:
    results = pool.map(use_db, items)
```

## Error Handling
<!-- Lines 72-80 -->

```python
result = pool.apply_async(risky_func, args)
try:
    value = result.get(timeout=10)
except Exception as e:
    print(f"Worker failed: {e}")
```
