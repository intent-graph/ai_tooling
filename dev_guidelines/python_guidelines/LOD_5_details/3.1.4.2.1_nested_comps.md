> When nesting is acceptable.

## Flattening (OK)
<!-- Lines 17-24 -->

```python
# Flatten nested lists
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6]
```

## Matrix Operations (OK)
<!-- Lines 27-32 -->

```python
# Transpose
transposed = [[row[i] for row in matrix] for i in range(len(matrix[0]))]
```

## Too Complex (Avoid)
<!-- Lines 35-49 -->

```python
# BAD: Triple nesting
result = [[[x*y*z for z in zs] for y in ys] for x in xs]

# GOOD: Use explicit loops
result = []
for x in xs:
    layer = []
    for y in ys:
        row = [x * y * z for z in zs]
        layer.append(row)
    result.append(layer)
```

## Rule
<!-- Lines 52-54 -->

If you need to pause to understand it, use loops instead.
