## Basic Mixin
<!-- Lines 17-29 -->

```python
class TimestampMixin:
    created_at: datetime
    updated_at: datetime

    def touch(self) -> None:
        self.updated_at = datetime.now()

class User(TimestampMixin, Base):
    name: str
```

## Serialization Mixin
<!-- Lines 32-42 -->

```python
class JSONMixin:
    def to_json(self) -> str:
        return json.dumps(self.__dict__)

    @classmethod
    def from_json(cls, data: str):
        return cls(**json.loads(data))
```

## Guidelines
<!-- Lines 45-56 -->

```python
# Mixins should:
# - Be small and focused
# - Not require __init__
# - Use super() for cooperative inheritance
# - Be placed before base class in MRO

class MyModel(MixinA, MixinB, BaseModel):
    ...
```

## Avoid Deep Hierarchies
<!-- Lines 59-69 -->

```python
# BAD
class A(B(C(D(E)))):
    ...

# GOOD: Flat mixin composition
class A(MixinX, MixinY, Base):
    ...
```
