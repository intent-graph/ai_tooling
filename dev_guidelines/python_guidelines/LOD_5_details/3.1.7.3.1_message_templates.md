## Good Messages
<!-- Lines 17-30 -->

```python
# Include what, why, and how to fix
raise ValueError(
    f"Invalid email '{email}': must contain '@'. "
    f"Example: user@example.com"
)

raise FileNotFoundError(
    f"Config file not found: {path}. "
    f"Create one with: cp config.example.yaml {path}"
)
```

## Include Context
<!-- Lines 33-40 -->

```python
raise ValidationError(
    f"Field 'age' must be positive, got {age}. "
    f"Record: {record_id}"
)
```

## Avoid
<!-- Lines 43-52 -->

```python
# BAD: Vague
raise ValueError("Invalid input")
raise RuntimeError("Error")

# BAD: Too technical
raise ValueError(f"Regex '^[a-z]+$' failed on '{value}'")
```

## Template Pattern
<!-- Lines 55-63 -->

```python
class APIError(Exception):
    def __init__(self, endpoint: str, status: int, detail: str):
        super().__init__(
            f"API request to {endpoint} failed with status {status}: {detail}"
        )
```
