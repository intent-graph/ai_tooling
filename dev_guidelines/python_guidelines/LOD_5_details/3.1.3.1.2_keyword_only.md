## Syntax
<!-- Lines 16-25 -->

```python
def fetch(url, *, timeout=30, retries=3):
    """timeout and retries must be keyword."""
    ...

fetch("http://api", timeout=10)        # OK
fetch("http://api", 10, 5)             # TypeError
```

## Benefits
<!-- Lines 28-36 -->

# Clear intent at call site
