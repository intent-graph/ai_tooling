> Choosing between asyncio concurrency primitives.

## asyncio.gather
<!-- Lines 19-29 -->

```python
# Wait for all, return results in order
results = await asyncio.gather(
    fetch(url1),
    fetch(url2),
    fetch(url3),
)
# results = [result1, result2, result3]
```

## gather with Exceptions
<!-- Lines 32-41 -->

```python
results = await asyncio.gather(
    fetch(url1),
    fetch(url2),
    return_exceptions=True  # Don't raise
)
# results may contain Exception objects
```

## asyncio.wait
<!-- Lines 44-53 -->

```python
tasks = [asyncio.create_task(fetch(url)) for url in urls]

done, pending = await asyncio.wait(tasks)

for task in done:
    result = task.result()
```

## wait with Conditions
<!-- Lines 56-73 -->

```python
# Return when first completes
done, pending = await asyncio.wait(
    tasks,
    return_when=asyncio.FIRST_COMPLETED
)

# Return on first exception
done, pending = await asyncio.wait(
    tasks,
    return_when=asyncio.FIRST_EXCEPTION
)

# With timeout
done, pending = await asyncio.wait(tasks, timeout=5)
```

## When to Use
<!-- Lines 76-83 -->

| Use Case | Choice |
|----------|--------|
| Get all results in order | gather |
| Need done/pending sets | wait |
| First result wins | wait(FIRST_COMPLETED) |
| Cancel on first error | wait(FIRST_EXCEPTION) |
