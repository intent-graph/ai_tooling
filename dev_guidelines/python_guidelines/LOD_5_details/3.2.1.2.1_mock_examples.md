> Common mocking patterns.

## Return Values
<!-- Lines 18-30 -->

```python
from unittest.mock import Mock, MagicMock

mock = Mock(return_value=42)
mock()  # 42

# Different returns per call
mock = Mock(side_effect=[1, 2, 3])
mock()  # 1
mock()  # 2
```

## Mock Methods
<!-- Lines 33-41 -->

```python
user_service = Mock()
user_service.get_user.return_value = User(id=1, name="Alice")

result = user_service.get_user(1)
user_service.get_user.assert_called_once_with(1)
```

## Mock Exceptions
<!-- Lines 44-51 -->

```python
mock = Mock(side_effect=ValueError("Invalid"))

with pytest.raises(ValueError):
    mock()
```

## Async Mocks
<!-- Lines 54-61 -->

```python
from unittest.mock import AsyncMock

mock = AsyncMock(return_value={"data": "value"})
result = await mock()  # {"data": "value"}
```

## Spec Mocks
<!-- Lines 64-71 -->

```python
# Only allows methods that exist on UserService
mock = Mock(spec=UserService)
mock.get_user(1)       # OK
mock.nonexistent()     # AttributeError
```
