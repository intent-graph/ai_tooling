## Syntax
<!-- Lines 17-27 -->

```python
from typing import Union

# Old style
result: Union[int, str]

# Modern (Python 3.10+)
result: int | str
```

## Common Patterns
<!-- Lines 30-41 -->

```python
# Function accepting multiple types
def process(value: int | float) -> float:
    return float(value) * 2

# Return different types
def parse(raw: str) -> dict | list:
    data = json.loads(raw)
    return data  # Could be either
```

## Narrowing
<!-- Lines 44-51 -->

```python
def handle(value: int | str) -> str:
    if isinstance(value, int):
        return str(value)  # value is int
    return value.upper()   # value is str
```

## Avoid Wide Unions
<!-- Lines 54-66 -->

```python
# BAD: Too many options
def process(x: int | str | list | dict | None):
    ...

# GOOD: Constrain or use overloads
@overload
def process(x: int) -> int: ...
@overload
def process(x: str) -> str: ...
```
