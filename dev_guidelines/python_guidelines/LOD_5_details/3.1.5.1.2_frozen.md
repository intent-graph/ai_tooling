## Basic Usage
<!-- Lines 17-29 -->

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Point:
    x: float
    y: float

p = Point(1.0, 2.0)
p.x = 3.0  # FrozenInstanceError
```

## Hashable
<!-- Lines 32-38 -->

```python
# Frozen dataclasses are hashable
points = {Point(0, 0), Point(1, 1)}
cache = {Point(0, 0): "origin"}
```

## Derived Values
<!-- Lines 41-52 -->

```python
@dataclass(frozen=True)
class Rectangle:
    width: float
    height: float

    @property
    def area(self) -> float:
        return self.width * self.height
```

## "Mutation" Pattern
<!-- Lines 55-62 -->

```python
from dataclasses import replace

p1 = Point(1.0, 2.0)
p2 = replace(p1, x=3.0)  # New instance with x=3.0
```
