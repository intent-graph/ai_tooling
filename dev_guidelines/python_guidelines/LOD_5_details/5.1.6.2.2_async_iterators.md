## Async Generator
<!-- Lines 19-33 -->

```python
async def fetch_pages(url):
    page = 1
    while True:
        data = await fetch(f"{url}?page={page}")
        if not data:
            break
        yield data
        page += 1

async for page in fetch_pages(url):
    process(page)
```

## Async Iterator Class
<!-- Lines 36-56 -->

```python
class AsyncCounter:
    def __init__(self, limit):
        self.limit = limit
        self.count = 0

    def __aiter__(self):
        return self

    async def __anext__(self):
        if self.count >= self.limit:
            raise StopAsyncIteration
        self.count += 1
        await asyncio.sleep(0.1)
        return self.count

async for num in AsyncCounter(5):
    print(num)
```
