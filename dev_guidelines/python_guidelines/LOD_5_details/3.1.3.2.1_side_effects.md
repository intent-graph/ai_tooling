## Pure vs Impure
<!-- Lines 16-27 -->

```python
# Pure: Same input → same output, no side effects
def add(a: int, b: int) -> int:
    return a + b

# Impure: Side effects
def log_and_add(a: int, b: int) -> int:
    print(f"Adding {a} + {b}")  # Side effect: I/O
    return a + b
```

## Common Side Effects
<!-- Lines 30-44 -->

```python
# I/O
print(), open(), requests.get()

# Mutation
list.append(), dict.update()

# Global state
global counter; counter += 1

# Time-dependent
datetime.now(), random.random()
```

## Isolation Pattern
<!-- Lines 47-60 -->

```python
# Separate pure logic from side effects
def calculate_total(items: list[Item]) -> float:
    """Pure calculation."""
    return sum(item.price for item in items)

def process_order(items: list[Item]) -> None:
    """Orchestrates side effects."""
    total = calculate_total(items)  # Pure
    save_to_db(total)               # Side effect
    send_receipt(total)             # Side effect
```
