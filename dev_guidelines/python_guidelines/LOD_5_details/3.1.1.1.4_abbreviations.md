> When abbreviations are acceptable.

## Allowed Abbreviations
<!-- Lines 16-32 -->

```python
# Universal
id      # identifier
db      # database
api     # application programming interface
url     # uniform resource locator
http    # hypertext transfer protocol
config  # configuration
auth    # authentication/authorization
admin   # administrator

# Domain-specific (document if needed)
tx      # transaction (in financial code)
msg     # message (in messaging systems)
```

## Avoid
<!-- Lines 35-47 -->

```python
# BAD: Unclear abbreviations
usr_mgr = UserManager()
proc_req = process_request()
calc_ttl = calculate_total()

# GOOD: Spell it out
user_manager = UserManager()
processed_request = process_request()
calculated_total = calculate_total()
```

## Rule
<!-- Lines 50-52 -->

Abbreviate only when the full word adds no clarity and the abbreviation is universally understood.
