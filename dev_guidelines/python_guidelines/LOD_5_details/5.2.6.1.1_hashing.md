## Password Hashing
<!-- Lines 18-31 -->

```python
# Use Argon2 (recommended)
from argon2 import PasswordHasher

ph = PasswordHasher()
hash = ph.hash("password123")

try:
    ph.verify(hash, "password123")
except argon2.exceptions.VerifyMismatchError:
    print("Wrong password")
```

## bcrypt Alternative
<!-- Lines 34-44 -->

```python
import bcrypt

salt = bcrypt.gensalt()
hash = bcrypt.hashpw(password.encode(), salt)

if bcrypt.checkpw(password.encode(), hash):
    print("Valid")
```

## HMAC for Authentication
<!-- Lines 58-69 -->

```python
import hmac

def sign(message: bytes, key: bytes) -> bytes:
    return hmac.new(key, message, 'sha256').digest()

def verify(message: bytes, signature: bytes, key: bytes) -> bool:
    expected = sign(message, key)
    return hmac.compare_digest(signature, expected)
```
