> Efficient layer caching for faster builds.

## Problem
<!-- Lines 19-25 -->

```dockerfile
# BAD: Reinstalls deps on every code change
COPY . .
RUN pip install -r requirements.txt
```

## Solution: Copy Dependencies First
<!-- Lines 28-36 -->

```dockerfile
# GOOD: Dependencies cached if unchanged
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY src/ ./src/
```

## Layer Order
<!-- Lines 39-51 -->

```dockerfile
# 1. System dependencies (rarely change)
RUN apt-get update && apt-get install -y libpq5

# 2. Python dependencies (change sometimes)
COPY pyproject.toml uv.lock ./
RUN uv sync --frozen

# 3. Application code (changes often)
COPY src/ ./src/
```

## BuildKit Cache Mounts
<!-- Lines 54-67 -->

```dockerfile
# syntax=docker/dockerfile:1
FROM python:3.11-slim

# Cache pip downloads
RUN --mount=type=cache,target=/root/.cache/pip \
    pip install -r requirements.txt

# Cache uv
RUN --mount=type=cache,target=/root/.cache/uv \
    uv sync --frozen
```

## CI Caching
<!-- Lines 70-78 -->

```yaml
# GitHub Actions
- uses: docker/build-push-action@v5
  with:
    cache-from: type=gha
    cache-to: type=gha,mode=max
```
