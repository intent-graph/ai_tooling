> Validate at system edges, trust internally.

## Boundary Pattern
<!-- Lines 17-29 -->

```
External (untrusted)
        │
    [Validate]  ← Convert to domain types
        │
Internal (trusted)
        │
    [Serialize] ← Convert back
        │
External Output
```

## Input Boundary
<!-- Lines 32-41 -->

```python
# API layer: validate and convert
@app.post("/tasks")
def create_task(data: TaskInput) -> TaskOutput:
    # TaskInput (Pydantic) validates automatically
    task = service.create(data.to_domain())  # Domain type
    return TaskOutput.from_domain(task)
```

## Internal Trust
<!-- Lines 44-53 -->

```python
# Domain layer: no re-validation
class TaskService:
    def create(self, task: Task) -> Task:
        # Task already validated at boundary
        # Don't validate again
        return self.repo.save(task)
```

## Key Principle
<!-- Lines 56-58 -->

Validate once at the edge, work with trusted types inside.
