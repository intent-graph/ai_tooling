> Preserve error context.

## Implicit Chaining
<!-- Lines 17-25 -->

```python
try:
    process()
except ValueError:
    raise RuntimeError("Processing failed")
# __context__ automatically set
```

## Explicit Chaining (from)
<!-- Lines 28-36 -->

```python
try:
    data = json.loads(raw)
except json.JSONDecodeError as e:
    raise ValidationError("Invalid JSON input") from e
# __cause__ explicitly set
```

## Suppress Chaining
<!-- Lines 39-47 -->

```python
try:
    process()
except ValueError:
    raise RuntimeError("New error") from None
# Hides original exception
```

## Accessing Chain
<!-- Lines 50-59 -->

```python
try:
    operation()
except RuntimeError as e:
    print(f"Error: {e}")
    if e.__cause__:
        print(f"Caused by: {e.__cause__}")
```
