## Image Variants
<!-- Lines 18-25 -->

| Image | Size | Use Case |
|-------|------|----------|
| `python:3.11` | ~900MB | Need build tools |
| `python:3.11-slim` | ~150MB | Most applications |
| `python:3.11-alpine` | ~50MB | Size-critical |
| `python:3.11-bookworm` | ~900MB | Latest Debian |

## Recommended: slim
<!-- Lines 28-37 -->

```dockerfile
FROM python:3.11-slim

# Install only what you need
RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq5 \
    && rm -rf /var/lib/apt/lists/*
```

## Alpine Caveats
<!-- Lines 40-55 -->

```dockerfile
FROM python:3.11-alpine

# Alpine uses musl, not glibc
# Many wheels don't work - need to compile
RUN apk add --no-cache gcc musl-dev

# Some packages may behave differently
```

**When to avoid Alpine:**
- Using packages with C extensions
- Need binary wheels
- Don't need absolute smallest size

## Distroless (Maximum Security)
<!-- Lines 58-69 -->

```dockerfile
FROM python:3.11-slim AS builder
# ... build steps ...

FROM gcr.io/distroless/python3
COPY --from=builder /app /app
CMD ["app.py"]
```

No shell, no package manager, minimal attack surface.

## Version Pinning
<!-- Lines 72-80 -->

```dockerfile
# Pin major.minor for stability
FROM python:3.11-slim

# Pin exact for reproducibility
FROM python:3.11.7-slim-bookworm
```
