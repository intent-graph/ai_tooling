## Core Concept
<!-- Lines 17-34 -->

**Rule #1:** Don't roll your own crypto. Use established libraries.

**Why:**
- Crypto is hard to get right
- Subtle bugs have catastrophic consequences
- Battle-tested libraries exist

**Libraries:**
- `cryptography`: Modern, comprehensive
- `PyNaCl`: Simple, secure defaults
- `argon2-cffi`: Password hashing

## Password Hashing
<!-- Lines 37-84 -->

Passwords must be hashed, not encrypted. Hashing is one-way.

**NEVER use for passwords:**
- MD5, SHA1, SHA256 (too fast, no salt)
- Encryption (reversible)
- Plain text (obviously)

**Use Argon2 (recommended):**
```python
from argon2 import PasswordHasher

ph = PasswordHasher()

# Hash password
hash = ph.hash("user_password")
# $argon2id$v=19$m=65536,t=3,p=4$...

# Verify password
try:
    ph.verify(hash, "user_password")
    # Success
except argon2.exceptions.VerifyMismatchError:
    # Wrong password
    pass
```

**Or bcrypt:**
```python
import bcrypt

# Hash
salt = bcrypt.gensalt()
hash = bcrypt.hashpw(password.encode(), salt)

# Verify
if bcrypt.checkpw(password.encode(), hash):
    # Success
    pass
```

**Password Hashing Properties:**
- Slow (intentionally, to prevent brute force)
- Salted (prevents rainbow tables)
- One-way (can't recover password)

## Encryption
<!-- Lines 87-136 -->

Use encryption when you need to recover the original data.

**Symmetric Encryption (Fernet):**
```python
from cryptography.fernet import Fernet

# Generate key (store securely!)
key = Fernet.generate_key()

# Encrypt
f = Fernet(key)
encrypted = f.encrypt(b"secret data")

# Decrypt
decrypted = f.decrypt(encrypted)
```

**Key Management:**
```python
import os
from base64 import urlsafe_b64encode

# Generate from secure random
key = urlsafe_b64encode(os.urandom(32))

# Or derive from password
from cryptography.hazmat.primitives.kdf.pbkdf2 import PBKDF2HMAC
from cryptography.hazmat.primitives import hashes

kdf = PBKDF2HMAC(
    algorithm=hashes.SHA256(),
    length=32,
    salt=salt,
    iterations=480000,
)
key = urlsafe_b64encode(kdf.derive(password.encode()))
```

**When to Encrypt:**
- Data at rest (database fields, files)
- Data in transit (TLS/HTTPS)
- Backups

**When NOT to Encrypt:**
- Passwords (hash instead)
- Data you never need to read back

## Secure Random
<!-- Lines 139-182 -->

For security purposes, use cryptographically secure random.

**NEVER use `random` module for security:**
```python
import random

# BAD: Predictable
token = ''.join(random.choices('abcdef0123456789', k=32))
```

**Use `secrets` module:**
```python
import secrets

# Token generation
token = secrets.token_urlsafe(32)  # URL-safe base64
token = secrets.token_hex(32)      # Hexadecimal
token = secrets.token_bytes(32)    # Raw bytes

# Random integer
n = secrets.randbelow(100)  # 0-99

# Random choice
item = secrets.choice(items)
```

**Use `os.urandom` for raw bytes:**
```python
import os

random_bytes = os.urandom(32)
```

**When to Use Secure Random:**
- Session tokens
- Password reset tokens
- API keys
- Cryptographic keys
- CSRF tokens
- Any security-sensitive random

## Common Mistakes
<!-- Lines 185-240 -->

**Using MD5/SHA for Passwords:**
```python
# WRONG
import hashlib
hash = hashlib.sha256(password.encode()).hexdigest()

# RIGHT
from argon2 import PasswordHasher
hash = PasswordHasher().hash(password)
```

**Hardcoded Keys:**
```python
# WRONG
KEY = "supersecretkey123"

# RIGHT
KEY = os.environ["ENCRYPTION_KEY"]
```

**ECB Mode:**
```python
# WRONG: ECB reveals patterns
# (Don't use low-level crypto anyway)

# RIGHT: Use high-level APIs like Fernet
# which handle mode selection correctly
```

**Predictable IVs:**
```python
# WRONG
iv = b"0000000000000000"

# RIGHT: Random IV (Fernet handles this)
```

**Comparing Secrets Insecurely:**
```python
# WRONG: Timing attack
if user_token == secret_token:
    pass

# RIGHT: Constant-time comparison
import secrets
if secrets.compare_digest(user_token, secret_token):
    pass
```

**Not Validating Decryption:**
```python
# Fernet validates automatically (authenticated encryption)
# If using lower-level APIs, always use authenticated modes
# (GCM, CCM) or add HMAC
```
