## Core Concept
<!-- Lines 38-69 -->

**Definition:** A breaking change is any modification that requires users to change their code to maintain the same behavior.

**What Breaks:**
- Removing functions, classes, or modules
- Changing function signatures (required params, types)
- Changing return types
- Changing default behavior
- Changing exception types
- Removing or renaming public attributes

**What Doesn't Break:**
- Adding new functions or classes
- Adding optional parameters
- Changing internal implementation
- Performance improvements
- Bug fixes (usually)

**SemVer and Breaking Changes:**
```
MAJOR.MINOR.PATCH
  ^
  └── Breaking changes increment MAJOR
      (1.x.x → 2.0.0)
```

## Identifying Breaking Changes
<!-- Lines 72-72 -->

### Signature Changes
<!-- Lines 75-88 -->

```python
# Breaking: Required parameter added
def process(data):           # v1
def process(data, config):   # v2 - breaks existing calls

# Not breaking: Optional parameter
def process(data, config=None):  # Safe addition

# Breaking: Parameter removed
def fetch(url, timeout=30):  # v1
def fetch(url):              # v2 - breaks timeout users
```

### Return Type Changes
<!-- Lines 91-101 -->

```python
# Breaking: Type change
def get_user(id) -> User:     # v1
def get_user(id) -> dict:     # v2 - breaks User method calls

# Breaking: Structure change
def get_users() -> list[User]:      # v1
def get_users() -> dict[str, User]: # v2 - breaks iteration
```

### Behavior Changes
<!-- Lines 104-116 -->

```python
# Breaking: Different default
def connect(timeout=30):   # v1: 30 second timeout
def connect(timeout=5):    # v2: May cause new timeouts

# Breaking: Different error
def parse(text):
    raise ValueError(...)  # v1
def parse(text):
    raise ParseError(...)  # v2: except ValueError won't catch
```

### Attribute Changes
<!-- Lines 119-134 -->

```python
# Breaking: Removed attribute
class User:
    name: str
    email: str      # v1
    # email removed in v2 - breaks user.email

# Breaking: Renamed attribute
class User:
    email: str       # v1
    email_address: str  # v2 - breaks user.email
```

### Add, Don't Modify
<!-- Lines 140-149 -->

```python
# Instead of changing, add a new function
def get_user(id) -> User:  # Keep for compatibility

### Use Optional Parameters
<!-- Lines 152-158 -->

```python

def process(data, *, format: str = "json"):
    """New format parameter doesn't break existing code."""
```

### Adapter Layer
<!-- Lines 161-176 -->

```python
# Provide compatibility shim
class LegacyUserAdapter:
    """Wraps new API in old interface."""

    def __init__(self, new_user: UserV2):
        self._user = new_user

    @property
    def email(self) -> str:
        # Old API: user.email
        # New API: user.contact.email
        return self._user.contact.email
```

### Grace Period
<!-- Lines 194-214 -->

```python
# Support both old and new patterns
def get_users(*, as_dict: bool = False) -> list | dict:
    """
    Args:
        as_dict: Return as dict (new format).
                 Will become default in v3.0.
    """
    users = fetch_users()
    if as_dict:
        return {u.id: u for u in users}
    warnings.warn(
        "List return is deprecated. Use as_dict=True.",
        DeprecationWarning
    )
    return users
```

#### `get_user()` return type changed
<!-- Lines 235-249 -->
- **Before**: Returned `User` object
- **After**: Returns `UserResponse` dict
- **Migration**:
  ```python
  # Old
  user = get_user(id)
  print(user.name)

  # New
  response = get_user(id)
  print(response["user"]["name"])
  ```
- **Reason**: Enables richer response metadata

### Automated Migration
<!-- Lines 279-294 -->

```python
# Provide codemods when possible
# Using libcst for safe transformations
import libcst as cst

class MigrateGetUser(cst.CSTTransformer):
    def leave_Call(self, original, updated):
        if self._is_get_user_call(updated):
            # get_user(x) → get_user(x)["user"]
            return cst.Subscript(
                value=updated,
                slice=[cst.SubscriptElement(cst.Index(cst.SimpleString('"user"')))]
            )
        return updated
```
