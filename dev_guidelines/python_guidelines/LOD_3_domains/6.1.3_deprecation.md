## Core Concept
<!-- Lines 29-54 -->

**Definition:** Deprecation is the process of marking features, APIs, or patterns as obsolete while giving users time to migrate to alternatives.

**Key Principles:**
- Never remove without deprecating first
- Always provide a migration path
- Emit warnings that guide users
- Set and communicate removal timelines

**The Deprecation Contract:**
1. Announce what is deprecated and why
2. Document the alternative
3. Warn at runtime during transition period
4. Remove only after sufficient warning period

**Timeline Guidelines:**
- Internal code: 1-2 release cycles
- Library APIs: 2+ major versions
- Critical infrastructure: Years with clear roadmap

## Deprecation Lifecycle
<!-- Lines 57-57 -->

### Phase 1: Announce
<!-- Lines 60-70 -->

```python
# Add to docstring and release notes
def old_function(x):
    """Process x.

    .. deprecated:: 2.0
        Use :func:`new_function` instead. Will be removed in 3.0.
    """
```

### Phase 2: Warn
<!-- Lines 73-87 -->

```python
import warnings

def old_function(x):
    """..."""
    warnings.warn(
        "old_function is deprecated, use new_function instead. "
        "Will be removed in version 3.0.",
        DeprecationWarning,
        stacklevel=2  # Point to caller, not this line
    )
    return new_function(x)
```

### Phase 3: Remove
<!-- Lines 90-98 -->

```python
# In version 3.0
# old_function is deleted entirely

# Update release notes:
# BREAKING: Removed old_function (deprecated since 2.0)
```

### Soft Deprecation
<!-- Lines 101-117 -->

For internal changes where removal isn't planned:

```python
def soft_deprecated_function(x):
    """Still works, but prefer new_function for new code.

    Note:
        This function is soft-deprecated. It will continue to work
        but new_function is preferred for new code.
    """
    # No warning emitted, just documented preference
    return _implementation(x)
```

## Python Deprecation Tools
<!-- Lines 120-120 -->

### warnings Module
<!-- Lines 123-140 -->

```python
import warnings

# Emit deprecation warning
warnings.warn("message", DeprecationWarning, stacklevel=2)

# Filter warnings (in tests)
warnings.filterwarnings("error", category=DeprecationWarning)

# Ignore specific deprecation
warnings.filterwarnings(
    "ignore",
    message="old_function.*",
    category=DeprecationWarning
)
```

### @deprecated Decorator (Python 3.13+)
<!-- Lines 152-165 -->

```python
from warnings import deprecated

@deprecated("Use new_function instead")
def old_function(x):
    return x

# Also works on classes
@deprecated("Use NewClass instead")
class OldClass:
    pass
```

### Custom Decorator (Pre-3.13)
<!-- Lines 168-193 -->

```python
import functools
import warnings

def deprecated(message: str, version: str = None):
    """Mark function as deprecated."""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            warn_msg = f"{func.__name__} is deprecated"
            if version:
                warn_msg += f" since version {version}"
            warn_msg += f". {message}"
            warnings.warn(warn_msg, DeprecationWarning, stacklevel=2)
            return func(*args, **kwargs)
        return wrapper
    return decorator

@deprecated("Use new_function instead", version="2.0")
def old_function(x):
    return new_function(x)
```

### Migration Guide
<!-- Lines 214-238 -->

```markdown
# Migrating from old_function to new_function

## Before (deprecated)
<!-- Lines 224-228 -->
```python
result = old_function(data)
name, value = result  # Tuple unpacking
```

## After
<!-- Lines 231-236 -->
```python
result = new_function(data)
name = result["name"]
value = result["value"]
```

## Why the change?
<!-- Lines 239-242 -->
The dict return type is more explicit and allows adding
new fields without breaking existing code.
```

### Warning Message Best Practices
<!-- Lines 241-254 -->

```python
# Good: Actionable, specific
warnings.warn(
    "get_user(id) is deprecated since v2.0. "
    "Use UserService.get(id) instead. "
    "See https://docs.example.com/migration for details.",
    DeprecationWarning,
    stacklevel=2
)

# Bad: Vague, unhelpful
warnings.warn("Deprecated", DeprecationWarning)
```
