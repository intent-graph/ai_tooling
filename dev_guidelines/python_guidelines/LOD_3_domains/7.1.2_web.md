## Core Concept
<!-- Lines 30-51 -->

**Definition:** Web applications serve HTML pages to browsers, handling HTTP requests, rendering templates, and managing user sessions.

**Key Concerns:**
- Request routing and handling
- Template rendering
- Session and authentication
- Database integration
- Form handling and validation
- Static files

**Web App vs API:**
- Web apps render HTML for browsers
- APIs return JSON/XML for programmatic clients
- Many apps do both (hybrid)

## Framework Comparison
<!-- Lines 54-54 -->

### Django
<!-- Lines 57-82 -->

```python
# urls.py
from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),
    path("users/<int:user_id>/", views.user_detail, name="user_detail"),
]

# views.py
from django.shortcuts import render, get_object_or_404

def home(request):
    users = User.objects.all()
    return render(request, "home.html", {"users": users})

def user_detail(request, user_id):
    user = get_object_or_404(User, pk=user_id)
    return render(request, "user_detail.html", {"user": user})
```

**Best for:** Full-featured web apps, admin interfaces, ORM-heavy
**Includes:** ORM, admin, auth, forms, migrations

### Flask
<!-- Lines 85-106 -->

```python
from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/")
def home():
    users = get_users()
    return render_template("home.html", users=users)

@app.route("/users/<int:user_id>")
def user_detail(user_id):
    user = get_user(user_id)
    if not user:
        abort(404)
    return render_template("user_detail.html", user=user)
```

**Best for:** Simple apps, maximum flexibility, learning
**Includes:** Minimal - add extensions as needed

### FastAPI (with Templates)
<!-- Lines 109-128 -->

```python
from fastapi import FastAPI, Request
from fastapi.templating import Jinja2Templates
from fastapi.staticfiles import StaticFiles

app = FastAPI()
app.mount("/static", StaticFiles(directory="static"), name="static")
templates = Jinja2Templates(directory="templates")

@app.get("/")
async def home(request: Request):
    users = await get_users()
    return templates.TemplateResponse(
        "home.html", {"request": request, "users": users}
    )
```

**Best for:** API-first with some HTML, async requirements

### Template Inheritance (Jinja2)
<!-- Lines 147-173 -->

```html
<!-- base.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}My App{% endblock %}</title>
</head>
<body>
    <nav>{% include "nav.html" %}</nav>
    <main>{% block content %}{% endblock %}</main>
</body>
</html>

<!-- home.html -->
{% extends "base.html" %}

{% block title %}Home - My App{% endblock %}

{% block content %}
<h1>Welcome</h1>
{% for user in users %}
    <p>{{ user.name }}</p>
{% endfor %}
{% endblock %}
```

### Form Handling (Flask)
<!-- Lines 176-196 -->

```python
from flask import request, flash, redirect

@app.route("/register", methods=["GET", "POST"])
def register():
    if request.method == "POST":
        email = request.form.get("email")
        password = request.form.get("password")

        if not email or not password:
            flash("All fields required", "error")
            return render_template("register.html")

        create_user(email, password)
        flash("Registration successful", "success")
        return redirect(url_for("login"))

    return render_template("register.html")
```

### Session Management
<!-- Lines 199-218 -->

```python
# Flask
from flask import session

@app.route("/login", methods=["POST"])
def login():
    user = authenticate(request.form["email"], request.form["password"])
    if user:
        session["user_id"] = user.id
        return redirect(url_for("dashboard"))
    flash("Invalid credentials")
    return redirect(url_for("login"))

@app.route("/logout")
def logout():
    session.pop("user_id", None)
    return redirect(url_for("home"))
```

### XSS Prevention
<!-- Lines 257-265 -->

```html
<!-- Jinja2 auto-escapes by default -->
{{ user.name }}  <!-- Safe: escapes HTML -->

<!-- Explicitly mark as safe (dangerous!) -->
{{ user.bio | safe }}  <!-- Only if you trust the content -->
```

### SQL Injection Prevention
<!-- Lines 268-276 -->

```python
# Always use parameterized queries
User.query.filter_by(email=email).first()  # Safe (ORM)

# Never string interpolation
f"SELECT * FROM users WHERE email = '{email}'"  # VULNERABLE
```

### Authentication Best Practices
<!-- Lines 292-304 -->

```python
# Hash passwords
from werkzeug.security import generate_password_hash, check_password_hash

hashed = generate_password_hash(password)
is_valid = check_password_hash(hashed, password)

# Use secure session cookies
app.config["SESSION_COOKIE_SECURE"] = True  # HTTPS only
app.config["SESSION_COOKIE_HTTPONLY"] = True  # No JS access
app.config["SESSION_COOKIE_SAMESITE"] = "Lax"  # CSRF protection
```
