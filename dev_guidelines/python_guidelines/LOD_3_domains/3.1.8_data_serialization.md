## Format Selection
<!-- Lines 16-44 -->

Choose serialization format based on use case, performance needs, and human readability requirements.

**Format Comparison:**

| Format | Human Readable | Schema | Performance | Use Case |
|--------|---------------|--------|-------------|----------|
| JSON | Yes | Optional | Medium | APIs, configs |
| YAML | Yes | Optional | Slow | Configs |
| TOML | Yes | No | Fast | Simple configs |
| Pickle | No | No | Fast | Python-to-Python |
| MessagePack | No | Optional | Very fast | High-performance |

**Decision Matrix:**
```
Need human editing? → YAML or TOML
Web API? → JSON
Python-only + trusted? → Pickle
Maximum speed? → MessagePack or Protocol Buffers
```

**Security Note:**
Never deserialize untrusted data with pickle—it executes arbitrary code.

## JSON
<!-- Lines 47-115 -->

JSON is the standard for web APIs and configuration files.

**Basic Usage:**
```python
import json

# Serialize
data = {"name": "Alice", "age": 30}
json_string = json.dumps(data)
json.dump(data, file)  # To file

# Deserialize
data = json.loads(json_string)
data = json.load(file)  # From file
```

**Pretty Printing:**
```python
json.dumps(data, indent=2, sort_keys=True)
```

**Custom Serialization:**
```python
from dataclasses import dataclass, asdict
from datetime import datetime

@dataclass
class User:
    name: str
    created_at: datetime

def serialize_user(user: User) -> str:
    data = asdict(user)
    data["created_at"] = user.created_at.isoformat()
    return json.dumps(data)
```

**Custom Encoder:**
```python
class CustomEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        if isinstance(obj, Decimal):
            return str(obj)
        return super().default(obj)

json.dumps(data, cls=CustomEncoder)
```

**With Pydantic (Recommended):**
```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

user = User(name="Alice", age=30)
json_str = user.model_dump_json()
user = User.model_validate_json(json_str)
```

## YAML and TOML
<!-- Lines 118-181 -->

YAML and TOML are human-friendly configuration formats.

**YAML:**
```python
import yaml

# Load
with open("config.yaml") as f:
    config = yaml.safe_load(f)  # Always use safe_load!

# Dump
with open("config.yaml", "w") as f:
    yaml.dump(config, f, default_flow_style=False)
```

**YAML Format:**
```yaml
database:
  host: localhost
  port: 5432

features:
  - dark_mode
  - notifications
```

**TOML (Python 3.11+):**
```python
import tomllib

# Load (read-only in stdlib)
with open("config.toml", "rb") as f:
    config = tomllib.load(f)

# For writing, use tomli-w
import tomli_w
with open("config.toml", "wb") as f:
    tomli_w.dump(config, f)
```

**TOML Format:**
```toml
[database]
host = "localhost"
port = 5432

[features]
dark_mode = true
```

**YAML vs TOML:**
| Aspect | YAML | TOML |
|--------|------|------|
| Complexity | High | Low |
| Indentation | Significant | Not significant |
| Comments | Yes | Yes |
| Multi-line strings | Multiple ways | Clear syntax |

## Binary Formats
<!-- Lines 184-245 -->

Binary formats offer better performance but sacrifice human readability.

**Pickle (Python-only):**
```python
import pickle

# Serialize
with open("data.pkl", "wb") as f:
    pickle.dump(obj, f)

# Deserialize
with open("data.pkl", "rb") as f:
    obj = pickle.load(f)

# WARNING: Never unpickle untrusted data!
```

**When to Use Pickle:**
- Python-to-Python communication
- Caching computed results
- Trusted data only

**MessagePack (Cross-language):**
```python
import msgpack

# Serialize
packed = msgpack.packb(data)

# Deserialize
data = msgpack.unpackb(packed)
```

**Protocol Buffers (Schema-based):**
```protobuf
// user.proto
message User {
  string name = 1;
  int32 age = 2;
}
```

```python
from user_pb2 import User

user = User(name="Alice", age=30)
binary = user.SerializeToString()
user = User.FromString(binary)
```

**Performance Comparison:**
```
JSON:        100% (baseline)
YAML:        ~50% (slower)
MessagePack: ~300% (faster)
Protobuf:    ~400% (faster)
Pickle:      ~200% (faster)
```
