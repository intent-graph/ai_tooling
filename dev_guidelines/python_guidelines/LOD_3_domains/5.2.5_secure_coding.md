## SQL Injection
<!-- Lines 35-80 -->

SQL injection occurs when user input is concatenated into SQL queries.

**Vulnerable:**
```python
# NEVER do this
user_id = request.args.get('id')
query = f"SELECT * FROM users WHERE id = {user_id}"
# Input: "1 OR 1=1" → Returns all users
# Input: "1; DROP TABLE users" → Data loss
```

**Safe: Parameterized Queries:**
```python
# Raw DB-API
cursor.execute("SELECT * FROM users WHERE id = %s", (user_id,))

# SQLAlchemy ORM
user = session.query(User).filter(User.id == user_id).first()

# SQLAlchemy Core
stmt = select(users).where(users.c.id == user_id)
```

**Safe: ORM Methods:**
```python
# Django
User.objects.filter(id=user_id)

# SQLAlchemy
User.query.filter_by(id=user_id).first()
```

**Dynamic Column Names (careful):**
```python
# If column name must be dynamic, allowlist it
ALLOWED_COLUMNS = {'name', 'email', 'created_at'}

def sort_by(column: str):
    if column not in ALLOWED_COLUMNS:
        raise ValueError("Invalid column")
    return f"ORDER BY {column}"  # Safe because allowlisted
```

## Command Injection
<!-- Lines 83-135 -->

Command injection occurs when user input is passed to shell commands.

**Vulnerable:**
```python
import os
import subprocess

filename = request.args.get('file')

# NEVER do this
os.system(f"cat {filename}")
# Input: "file.txt; rm -rf /" → Disaster

subprocess.run(f"convert {filename} output.png", shell=True)
# Same problem
```

**Safe: List Arguments:**
```python
# Use list form, no shell
subprocess.run(["cat", filename])
subprocess.run(["convert", filename, "output.png"])
```

**Safe: shlex.quote:**
```python
import shlex

# If shell=True is unavoidable
cmd = f"echo {shlex.quote(user_input)}"
subprocess.run(cmd, shell=True)
```

**Avoid Shell Entirely:**
```python
# Instead of calling shell commands, use Python libraries
# Bad
subprocess.run(["cat", filename])

# Good
with open(filename) as f:
    content = f.read()

# Bad
subprocess.run(["ls", directory])

# Good
files = list(Path(directory).iterdir())
```

## Path Traversal
<!-- Lines 138-182 -->

Path traversal allows accessing files outside intended directories.

**Vulnerable:**
```python
def read_file(filename):
    with open(f"/app/uploads/{filename}") as f:
        return f.read()

# Input: "../../../etc/passwd" → Reads system file
```

**Safe: Validate Path:**
```python
from pathlib import Path

def safe_read(user_filename: str) -> str:
    base = Path("/app/uploads").resolve()
    target = (base / user_filename).resolve()

    # Check target is under base
    if not target.is_relative_to(base):
        raise ValueError("Path traversal attempt")

    if not target.exists():
        raise FileNotFoundError("File not found")

    return target.read_text()
```

**Safe: Allowlist Approach:**
```python
import hashlib

def get_upload_path(user_id: int, filename: str) -> Path:
    # Generate safe filename from hash
    safe_name = hashlib.sha256(filename.encode()).hexdigest()[:16]
    ext = Path(filename).suffix
    if ext not in ALLOWED_EXTENSIONS:
        raise ValueError("Invalid extension")
    return Path(f"/app/uploads/{user_id}/{safe_name}{ext}")
```

## Timing Attacks
<!-- Lines 185-230 -->

Timing attacks extract information by measuring response time.

**Vulnerable:**
```python
def check_token(user_token: str, secret_token: str) -> bool:
    # Early exit reveals how many characters matched
    if len(user_token) != len(secret_token):
        return False
    for a, b in zip(user_token, secret_token):
        if a != b:
            return False  # Time varies by match position
    return True
```

**Safe: Constant-Time Comparison:**
```python
import secrets

def check_token(user_token: str, secret_token: str) -> bool:
    # Always takes same time regardless of match
    return secrets.compare_digest(user_token, secret_token)
```

**Safe: hmac.compare_digest:**
```python
import hmac

def verify_signature(received: bytes, expected: bytes) -> bool:
    return hmac.compare_digest(received, expected)
```

**Other Timing Considerations:**
```python
# Avoid early returns in authentication
def authenticate(username: str, password: str) -> bool:
    user = get_user(username)

    # Bad: Returns early if user not found
    if not user:
        return False

    # Good: Always check password (even fake hash)
    expected = user.password_hash if user else fake_hash()
    return check_password(password, expected) and user is not None
```
