## Core Concept
<!-- Lines 20-35 -->

Profiling measures actual performance, replacing guesses with data. Different profilers serve different needs.

| Profiler | Measures | Overhead | Use Case |
|----------|----------|----------|----------|
| cProfile | Function time | Low | General profiling |
| line_profiler | Line time | High | Hot function analysis |
| memory_profiler | Memory | High | Memory debugging |
| py-spy | Sampling | Minimal | Production profiling |

## cProfile
<!-- Lines 38-79 -->

Built-in function-level profiler. Low overhead, good for overall picture.

**Command Line:**
```bash
python -m cProfile -s cumulative script.py
```

**Programmatic:**
```python
import cProfile
import pstats

profiler = cProfile.Profile()
profiler.enable()

# Code to profile
main()

profiler.disable()
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative')
stats.print_stats(20)  # Top 20 functions
```

**Output Columns:**
| Column | Meaning |
|--------|---------|
| ncalls | Number of calls |
| tottime | Time in function (excluding subcalls) |
| cumtime | Time in function (including subcalls) |
| percall | Time per call |

**Save for Visualization:**
```python
profiler.dump_stats('profile.prof')
# Visualize with snakeviz
# pip install snakeviz && snakeviz profile.prof
```

## line_profiler
<!-- Lines 82-118 -->

Line-by-line timing for specific functions. High overhead—use on targeted functions.

**Installation:**
```bash
pip install line_profiler
```

**Usage:**
```python
@profile  # Decorator added by kernprof
def slow_function():
    data = load_data()       # Line 1
    processed = process(data) # Line 2
    return save(processed)    # Line 3
```

```bash
kernprof -l -v script.py
```

**Output:**
```
Line #      Hits         Time  Per Hit   % Time  Line Contents
==============================================================
     1         1      15000.0  15000.0     15.0  data = load_data()
     2         1      80000.0  80000.0     80.0  processed = process(data)
     3         1       5000.0   5000.0      5.0  return save(processed)
```

**When to Use:**
- cProfile identified a slow function
- Need to know which line is the problem
- Optimizing a specific hot path

## memory_profiler
<!-- Lines 121-163 -->

Line-by-line memory usage tracking.

**Installation:**
```bash
pip install memory_profiler
```

**Usage:**
```python
from memory_profiler import profile

@profile
def memory_heavy():
    a = [1] * (10 ** 6)
    b = [2] * (2 * 10 ** 7)
    del b
    return a
```

```bash
python -m memory_profiler script.py
```

**Output:**
```
Line #    Mem usage    Increment   Line Contents
================================================
     3     38.0 MiB     38.0 MiB   @profile
     4     45.6 MiB      7.6 MiB   a = [1] * (10 ** 6)
     5    198.2 MiB    152.6 MiB   b = [2] * (2 * 10 ** 7)
     6     45.6 MiB   -152.6 MiB   del b
     7     45.6 MiB      0.0 MiB   return a
```

**mprof for Over-Time Analysis:**
```bash
mprof run script.py
mprof plot
```

## py-spy
<!-- Lines 166-200 -->

Sampling profiler that can attach to running processes. Minimal overhead—safe for production.

**Installation:**
```bash
pip install py-spy
```

**Live Top View:**
```bash
py-spy top --pid 12345
```

**Generate Flame Graph:**
```bash
py-spy record -o profile.svg --pid 12345
# Open profile.svg in browser
```

**Profile a Script:**
```bash
py-spy record -o profile.svg -- python script.py
```

**Advantages:**
- No code changes needed
- Attach to running process
- Low overhead (~2%)
- Works with native extensions

**Flame Graph Reading:**
- Width = time spent
- Stack grows upward
- Wide bars at bottom = hot path
- Look for unexpected wide sections
