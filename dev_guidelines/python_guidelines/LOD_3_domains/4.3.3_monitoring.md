## Core Concept
<!-- Lines 17-37 -->

Monitoring answers: "Is the system healthy? How is it performing?" You can't debug what you can't see.

**Observability Pillars:**
- **Metrics**: Numeric measurements over time
- **Logs**: Discrete events with context
- **Traces**: Request flow across services

**Why Monitor:**
- Detect problems before users report them
- Understand system behavior
- Capacity planning
- Post-incident analysis

## Metrics Types
<!-- Lines 40-87 -->

**Counter:** Monotonically increasing value.
```python
from prometheus_client import Counter

REQUEST_COUNT = Counter(
    "http_requests_total",
    "Total HTTP requests",
    ["method", "endpoint", "status"]
)

# Usage
REQUEST_COUNT.labels(method="GET", endpoint="/users", status="200").inc()
```

**Gauge:** Value that can go up or down.
```python
from prometheus_client import Gauge

ACTIVE_CONNECTIONS = Gauge(
    "active_connections",
    "Number of active connections"
)

# Usage
ACTIVE_CONNECTIONS.inc()   # Connection opened
ACTIVE_CONNECTIONS.dec()   # Connection closed
ACTIVE_CONNECTIONS.set(42) # Set absolute value
```

**Histogram:** Distribution of values.
```python
from prometheus_client import Histogram

REQUEST_LATENCY = Histogram(
    "http_request_duration_seconds",
    "HTTP request latency",
    ["endpoint"],
    buckets=[0.01, 0.05, 0.1, 0.5, 1.0, 5.0]
)

# Usage
with REQUEST_LATENCY.labels(endpoint="/users").time():
    process_request()
```

## Prometheus Integration
<!-- Lines 90-144 -->

**Setup:**
```python
from prometheus_client import (
    Counter, Histogram,
    generate_latest, CONTENT_TYPE_LATEST
)
from fastapi import FastAPI, Response

app = FastAPI()

REQUEST_COUNT = Counter(
    "myapp_requests_total",
    "Total requests",
    ["method", "path", "status"]
)

REQUEST_LATENCY = Histogram(
    "myapp_request_duration_seconds",
    "Request latency",
    ["path"]
)

@app.middleware("http")
async def metrics_middleware(request, call_next):
    with REQUEST_LATENCY.labels(path=request.url.path).time():
        response = await call_next(request)
    REQUEST_COUNT.labels(
        method=request.method,
        path=request.url.path,
        status=response.status_code
    ).inc()
    return response

@app.get("/metrics")
def metrics():
    return Response(
        generate_latest(),
        media_type=CONTENT_TYPE_LATEST
    )
```

**Prometheus Scrape Config:**
```yaml
# prometheus.yml
scrape_configs:
  - job_name: 'myapp'
    static_configs:
      - targets: ['myapp:8000']
    metrics_path: /metrics
    scrape_interval: 15s
```

## Golden Signals
<!-- Lines 147-201 -->

Google's four golden signals for monitoring any system:

**1. Latency:** Time to service a request.
```python
REQUEST_LATENCY = Histogram(
    "request_duration_seconds",
    "Request latency by endpoint",
    ["endpoint"],
    buckets=[0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0, 2.5]
)
```

**2. Traffic:** Requests per second.
```python
REQUEST_COUNT = Counter(
    "requests_total",
    "Total requests",
    ["method", "endpoint"]
)
```

**3. Errors:** Rate of failed requests.
```python
ERROR_COUNT = Counter(
    "errors_total",
    "Total errors",
    ["type", "endpoint"]
)

# Track separately or derive from REQUEST_COUNT by status
```

**4. Saturation:** Resource utilization.
```python
QUEUE_SIZE = Gauge(
    "queue_size",
    "Number of items in processing queue"
)

CPU_USAGE = Gauge(
    "cpu_usage_percent",
    "CPU utilization percentage"
)
```

**Alerting Thresholds:**
| Signal | Warning | Critical |
|--------|---------|----------|
| Latency (p99) | >500ms | >2s |
| Error rate | >1% | >5% |
| Saturation | >70% | >90% |

## Dashboards and Alerts

**Grafana Dashboard Elements:**

```

│  Request Rate     │  Error Rate     │  p99   │
│  ████████ 150/s   │  ░░░░ 0.2%      │  45ms  │
├──────────────────────────────────────────────┤
│              Request Latency Histogram       │
│  ▁▂▃▅▆▇█▇▅▃▂▁                               │
├──────────────────────────────────────────────┤
│              Requests by Endpoint            │
│  /api/users:   ███████████ 45%              │
│  /api/orders:  ██████ 25%                   │
│  /api/items:   ████ 18%                     │
└──────────────────────────────────────────────┘
```

**Alert Rules (Prometheus Alertmanager):**
```yaml
groups:
  - name: myapp
    rules:
      - alert: HighErrorRate
        expr: rate(errors_total[5m]) / rate(requests_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"

      - alert: HighLatency
        expr: histogram_quantile(0.99, rate(request_duration_seconds_bucket[5m])) > 2
        for: 5m
        labels:
          severity: warning
```

**Best Practices:**
- Alert on symptoms, not causes
- Set thresholds based on SLOs
- Include runbook links in alerts
- Avoid alert fatigue (too many alerts)
