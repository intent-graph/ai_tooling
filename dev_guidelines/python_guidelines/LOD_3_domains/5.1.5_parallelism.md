## Core Concept
<!-- Lines 17-34 -->

Parallelism runs multiple tasks simultaneously on different CPU cores. Unlike threading, multiprocessing bypasses the GIL by using separate processes.

**Threading vs Multiprocessing:**
| Aspect | Threading | Multiprocessing |
|--------|-----------|-----------------|
| GIL | Constrained | Bypassed |
| Best for | I/O-bound | CPU-bound |
| Memory | Shared | Separate |
| Overhead | Low | High |
| Data passing | Easy | Serialization |

## multiprocessing Module
<!-- Lines 37-75 -->

**Basic Process:**
```python
from multiprocessing import Process

def cpu_intensive(n):
    return sum(i * i for i in range(n))

if __name__ == "__main__":
    p = Process(target=cpu_intensive, args=(10000000,))
    p.start()
    p.join()
```

**Process Pool:**
```python
from multiprocessing import Pool

def process_item(item):
    return heavy_computation(item)

if __name__ == "__main__":
    with Pool(processes=4) as pool:
        results = pool.map(process_item, items)
```

**Pool Methods:**
| Method | Behavior |
|--------|----------|
| `map` | Blocks until all complete |
| `map_async` | Returns AsyncResult immediately |
| `imap` | Iterator, results as ready |
| `apply` | Single call, blocking |
| `apply_async` | Single call, non-blocking |

**IMPORTANT:** Always use `if __name__ == "__main__":` guard on Windows/macOS.

## ProcessPoolExecutor
<!-- Lines 78-114 -->

High-level interface, same API as ThreadPoolExecutor.

```python
from concurrent.futures import ProcessPoolExecutor, as_completed

def cpu_intensive(n):
    return sum(i * i for i in range(n))

if __name__ == "__main__":
    with ProcessPoolExecutor(max_workers=4) as executor:
        futures = [executor.submit(cpu_intensive, n) for n in range(10)]

        for future in as_completed(futures):
            result = future.result()
            print(result)
```

**executor.map:**
```python
with ProcessPoolExecutor() as executor:
    results = list(executor.map(cpu_intensive, range(100)))
```

**Switching Between Thread/Process:**
```python
# Easy to switch
from concurrent.futures import ThreadPoolExecutor  # I/O-bound
from concurrent.futures import ProcessPoolExecutor  # CPU-bound

# Same interface
with Executor(max_workers=4) as executor:
    results = executor.map(func, items)
```

## Data Sharing
<!-- Lines 117-156 -->

Processes have separate memory. Data must be serialized (pickled) to pass between them.

**What Can Be Passed:**
- Built-in types (int, str, list, dict)
- Picklable objects
- NumPy arrays

**What Cannot Be Passed:**
- Lambda functions
- Open file handles
- Database connections
- Most locks

**Shared Memory (large data):**
```python
from multiprocessing import shared_memory
import numpy as np

# Create shared array
shm = shared_memory.SharedMemory(create=True, size=1000000)
arr = np.ndarray((1000, 1000), dtype=np.float64, buffer=shm.buf)

# In worker process
existing_shm = shared_memory.SharedMemory(name=shm.name)
arr = np.ndarray((1000, 1000), dtype=np.float64, buffer=existing_shm.buf)
```

**Manager (shared state):**
```python
from multiprocessing import Manager

with Manager() as manager:
    shared_dict = manager.dict()
    shared_list = manager.list()
    # Workers can modify these
```

## When to Use
<!-- Lines 159-195 -->

**Use Multiprocessing When:**
- CPU-bound work (computation, not waiting)
- Work is parallelizable (independent tasks)
- Overhead is acceptable (process creation ~100ms)
- Data can be serialized efficiently

**Don't Use When:**
- I/O-bound (use threading or async)
- Tasks are too small (overhead dominates)
- Heavy data sharing needed
- Simple sequential code is fast enough

**Overhead Considerations:**
```python
# Bad: Too fine-grained
# Process creation overhead >> computation time
with Pool(4) as p:
    results = p.map(lambda x: x + 1, range(1000))

# Good: Batch work
def process_batch(batch):
    return [heavy_compute(x) for x in batch]

batches = [items[i:i+100] for i in range(0, len(items), 100)]
with Pool(4) as p:
    results = p.map(process_batch, batches)
```

**joblib (easier for scientific computing):**
```python
from joblib import Parallel, delayed

results = Parallel(n_jobs=4)(
    delayed(process)(item) for item in items
)
```
