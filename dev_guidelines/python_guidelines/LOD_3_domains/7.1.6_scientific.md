## Core Concept
<!-- Lines 33-52 -->

**Definition:** Scientific computing uses Python for data analysis, numerical computation, machine learning, and research. It emphasizes correctness, reproducibility, and exploratory workflows.

**Key Priorities:**
1. Correctness (wrong results are useless)
2. Reproducibility (others can verify)
3. Performance (often large datasets)
4. Exploration (iterative discovery)

**Unique Challenges:**
- Notebooks encourage bad habits
- Data science ≠ software engineering (different skills)
- Research code often becomes production code
- Results must be reproducible

### NumPy (Foundation)
<!-- Lines 58-75 -->

```python
import numpy as np

# Vectorized operations (fast)
a = np.array([1, 2, 3, 4])
b = a * 2  # [2, 4, 6, 8]

# Matrix operations
matrix = np.array([[1, 2], [3, 4]])
result = np.dot(matrix, matrix.T)

# Broadcasting
x = np.array([[1], [2], [3]])  # (3, 1)
y = np.array([1, 2, 3])         # (3,)
z = x + y  # (3, 3) - broadcasting!
```

### pandas (Data Manipulation)
<!-- Lines 78-102 -->

```python
import pandas as pd

# Read data
df = pd.read_csv("data.csv")

# Clean
df = df.dropna(subset=["required_col"])
df["date"] = pd.to_datetime(df["date"])

# Transform
df["year"] = df["date"].dt.year
result = df.groupby("year")["value"].mean()

# Method chaining
result = (
    df
    .query("status == 'active'")
    .groupby("category")
    .agg({"value": "sum", "count": "size"})
    .reset_index()
)
```

### Data Versioning
<!-- Lines 280-293 -->

```python
# Hash data for verification
import hashlib

def data_hash(df):
    return hashlib.md5(
        pd.util.hash_pandas_object(df).values
    ).hexdigest()

# Log hash with results
print(f"Data version: {data_hash(df)}")
```
