## Core Concept
<!-- Lines 31-55 -->

**Definition:** Libraries are packages designed for import and use by other codebases. They differ from applications in their audience (developers) and constraints (stability, compatibility).

**Library vs Application:**
| Aspect | Library | Application |
|--------|---------|-------------|
| User | Developers | End users |
| Change tolerance | Low | Higher |
| Dependencies | Minimal | As needed |
| Python versions | Wide support | Can be specific |
| Breaking changes | Major versions only | Anytime |

**Key Priorities:**
1. API stability
2. Clear documentation
3. Minimal dependencies
4. Excellent error messages
5. Type annotations

### Principle of Least Surprise
<!-- Lines 79-95 -->

```python
# Bad: Surprising behavior
def get_user(id):
    """Get user by ID. Creates if not found."""  # Unexpected!
    ...

# Good: Explicit behavior
def get_user(id) -> User | None:
    """Get user by ID. Returns None if not found."""
    ...

def get_or_create_user(id) -> User:
    """Get user by ID, creating if necessary."""
    ...
```

### Type Hints for Public API
<!-- Lines 98-122 -->

```python
from typing import Sequence, TypeVar

T = TypeVar("T")

def first(items: Sequence[T], *, default: T | None = None) -> T | None:
    """Return first item or default if empty.

    Args:
        items: Sequence to get first item from.
        default: Value to return if items is empty.

    Returns:
        First item or default.

    Example:
        >>> first([1, 2, 3])
        1
        >>> first([], default=0)
        0
    """
    return items[0] if items else default
```

<!-- Lines 125-136 -->


### Dependency Minimization
<!-- Lines 174-187 -->

```python
# Bad: Heavy dependency for one function
import pandas as pd

def get_names(data):
    df = pd.DataFrame(data)
    return df["name"].tolist()

# Good: Use standard library when possible
def get_names(data: list[dict]) -> list[str]:
    return [item["name"] for item in data]
```

```python
# Graceful feature detection
try:
    import pandas as pd
    HAS_PANDAS = True
except ImportError:
    HAS_PANDAS = False

def to_dataframe(data):
    if not HAS_PANDAS:
        raise ImportError(
            "pandas is required for to_dataframe(). "
            "Install with: pip install mylib[pandas]"
        )
    return pd.DataFrame(data)
```

### CI/CD for Libraries
<!-- Lines 293-312 -->

```yaml
# .github/workflows/publish.yml
on:
  release:
    types: [published]

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - run: pip install build twine
      - run: python -m build
      - run: twine upload dist/*
        env:
          TWINE_USERNAME: __token__
          TWINE_PASSWORD: ${{ secrets.PYPI_TOKEN }}
```
