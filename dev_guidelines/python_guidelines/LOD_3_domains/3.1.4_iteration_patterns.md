## Pattern Selection
<!-- Lines 16-47 -->

Python offers multiple iteration approaches. Choose based on readability and memory needs.

**Decision Matrix:**

| Pattern | Use When | Memory |
|---------|----------|--------|
| `for` loop | Complex logic, side effects | Eager |
| List comp | Simple transform + filter | Eager |
| Generator expr | Large data, pipeline | Lazy |
| `map`/`filter` | Functional composition | Lazy |

**Selection Flowchart:**
```
Need to iterate?
├── Complex logic or side effects?
│   └── Use for loop
├── Simple transform/filter?
│   ├── Need list result?
│   │   └── List comprehension
│   └── Only iterating once?
│       └── Generator expression
└── Processing large/infinite data?
    └── Generator
```

## For Loops
<!-- Lines 50-103 -->

Use `for` loops when logic is complex or you need index access.

**Basic Pattern:**
```python
for item in items:
    process(item)
```

**With Index:**
```python
for i, item in enumerate(items):
    print(f"{i}: {item}")
```

**Multiple Iterables:**
```python
for name, score in zip(names, scores):
    print(f"{name}: {score}")

# With strict length check (Python 3.10+)
for name, score in zip(names, scores, strict=True):
    ...
```

**Loop Control:**
```python
for item in items:
    if should_skip(item):
        continue
    if should_stop(item):
        break
    process(item)
else:
    # Runs if loop completes without break
    print("All items processed")
```

**Avoid:**
```python
# BAD: Manual indexing
for i in range(len(items)):
    process(items[i])

# GOOD: Iterate directly
for item in items:
    process(item)
```

## Comprehensions
<!-- Lines 106-163 -->

Comprehensions provide concise syntax for building collections.

**List Comprehension:**
```python
# Transform
squares = [x ** 2 for x in numbers]

# Filter
evens = [x for x in numbers if x % 2 == 0]

# Transform + Filter
even_squares = [x ** 2 for x in numbers if x % 2 == 0]
```

**Dict Comprehension:**
```python
# From pairs
scores = {name: score for name, score in pairs}

# Transform keys/values
upper_scores = {k.upper(): v for k, v in scores.items()}
```

**Set Comprehension:**
```python
unique_lengths = {len(word) for word in words}
```

**Readability Guidelines:**
```python
# GOOD: Simple, readable
names = [user.name for user in users if user.active]

# BAD: Too complex
result = [
    transform(x)
    for x in items
    if condition1(x)
    for y in nested(x)
    if condition2(y)
]

# Better: Use loop for complex logic
result = []
for x in items:
    if not condition1(x):
        continue
    for y in nested(x):
        if condition2(y):
            result.append(transform(x))
```

## Generators
<!-- Lines 166-221 -->

Generators produce values lazily, enabling memory-efficient processing of large datasets.

**Generator Expression:**
```python
# Like list comp but lazy
squares = (x ** 2 for x in range(1_000_000))
# Memory: O(1), not O(n)

# Use in functions that accept iterables
total = sum(x ** 2 for x in numbers)
```

**Generator Function:**
```python
def read_large_file(path: str) -> Iterator[str]:
    """Yield lines without loading entire file."""
    with open(path) as f:
        for line in f:
            yield line.strip()

# Process line by line
for line in read_large_file("huge.txt"):
    process(line)
```

**yield from:**
```python
def flatten(nested: list[list[T]]) -> Iterator[T]:
    for inner in nested:
        yield from inner

# Equivalent to:
# for item in inner:
#     yield item
```

**When to Use Generators:**
- Processing large files
- Infinite sequences
- Pipeline processing
- Memory-constrained environments

**Generator Gotcha:**
```python
# Generators exhaust after one iteration
gen = (x for x in range(3))
list(gen)  # [0, 1, 2]
list(gen)  # [] - already exhausted!

# If you need multiple iterations, use list
items = list(x for x in range(3))
```
