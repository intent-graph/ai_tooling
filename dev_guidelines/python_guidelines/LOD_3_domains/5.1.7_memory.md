## Core Concept
<!-- Lines 18-32 -->

Python manages memory automatically via reference counting and garbage collection. Understanding memory usage helps avoid issues in memory-constrained environments or when processing large data.

**Memory Categories:**
- **Object overhead**: Every object has ~28 bytes overhead
- **Container overhead**: Lists, dicts have additional overhead
- **Reference counting**: Each reference adds tracking
- **Fragmentation**: Memory not returned to OS

## Generators
<!-- Lines 35-87 -->

Generators produce values on-demand instead of storing all in memory.

**List vs Generator:**
```python
# List: All in memory at once
numbers = [x * 2 for x in range(10_000_000)]  # ~80MB

# Generator: One at a time
numbers = (x * 2 for x in range(10_000_000))  # ~100 bytes
```

**File Processing:**
```python
# Bad: Loads entire file
lines = open('huge.txt').readlines()
for line in lines:
    process(line)

# Good: Streams line by line
for line in open('huge.txt'):
    process(line)
```

**Generator Function:**
```python
def read_large_file(path):
    with open(path) as f:
        for line in f:
            yield process_line(line)

# Memory-efficient processing
for item in read_large_file('huge.txt'):
    handle(item)
```

**Chaining Generators:**
```python
def filter_valid(items):
    for item in items:
        if is_valid(item):
            yield item

def transform(items):
    for item in items:
        yield expensive_transform(item)

# Lazy pipeline
result = transform(filter_valid(raw_data))
```

## __slots__
<!-- Lines 90-137 -->

`__slots__` prevents `__dict__` creation, reducing memory per instance.

**Without slots:**
```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

# Each instance: ~300 bytes
```

**With slots:**
```python
class Point:
    __slots__ = ('x', 'y')

    def __init__(self, x, y):
        self.x = x
        self.y = y

# Each instance: ~70 bytes (~75% reduction)
```

**When to Use:**
- Many instances (100,000+)
- Fixed attributes
- Memory-constrained
- Performance-critical inner loops

**Limitations:**
- Cannot add attributes dynamically
- Cannot use `__dict__`
- Inheritance requires care

**Dataclass with slots:**
```python
from dataclasses import dataclass

@dataclass(slots=True)
class Point:
    x: float
    y: float
```

**sys.getsizeof:**

```python
import sys

x = [1, 2, 3]
sys.getsizeof(x)  # Size of list object, not contents
```

**memory_profiler:**

```bash
pip install memory_profiler
```

```python
from memory_profiler import profile

@profile
def memory_heavy():
    data = [x for x in range(1000000)]
    return sum(data)
```

**tracemalloc (built-in):**
```python
import tracemalloc

tracemalloc.start()

# Code to measure
data = [x for x in range(1000000)]

snapshot = tracemalloc.take_snapshot()
top_stats = snapshot.statistics('lineno')

for stat in top_stats[:10]:
    print(stat)
```

**objgraph (reference tracking):**
```python

objgraph.show_most_common_types(limit=10)
objgraph.show_growth()  # New objects since last call
```

## Common Issues
<!-- Lines 191-254 -->

**Unbounded Caches:**
```python
# Problem: Cache grows forever
cache = {}
def cached_compute(key):
    if key not in cache:
        cache[key] = expensive(key)
    return cache[key]

# Solution: Bounded cache
from functools import lru_cache

@lru_cache(maxsize=1000)
def cached_compute(key):
    return expensive(key)
```

**String Concatenation:**
```python
# Bad: Creates many intermediate strings
result = ""
for item in items:
    result += str(item)  # O(n²) memory allocations

# Good: Join once
result = "".join(str(item) for item in items)
```

**Circular References:**
```python
class Node:
    def __init__(self):
        self.children = []
        self.parent = None

# Circular reference (a.parent = b, b.children = [a])
# Usually handled by GC, but can delay cleanup

# Solution: Weak references
import weakref

class Node:
    def __init__(self):
        self.children = []
        self._parent = None

    @property
    def parent(self):
        return self._parent() if self._parent else None

    @parent.setter
    def parent(self, node):
        self._parent = weakref.ref(node) if node else None
```

**Large Intermediate Results:**
```python
# Bad: Creates large intermediate list
result = sum([x * 2 for x in range(10_000_000)])

# Good: Generator expression
result = sum(x * 2 for x in range(10_000_000))
```
