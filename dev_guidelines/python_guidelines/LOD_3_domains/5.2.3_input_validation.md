## Core Concept
<!-- Lines 17-34 -->

All external input is untrusted. This includes:
- HTTP request parameters
- Form data
- File uploads
- API payloads
- Database results
- Environment variables
- Command-line arguments

**Validation Principle:** Validate as early as possible, reject invalid input.

## Validation Layers
<!-- Lines 37-81 -->

**1. Syntactic Validation:** Is the format correct?
```python
# Is this a valid email format?
import re
EMAIL_PATTERN = re.compile(r'^[\w\.-]+@[\w\.-]+\.\w+$')

def is_valid_email(email: str) -> bool:
    return bool(EMAIL_PATTERN.match(email))
```

**2. Semantic Validation:** Is the value sensible?
```python
def validate_age(age: int) -> int:
    if not 0 <= age <= 150:
        raise ValueError("Age must be between 0 and 150")
    return age
```

**3. Authorization Validation:** Is user allowed this value?
```python
def validate_user_access(user_id: int, resource_id: int) -> bool:
    resource = Resource.get(resource_id)
    return resource.owner_id == user_id
```

**Fail Closed:**
```python
# Bad: Fail open
def get_user_role(user):
    try:
        return user.role
    except:
        return "admin"  # Dangerous default!

# Good: Fail closed
def get_user_role(user):
    try:
        return user.role
    except:
        return "guest"  # Safe default
```

## Pydantic Validation
<!-- Lines 84-133 -->

Pydantic provides robust input validation.

**Basic Validation:**
```python
from pydantic import BaseModel, EmailStr, conint, constr

class UserCreate(BaseModel):
    email: EmailStr
    username: constr(min_length=3, max_length=20, pattern=r'^[a-z0-9_]+$')
    age: conint(ge=0, le=150)
```

**Custom Validators:**
```python
from pydantic import BaseModel, field_validator

class Order(BaseModel):
    quantity: int
    price: float

    @field_validator('quantity')
    @classmethod
    def quantity_positive(cls, v):
        if v <= 0:
            raise ValueError('Quantity must be positive')
        return v

    @field_validator('price')
    @classmethod
    def price_reasonable(cls, v):
        if not 0.01 <= v <= 1000000:
            raise ValueError('Price out of range')
        return v
```

**Usage with FastAPI:**
```python
from fastapi import FastAPI

app = FastAPI()

@app.post("/users")
def create_user(user: UserCreate):
    # user is already validated
    return {"email": user.email}
```

## Allowlists
<!-- Lines 136-178 -->

**Allowlist > Denylist:**
```python
# Bad: Trying to block bad inputs (incomplete)
FORBIDDEN_CHARS = ['<', '>', '"', "'", '&']
def sanitize(text):
    for char in FORBIDDEN_CHARS:
        text = text.replace(char, '')
    return text  # Misses many attack vectors

# Good: Allow only known-good
ALLOWED_CHARS = set('abcdefghijklmnopqrstuvwxyz0123456789-_')
def validate_username(username: str) -> str:
    if not all(c in ALLOWED_CHARS for c in username.lower()):
        raise ValueError("Invalid characters in username")
    return username
```

**Enum Validation:**
```python
from enum import Enum
from pydantic import BaseModel

class Status(str, Enum):
    pending = "pending"
    approved = "approved"
    rejected = "rejected"

class Order(BaseModel):
    status: Status  # Only allows enum values
```

**File Extension Validation:**
```python
ALLOWED_EXTENSIONS = {'.jpg', '.jpeg', '.png', '.gif'}

def validate_image(filename: str) -> bool:
    ext = Path(filename).suffix.lower()
    return ext in ALLOWED_EXTENSIONS
```

## Context-Specific Escaping
<!-- Lines 181-231 -->

Different contexts need different escaping.

**HTML Context:**
```python
from markupsafe import escape

user_input = "<script>alert('xss')</script>"
safe_html = escape(user_input)
# &lt;script&gt;alert(&#39;xss&#39;)&lt;/script&gt;
```

**SQL Context:**
```python
# NEVER string formatting
query = f"SELECT * FROM users WHERE name = '{name}'"  # SQL injection!

# ALWAYS parameterized queries
cursor.execute("SELECT * FROM users WHERE name = %s", (name,))
```

**Shell Context:**
```python
import subprocess
import shlex

# NEVER shell=True with user input
subprocess.run(f"echo {user_input}", shell=True)  # Command injection!

# ALWAYS list form or shlex.quote
subprocess.run(["echo", user_input])
# Or if shell needed:
subprocess.run(f"echo {shlex.quote(user_input)}", shell=True)
```

**URL Context:**
```python
from urllib.parse import quote

user_input = "value with spaces & special=chars"
safe_url = f"https://api.example.com?q={quote(user_input)}"
```

**JSON Context:**
```python
import json

# json.dumps handles escaping
data = {"user_input": "<script>"}
safe_json = json.dumps(data)  # Properly escaped
```
