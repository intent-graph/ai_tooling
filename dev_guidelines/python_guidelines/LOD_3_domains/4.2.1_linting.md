## Core Concept
<!-- Lines 17-32 -->

Linting analyzes code without executing it. It catches:
- Syntax errors
- Undefined names
- Unused imports/variables
- Style violations
- Common bug patterns

Ruff has become the standard linter—it's 10-100x faster than alternatives and consolidates functionality from flake8, isort, pyupgrade, and many plugins.

## Ruff Configuration
<!-- Lines 35-87 -->

```toml
[tool.ruff]
# Target Python version
target-version = "py310"

# Line length (match Black)
line-length = 88

# Files to exclude
exclude = [
    ".git",
    ".venv",
    "__pycache__",
    "build",
    "dist",
]

[tool.ruff.lint]
# Enable rule sets
select = [
    "E",      # pycodestyle errors
    "W",      # pycodestyle warnings
    "F",      # Pyflakes
    "I",      # isort
    "B",      # flake8-bugbear
    "UP",     # pyupgrade
    "SIM",    # flake8-simplify
    "PTH",    # flake8-use-pathlib
]

# Ignore specific rules
ignore = [
    "E501",   # Line length (handled by formatter)
]

# Auto-fixable rules
fixable = ["ALL"]

[tool.ruff.lint.isort]
known-first-party = ["mypackage"]
force-single-line = false
```

**Running Ruff:**
```bash
ruff check .           # Check all files
ruff check --fix .     # Auto-fix issues
ruff check --watch .   # Watch mode
```

## Rule Selection
<!-- Lines 90-122 -->

**Rule Prefixes:**
| Prefix | Source | Purpose |
|--------|--------|---------|
| `E/W` | pycodestyle | PEP 8 style |
| `F` | Pyflakes | Logic errors |
| `I` | isort | Import sorting |
| `B` | flake8-bugbear | Bug-prone patterns |
| `UP` | pyupgrade | Modern Python syntax |
| `SIM` | flake8-simplify | Simplifications |
| `PTH` | flake8-use-pathlib | Use pathlib |
| `RUF` | Ruff-specific | Ruff's own rules |
| `S` | flake8-bandit | Security |
| `N` | pep8-naming | Naming conventions |

**Recommended Starter Set:**
```toml
select = ["E", "F", "I", "B", "UP"]
```

**Progressive Expansion:**
```toml
# Start minimal
select = ["E", "F"]

# Add as you fix existing violations
select = ["E", "F", "I"]  # + import sorting
select = ["E", "F", "I", "B"]  # + bugbear
select = ["E", "F", "I", "B", "UP", "SIM"]  # + upgrades, simplify
```

## Ignoring Rules
<!-- Lines 125-155 -->

**Per-file Ignores:**
```toml
[tool.ruff.lint.per-file-ignores]
"tests/*" = ["S101"]  # Allow assert in tests
"__init__.py" = ["F401"]  # Allow unused imports
```

**Inline Ignores:**
```python
# Ignore single rule
x = eval(data)  # noqa: S307

# Ignore multiple rules
x = eval(data)  # noqa: S307, B008

# Ignore with explanation (preferred)
x = eval(trusted_data)  # noqa: S307 - Data from internal config only
```

**When to Ignore:**
- False positives from linter
- Intentional patterns (e.g., `assert` in tests)
- Legacy code with explicit tech debt tracking

**When NOT to Ignore:**
- Inconvenient rules (fix the code instead)
- All files (configure properly instead)

## Migration
<!-- Lines 158-187 -->

**From flake8:**
```bash
# Generate Ruff config from flake8
ruff check --show-settings > ruff_settings.toml

# Common mappings
# flake8-isort → I
# flake8-bugbear → B
# flake8-comprehensions → C4
```

**Handling Existing Violations:**
```bash
# See all current violations
ruff check . --statistics

# Fix auto-fixable
ruff check --fix .

# Generate baseline (ignore existing)
ruff check . --output-format=json > baseline.json
```

**Gradual Rollout:**
1. Enable `E`, `F` only
2. Fix violations or add per-file ignores
3. Add rule sets one at a time
4. Run `--fix` liberally
5. Add to pre-commit and CI
