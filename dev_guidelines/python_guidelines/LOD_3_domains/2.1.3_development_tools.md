## Package Managers
<!-- Lines 16-53 -->

Package managers handle dependency installation, resolution, and locking. Choose based on speed requirements and project complexity.

**Tool Comparison:**

| Tool | Speed | Lock Files | Best For |
|------|-------|------------|----------|
| pip | Baseline | Manual | Simple projects |
| uv | 10-100x faster | Native | Most projects |
| poetry | Moderate | Native | Full project management |
| pdm | Fast | Native | PEP-compliant workflows |

**Recommendation Hierarchy:**
1. **uv** — Fast, modern, drop-in pip replacement
2. **pip** — Universal fallback, always available
3. **poetry** — When you need full project lifecycle management

**Lock Files:**
Lock files pin exact versions for reproducible installs.

```bash
# pip approach
pip freeze > requirements.txt

# uv approach (recommended)
uv pip compile pyproject.toml -o requirements.lock

# poetry approach
poetry lock
```

## uv
<!-- Lines 56-105 -->

uv is a fast Python package manager written in Rust. Use it for significant speed improvements over pip.

**Installation:**
```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Or via pip (slower)
pip install uv
```

**Basic Usage:**
```bash
# Create venv (optional, uv can auto-create)
uv venv

# Install package
uv pip install httpx

# Install from pyproject.toml
uv pip install -e ".[dev]"

# Compile lock file
uv pip compile pyproject.toml -o requirements.lock

# Install from lock file
uv pip sync requirements.lock
```

**Speed Comparison:**
```
pip install numpy pandas scipy
# ~30 seconds

uv pip install numpy pandas scipy
# ~3 seconds
```

**Why uv:**
- 10-100x faster than pip
- Built-in lock file support
- Drop-in pip replacement
- Active development

## pip
<!-- Lines 108-158 -->

pip is Python's default package installer. It's always available but slower than modern alternatives.

**Basic Usage:**
```bash
# Install package
pip install httpx

# Install specific version
pip install httpx==0.24.1

# Install from requirements
pip install -r requirements.txt

# Install in editable mode
pip install -e .

# With optional dependencies
pip install -e ".[dev]"
```

**Useful Options:**
```bash
# Upgrade package
pip install --upgrade httpx

# Install without cache (clean)
pip install --no-cache-dir httpx

# Show package info
pip show httpx

# List installed packages
pip list
```

**Constraints File:**
```bash
# constraints.txt - pin transitive dependencies
numpy==1.26.4
pandas==2.2.0

# Use with install
pip install -c constraints.txt mypackage
```

## Development Utilities
<!-- Lines 161-207 -->

Install development tools globally with pipx to avoid polluting project environments.

**pipx — Isolated Tool Installation:**
```bash
# Install pipx
pip install --user pipx
pipx ensurepath

# Install tools
pipx install ruff
pipx install mypy
pipx install pre-commit
pipx install tox
```

**Essential Tools:**

| Tool | Purpose | Install |
|------|---------|---------|
| ruff | Lint + format | `pipx install ruff` |
| mypy | Type checking | `pipx install mypy` |
| pre-commit | Git hooks | `pipx install pre-commit` |
| tox | Multi-env testing | `pipx install tox` |
| build | Package building | `pipx install build` |
| twine | PyPI upload | `pipx install twine` |

**Project Setup Script:**
```bash
#!/bin/bash
# scripts/setup.sh

# Create environment
python -m venv .venv
source .venv/bin/activate

# Install dependencies
uv pip install -e ".[dev]"

# Setup pre-commit
pre-commit install

echo "Development environment ready!"
```
