## Core Concept
<!-- Lines 17-36 -->

Configuration varies between environments: database URLs, API keys, feature flags, log levels. The 12-Factor App principle: store configuration in environment variables.

**Why Environment Variables:**
- Language and OS agnostic
- Easy to change between deploys
- Can't be accidentally committed to version control
- Supported by all deployment platforms

**Configuration Hierarchy:**
1. Environment variables (highest priority)
2. `.env` files (development)
3. Default values in code (lowest priority)

## Environment Variables
<!-- Lines 39-91 -->

**Reading Environment Variables:**
```python
import os

# Basic read
database_url = os.environ["DATABASE_URL"]

# With default
debug = os.environ.get("DEBUG", "false").lower() == "true"

# Required with clear error
api_key = os.environ.get("API_KEY")
if not api_key:
    raise ValueError("API_KEY environment variable required")
```

**Naming Conventions:**
```bash
# Prefix with app name
MYAPP_DATABASE_URL
MYAPP_API_KEY
MYAPP_DEBUG

# Common patterns
DATABASE_URL       # Connection string
LOG_LEVEL         # Logging verbosity
SECRET_KEY        # Cryptographic key
```

**.env Files (development only):**
```bash
# .env
DATABASE_URL=postgresql://localhost/myapp
API_KEY=dev-key-not-for-production
DEBUG=true
```

```python
# Load .env file
from dotenv import load_dotenv
load_dotenv()  # Reads .env into os.environ
```

**Add to .gitignore:**
```
.env
.env.local
*.env
```

## Configuration Libraries
<!-- Lines 94-135 -->

**pydantic-settings (recommended):**
```python
from pydantic_settings import BaseSettings
from pydantic import Field

class Settings(BaseSettings):
    database_url: str
    api_key: str
    debug: bool = False
    log_level: str = "INFO"

    model_config = {
        "env_prefix": "MYAPP_",
        "env_file": ".env",
    }

settings = Settings()
# Reads MYAPP_DATABASE_URL, MYAPP_API_KEY, etc.
```

**Benefits:**
- Type validation
- Clear defaults
- Documentation via type hints
- Automatic .env loading

**Nested Configuration:**
```python
class DatabaseSettings(BaseSettings):
    host: str = "localhost"
    port: int = 5432
    name: str = "myapp"

    model_config = {"env_prefix": "DB_"}

class Settings(BaseSettings):
    database: DatabaseSettings = DatabaseSettings()
```

## Secrets Management
<!-- Lines 138-181 -->

Secrets require extra care—they must never appear in logs, errors, or version control.

**Development:**
```bash
# .env (local only, gitignored)
DATABASE_PASSWORD=localpassword
API_SECRET=devsecret
```

**Production Options:**
| Solution | When to Use |
|----------|-------------|
| Environment variables | Simple deployments |
| AWS Secrets Manager | AWS infrastructure |
| HashiCorp Vault | Multi-cloud, complex needs |
| Kubernetes Secrets | Kubernetes deployments |

**Secrets Manager Pattern:**
```python
import boto3

def get_secret(secret_name: str) -> str:
    client = boto3.client("secretsmanager")
    response = client.get_secret_value(SecretId=secret_name)
    return response["SecretString"]

# Use in settings
class Settings(BaseSettings):
    @property
    def db_password(self) -> str:
        if os.environ.get("AWS_EXECUTION_ENV"):
            return get_secret("myapp/db_password")
        return os.environ["DB_PASSWORD"]
```

**Secret Hygiene:**
- Rotate secrets regularly
- Use different secrets per environment
- Never log secrets
- Audit access to secrets

## Environment Parity
<!-- Lines 184-226 -->

Keep development, staging, and production as similar as possible.

**12-Factor Principle:**
Development should closely mirror production:
- Same database (PostgreSQL, not SQLite)
- Same cache (Redis, not in-memory dict)
- Same queue system

**Configuration per Environment:**
```python
class Settings(BaseSettings):
    environment: str = "development"

    @property
    def is_production(self) -> bool:
        return self.environment == "production"

# Environment-specific behavior
if settings.is_production:
    logging.config.dictConfig(production_logging)
else:
    logging.basicConfig(level=logging.DEBUG)
```

**Feature Flags:**
```python
class Settings(BaseSettings):
    feature_new_ui: bool = False
    feature_beta_api: bool = False

# Usage
if settings.feature_new_ui:
    return render_new_ui()
return render_classic_ui()
```

**Environment Matrix:**
| Setting | Dev | Staging | Prod |
|---------|-----|---------|------|
| DEBUG | true | false | false |
| LOG_LEVEL | DEBUG | INFO | WARNING |
| DATABASE | local | staging-db | prod-db |
