## Core Concept
<!-- Lines 17-34 -->

Health checks let orchestrators (Kubernetes, Docker Swarm, load balancers) know if your application is functioning. They enable:

- Automatic restart of unhealthy containers
- Traffic routing only to healthy instances
- Graceful rolling deployments
- Self-healing infrastructure

**Types:**
- **Liveness**: Is the process alive? If not, restart it.
- **Readiness**: Can it serve traffic? If not, remove from load balancer.
- **Startup**: Has it finished initializing?

## Liveness vs Readiness
<!-- Lines 37-66 -->

**Liveness Probe:**
"Should I restart this container?"

Check if the process is alive and not deadlocked:
- Simple HTTP 200 response
- Should almost always pass
- Only fail if restart would help

**Readiness Probe:**
"Should I send traffic to this container?"

Check if the application can serve requests:
- Database connection working
- Cache accessible
- Required services available

**Comparison:**
| Aspect | Liveness | Readiness |
|--------|----------|-----------|
| Failure action | Restart container | Remove from service |
| Check frequency | Less often (30s) | More often (10s) |
| Dependencies | None | External services |
| Strictness | Lenient | Strict |

**Common Mistake:**
Don't check external dependencies in liveness probes. If the database is down, restarting your app won't fix it.

## Implementation
<!-- Lines 69-125 -->

**FastAPI Implementation:**
```python
from fastapi import FastAPI, status
from fastapi.responses import JSONResponse

app = FastAPI()

@app.get("/health/live")
def liveness():
    """Liveness: Is the process running?"""
    return {"status": "alive"}

@app.get("/health/ready")
async def readiness():
    """Readiness: Can we handle requests?"""
    checks = {}

    # Check database
    try:
        await db.execute("SELECT 1")
        checks["database"] = "ok"
    except Exception as e:
        checks["database"] = str(e)

    # Check cache
    try:
        await cache.ping()
        checks["cache"] = "ok"
    except Exception as e:
        checks["cache"] = str(e)

    # All checks must pass
    all_ok = all(v == "ok" for v in checks.values())

    if all_ok:
        return {"status": "ready", "checks": checks}

    return JSONResponse(
        {"status": "not_ready", "checks": checks},
        status_code=status.HTTP_503_SERVICE_UNAVAILABLE
    )
```

**Health Check Response:**
```json
{
  "status": "ready",
  "checks": {
    "database": "ok",
    "cache": "ok"
  }
}
```

## Kubernetes Configuration
<!-- Lines 128-178 -->

```yaml
apiVersion: apps/v1
kind: Deployment
spec:
  template:
    spec:
      containers:
        - name: myapp
          image: myapp:latest
          ports:
            - containerPort: 8000

          startupProbe:
            httpGet:
              path: /health/live
              port: 8000
            initialDelaySeconds: 5
            periodSeconds: 5
            failureThreshold: 30  # 5s × 30 = 150s max startup

          livenessProbe:
            httpGet:
              path: /health/live
              port: 8000
            initialDelaySeconds: 0  # After startup probe passes
            periodSeconds: 30
            timeoutSeconds: 5
            failureThreshold: 3

          readinessProbe:
            httpGet:
              path: /health/ready
              port: 8000
            initialDelaySeconds: 0
            periodSeconds: 10
            timeoutSeconds: 5
            failureThreshold: 3
```

**Probe Parameters:**
| Parameter | Purpose |
|-----------|---------|
| `initialDelaySeconds` | Wait before first probe |
| `periodSeconds` | Time between probes |
| `timeoutSeconds` | Probe timeout |
| `failureThreshold` | Failures before action |
| `successThreshold` | Successes to recover |

## Best Practices
<!-- Lines 181-224 -->

**Do:**
- Keep health checks fast (<1 second)
- Return immediately (no blocking operations)
- Include dependency checks in readiness only
- Log health check failures
- Use startup probes for slow-starting apps

**Don't:**
- Check transient external services in liveness
- Make health checks do heavy work
- Return 500 for expected conditions
- Cache health check results too long

**Structured Health Response:**
```python
@app.get("/health")
def comprehensive_health():
    return {
        "status": "healthy",
        "version": __version__,
        "uptime_seconds": get_uptime(),
        "checks": {
            "database": {"status": "ok", "latency_ms": 5},
            "cache": {"status": "ok", "latency_ms": 1},
            "queue": {"status": "ok", "depth": 42}
        }
    }
```

**Graceful Shutdown:**
```python
import signal

def shutdown_handler(signum, frame):
    # Mark as not ready
    app.state.ready = False
    # Wait for in-flight requests
    time.sleep(10)
    # Exit
    sys.exit(0)

signal.signal(signal.SIGTERM, shutdown_handler)
```
