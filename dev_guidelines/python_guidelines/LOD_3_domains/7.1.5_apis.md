## Core Concept
<!-- Lines 29-51 -->

**Definition:** APIs (Application Programming Interfaces) expose functionality over HTTP for programmatic clients—mobile apps, web frontends, other services.

**REST Principles:**
- Resources identified by URLs
- Operations via HTTP methods (GET, POST, PUT, DELETE)
- Stateless requests
- Standard status codes

**Key Concerns:**
- Consistent request/response format
- Authentication and authorization
- Rate limiting
- Versioning
- Error handling
- Documentation

## Framework Comparison
<!-- Lines 54-54 -->

### FastAPI (Recommended for New APIs)
<!-- Lines 57-87 -->

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI(title="User API", version="1.0.0")

class User(BaseModel):
    id: int
    name: str
    email: str

class UserCreate(BaseModel):
    name: str
    email: str

@app.get("/users/{user_id}", response_model=User)
async def get_user(user_id: int):
    user = await db.get_user(user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    return user

@app.post("/users", response_model=User, status_code=201)
async def create_user(user: UserCreate):
    return await db.create_user(user.name, user.email)
```

**Pros:** Auto-docs, validation, async, type safety
**Cons:** Async-first (can be sync)

### Django REST Framework
<!-- Lines 90-107 -->

```python
from rest_framework import viewsets, serializers
from .models import User

class UserSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = ["id", "name", "email"]

class UserViewSet(viewsets.ModelViewSet):
    queryset = User.objects.all()
    serializer_class = UserSerializer
```

**Pros:** Django integration, batteries-included
**Cons:** Tied to Django

### Flask + Marshmallow
<!-- Lines 110-134 -->

```python
from flask import Flask, jsonify, request
from marshmallow import Schema, fields

app = Flask(__name__)

class UserSchema(Schema):
    id = fields.Int(dump_only=True)
    name = fields.Str(required=True)
    email = fields.Email(required=True)

@app.route("/users/<int:user_id>")
def get_user(user_id):
    user = db.get_user(user_id)
    if not user:
        return jsonify({"error": "Not found"}), 404
    return UserSchema().dump(user)
```

**Pros:** Flexible, gradual adoption
**Cons:** Manual wiring

### URL Structure
<!-- Lines 140-156 -->

```python
# Resources as nouns, actions via HTTP methods
GET    /users          # List users
POST   /users          # Create user
GET    /users/{id}     # Get user
PUT    /users/{id}     # Update user
DELETE /users/{id}     # Delete user

# Nested resources
GET    /users/{id}/orders     # User's orders
POST   /users/{id}/orders     # Create order for user

# Actions (when CRUD doesn't fit)
POST   /users/{id}/activate   # Activate user
```

### Pagination
<!-- Lines 159-182 -->

```python
from fastapi import Query

@app.get("/users")
async def list_users(
    page: int = Query(1, ge=1),
    per_page: int = Query(20, ge=1, le=100),
):
    offset = (page - 1) * per_page
    users = await db.get_users(limit=per_page, offset=offset)
    total = await db.count_users()

    return {
        "data": users,
        "meta": {
            "page": page,
            "per_page": per_page,
            "total": total,
            "pages": (total + per_page - 1) // per_page,
        }
    }
```

### Error Responses
<!-- Lines 185-205 -->

```python
from fastapi import HTTPException
from pydantic import BaseModel

class ErrorResponse(BaseModel):
    error: str
    detail: str | None = None
    code: str | None = None

@app.exception_handler(HTTPException)
async def http_exception_handler(request, exc):
    return JSONResponse(
        status_code=exc.status_code,
        content=ErrorResponse(
            error=exc.detail,
            code=f"ERR_{exc.status_code}",
        ).model_dump()
    )
```

### Versioning
<!-- Lines 208-226 -->

```python
# URL versioning
app_v1 = FastAPI()
app_v2 = FastAPI()

app.mount("/v1", app_v1)
app.mount("/v2", app_v2)

# Or header versioning
@app.get("/users")
async def get_users(
    api_version: str = Header("1", alias="X-API-Version")
):
    if api_version == "2":
        return await get_users_v2()
    return await get_users_v1()
```
