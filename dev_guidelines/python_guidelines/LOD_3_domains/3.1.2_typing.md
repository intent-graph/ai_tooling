## Why Type Hints
<!-- Lines 17-49 -->

Type hints make code self-documenting and enable static analysis tools to catch bugs before runtime.

**Benefits:**
- Documentation that stays current (enforced by tools)
- IDE autocomplete and refactoring support
- Catch type errors without running code
- Make interfaces explicit

**Example Without Types:**
```python
def process(data, config):  # What types? What's returned?
    ...
```

**Example With Types:**
```python
def process(data: list[dict], config: Config) -> ProcessResult:
    ...  # Contract is clear
```

**Typing Strategy:**
1. Always type function signatures
2. Type public APIs comprehensively
3. Let inference handle local variables
4. Use `Any` sparingly and intentionally

## Basic Types
<!-- Lines 52-96 -->

Python's type system covers primitive and composite types.

**Primitive Types:**
```python
name: str = "Alice"
count: int = 42
ratio: float = 0.5
active: bool = True
data: bytes = b"raw"
```

**Collection Types:**
```python
# Modern syntax (Python 3.9+)
names: list[str] = ["Alice", "Bob"]
scores: dict[str, int] = {"Alice": 100}
unique: set[int] = {1, 2, 3}
pair: tuple[str, int] = ("Alice", 100)
```

**Optional and Union:**
```python
from typing import Optional

# Optional = X | None
def find_user(id: int) -> Optional[User]:
    return users.get(id)  # May return None

# Union for multiple types
def parse(value: str | int) -> str:
    return str(value)
```

**None Type:**
```python
def log(message: str) -> None:
    print(message)  # Returns None implicitly
```

## Generics
<!-- Lines 99-151 -->

Generics enable type-safe code that works with multiple types.

**TypeVar:**
```python
from typing import TypeVar

T = TypeVar("T")

def first(items: list[T]) -> T:
    return items[0]

# Type is preserved
name: str = first(["a", "b"])    # str
num: int = first([1, 2, 3])      # int
```

**Bounded TypeVar:**
```python
from typing import TypeVar

Numeric = TypeVar("Numeric", int, float)

def add(a: Numeric, b: Numeric) -> Numeric:
    return a + b
```

**Generic Classes:**
```python
from typing import Generic, TypeVar

T = TypeVar("T")

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        return self._items.pop()

# Usage
stack: Stack[int] = Stack()
stack.push(1)
```

## Protocols
<!-- Lines 154-196 -->

Protocols enable structural typing—if it has the methods, it matches.

**Defining Protocols:**
```python
from typing import Protocol

class Readable(Protocol):
    def read(self) -> str: ...

class Writable(Protocol):
    def write(self, data: str) -> None: ...

class ReadWritable(Readable, Writable, Protocol):
    pass
```

**Using Protocols:**
```python
def process(source: Readable) -> str:
    return source.read()

# Any object with read() method works
class FileWrapper:
    def read(self) -> str:
        return "data"

process(FileWrapper())  # Works!
```

**Protocol vs ABC:**
| Aspect | Protocol | ABC |
|--------|----------|-----|
| Inheritance | Not required | Required |
| Runtime check | Limited | Full |
| Flexibility | High | Lower |
| Use case | Duck typing | Type hierarchies |

## Gradual Typing
<!-- Lines 199-249 -->

Python's type system is gradual—you can add types incrementally.

**Migration Strategy:**
1. Start with function signatures
2. Add types to public APIs
3. Enable strict checking incrementally
4. Use `# type: ignore` sparingly

**Strictness Levels:**
```toml
# pyproject.toml
[tool.mypy]
# Start permissive
warn_return_any = false
check_untyped_defs = false

# Progress to strict
strict = true
```

**Handling Untyped Libraries:**
```python
# Option 1: Stub files
# mypackage.pyi with type definitions

# Option 2: Type ignore
import untyped_lib  # type: ignore

# Option 3: mypy config
[[tool.mypy.overrides]]
module = "untyped_lib.*"
ignore_missing_imports = true
```

**When to Use Any:**
```python
from typing import Any

# Acceptable: Truly dynamic data
def parse_json(data: str) -> Any:
    return json.loads(data)

# Better: More specific when possible
def parse_config(data: str) -> dict[str, str | int | bool]:
    return json.loads(data)
```
