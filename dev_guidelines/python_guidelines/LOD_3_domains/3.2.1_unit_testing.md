## Unit Test Philosophy
<!-- Lines 16-57 -->

Unit tests verify the smallest testable parts of code in isolation.

**Characteristics:**
- Fast (< 100ms each)
- Isolated (no external dependencies)
- Deterministic (same result every run)
- Focused (tests one behavior)

**What to Unit Test:**
- Business logic
- Data transformations
- Edge cases and boundaries
- Error conditions

**What NOT to Unit Test:**
- Framework code (Django ORM, Flask routes)
- Simple getters/setters
- Third-party library behavior
- Configuration

**Test Isolation:**
```python
# GOOD: Pure function, no external deps
def test_calculate_discount():
    result = calculate_discount(100, 0.2)
    assert result == 80

# NEEDS MOCKING: Has external dependency
def test_fetch_user():
    with mock.patch('db.get_user') as mock_get:
        mock_get.return_value = User(id=1)
        result = fetch_user(1)
        assert result.id == 1
```

## Test Structure
<!-- Lines 60-108 -->

Use the AAA pattern: Arrange, Act, Assert.

**AAA Pattern:**
```python
def test_user_full_name():
    # Arrange: Set up test data
    user = User(first_name="Alice", last_name="Smith")

    # Act: Execute the code under test
    result = user.full_name()

    # Assert: Verify the result
    assert result == "Alice Smith"
```

**One Assertion Per Test (Guideline):**
```python
# GOOD: Focused test
def test_user_email_is_lowercase():
    user = User(email="ALICE@EXAMPLE.COM")
    assert user.email == "alice@example.com"

def test_user_email_validates_format():
    with pytest.raises(ValueError):
        User(email="invalid")

# ACCEPTABLE: Related assertions
def test_user_creation():
    user = User(name="Alice", age=30)
    assert user.name == "Alice"
    assert user.age == 30
```

**Test Naming:**
```python
# Pattern: test_<unit>_<scenario>_<expected>
def test_calculate_total_with_discount_returns_reduced_price():
    ...

def test_validate_email_with_missing_at_raises_error():
    ...
```

## Mocking
<!-- Lines 111-176 -->

Mocks replace dependencies with controlled substitutes.

**When to Mock:**
- External services (APIs, databases)
- Non-deterministic behavior (time, random)
- Slow operations
- Side effects (sending emails)

**Basic Mocking:**
```python
from unittest.mock import Mock, patch

def test_send_notification():
    # Create mock
    mock_client = Mock()
    mock_client.send.return_value = True

    # Inject and test
    result = send_notification("Hello", client=mock_client)

    mock_client.send.assert_called_once_with("Hello")
    assert result is True
```

**Patch Decorator:**
```python
@patch('mymodule.external_api.fetch')
def test_process_data(mock_fetch):
    mock_fetch.return_value = {"data": [1, 2, 3]}

    result = process_data()

    assert result == [1, 2, 3]
    mock_fetch.assert_called_once()
```

**Patch Context Manager:**
```python
def test_get_current_time():
    with patch('mymodule.datetime') as mock_dt:
        mock_dt.now.return_value = datetime(2024, 1, 1, 12, 0, 0)

        result = get_current_time()

        assert result.hour == 12
```

**Don't Over-Mock:**
```python
# BAD: Mocking internals
def test_process():
    with patch.object(processor, '_internal_method'):
        ...  # Testing implementation, not behavior

# GOOD: Mock at boundaries
def test_process():
    with patch('processor.external_service'):
        ...  # Mock external dependency only
```

## Parametrization
<!-- Lines 179-234 -->

Parametrization runs the same test with different inputs.

**Basic Parametrization:**
```python
import pytest

@pytest.mark.parametrize("input,expected", [
    (1, 1),
    (2, 4),
    (3, 9),
    (4, 16),
])
def test_square(input, expected):
    assert square(input) == expected
```

**Multiple Parameters:**
```python
@pytest.mark.parametrize("a,b,expected", [
    (1, 2, 3),
    (0, 0, 0),
    (-1, 1, 0),
])
def test_add(a, b, expected):
    assert add(a, b) == expected
```

**Edge Cases:**
```python
@pytest.mark.parametrize("email,valid", [
    ("user@example.com", True),
    ("user@sub.example.com", True),
    ("user+tag@example.com", True),
    ("invalid", False),
    ("@example.com", False),
    ("user@", False),
    ("", False),
])
def test_validate_email(email, valid):
    assert validate_email(email) == valid
```

**IDs for Clarity:**
```python
@pytest.mark.parametrize("value,expected", [
    pytest.param(0, "zero", id="zero"),
    pytest.param(1, "positive", id="positive"),
    pytest.param(-1, "negative", id="negative"),
])
def test_sign(value, expected):
    assert sign(value) == expected
```
