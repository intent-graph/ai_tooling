## Core Concept
<!-- Lines 29-47 -->

**Definition:** Refactoring is restructuring existing code without changing its external behavior. The goal is improving internal quality—readability, maintainability, extensibility—while preserving functionality.

**Key Principles:**
- Always have tests before refactoring
- Make small, reversible changes
- Commit frequently during refactoring
- Separate refactoring commits from feature commits

**The Two Hats:**
Martin Fowler's metaphor: you wear either the "adding function" hat or the "refactoring" hat, never both simultaneously. When adding features, don't restructure. When refactoring, don't change behavior.

## Refactoring Catalog
<!-- Lines 50-50 -->

### Extract Function
<!-- Lines 53-78 -->

Pull code into a named function:

```python
# Before
def process_order(order):
    # Calculate total
    total = 0
    for item in order.items:
        total += item.price * item.quantity
    if order.discount:
        total *= (1 - order.discount)
    # ... more processing

# After
def calculate_total(order) -> float:
    total = sum(item.price * item.quantity for item in order.items)
    if order.discount:
        total *= (1 - order.discount)
    return total

def process_order(order):
    total = calculate_total(order)
    # ... more processing
```

### Rename
<!-- Lines 81-93 -->

Change names to improve clarity:

```python
# Before
def calc(d, r):
    return d * r * 0.01

# After
def calculate_interest(principal: float, rate_percent: float) -> float:
    return principal * rate_percent * 0.01
```

### Extract Variable
<!-- Lines 96-111 -->

Name intermediate values:

```python
# Before
if user.age >= 18 and user.country in ALLOWED_COUNTRIES and user.verified:
    grant_access()

# After
is_adult = user.age >= 18
in_allowed_region = user.country in ALLOWED_COUNTRIES
is_eligible = is_adult and in_allowed_region and user.verified
if is_eligible:
    grant_access()
```

### Inline
<!-- Lines 114-129 -->

Remove unnecessary indirection:

```python
# Before
def get_base_price(order):
    return order.base_price

total = get_base_price(order) * quantity

# After
total = order.base_price * quantity
```

## Safe Refactoring Process
<!-- Lines 132-132 -->

### Step 1: Ensure Test Coverage
<!-- Lines 135-146 -->

```python
# Before refactoring, verify tests exist
def test_calculate_total_basic():
    order = Order(items=[Item(price=10, quantity=2)])
    assert calculate_total(order) == 20

def test_calculate_total_with_discount():
    order = Order(items=[Item(price=100, quantity=1)], discount=0.1)
    assert calculate_total(order) == 90
```

### Step 2: Small Steps
<!-- Lines 149-157 -->

Make one change at a time:

```bash
# Commit after each atomic change
git commit -m "refactor: extract calculate_total function"
git commit -m "refactor: rename d to principal in calculate_interest"
```

### Step 3: Run Tests After Each Change
<!-- Lines 160-165 -->

```bash
# After every refactoring step
pytest tests/ -x  # Stop on first failure
```

### Step 4: Verify No Behavior Change
<!-- Lines 168-182 -->

```python
# Use property-based testing for confidence
from hypothesis import given, strategies as st

@given(st.lists(st.floats(min_value=0, max_value=1000)))
def test_total_unchanged(prices):
    # Old implementation result should equal new
    old_result = old_calculate_total(prices)
    new_result = new_calculate_total(prices)
    assert old_result == new_result
```

### Automated Refactoring with rope
<!-- Lines 208-222 -->

```python
# rope provides programmatic refactoring
from rope.base.project import Project
from rope.refactor.rename import Rename

project = Project('myproject')
resource = project.get_resource('module.py')

# Rename a function
renamer = Rename(project, resource, offset=123)
changes = renamer.get_changes('new_name')
project.do(changes)
```

### Refactoring Safety Checklist
<!-- Lines 225-230 -->

- [ ] Tests pass before starting
- [ ] Each change is atomic and reversible
- [ ] Tests pass after each change
- [ ] No behavior changes mixed with refactoring
- [ ] Commit history tells the story
