## pyproject.toml
<!-- Lines 18-74 -->

`pyproject.toml` is the single source of truth for Python project configuration (PEP 517/518).

**Complete Example:**
```toml
[project]
name = "my-package"
version = "0.1.0"
description = "What this package does"
readme = "README.md"
license = {text = "MIT"}
requires-python = ">=3.11"
authors = [
    {name = "Your Name", email = "you@example.com"}
]
keywords = ["keyword1", "keyword2"]
classifiers = [
    "Development Status :: 4 - Beta",
    "Programming Language :: Python :: 3.11",
    "Programming Language :: Python :: 3.12",
]

dependencies = [
    "httpx>=0.24",
    "pydantic>=2.0",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.0",
    "ruff>=0.1",
    "mypy>=1.0",
]
docs = [
    "mkdocs>=1.5",
    "mkdocs-material>=9.0",
]

[project.urls]
Homepage = "https://github.com/user/project"
Documentation = "https://project.readthedocs.io"
Repository = "https://github.com/user/project"

[project.scripts]
mycommand = "my_package.cli:main"

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
```

## Tool Configuration
<!-- Lines 77-141 -->

Most Python tools support configuration in `pyproject.toml` under `[tool.*]` sections.

**Ruff (Linting/Formatting):**
```toml
[tool.ruff]
line-length = 88
target-version = "py311"

[tool.ruff.lint]
select = [
    "E",   # pycodestyle errors
    "W",   # pycodestyle warnings
    "F",   # pyflakes
    "I",   # isort
    "B",   # flake8-bugbear
    "UP",  # pyupgrade
]
ignore = ["E501"]  # Line too long (handled by formatter)

[tool.ruff.lint.isort]
known-first-party = ["my_package"]
```

**Mypy (Type Checking):**
```toml
[tool.mypy]
python_version = "3.11"
strict = true
warn_return_any = true
warn_unused_ignores = true

[[tool.mypy.overrides]]
module = "third_party.*"
ignore_missing_imports = true
```

**Pytest:**
```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
pythonpath = ["src"]
addopts = "-ra -q --strict-markers"
markers = [
    "slow: marks tests as slow",
    "integration: integration tests",
]
```

**Coverage:**
```toml
[tool.coverage.run]
source = ["src"]
branch = true

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "if TYPE_CHECKING:",
    "raise NotImplementedError",
]
```

## Legacy Files
<!-- Lines 144-176 -->

Some legacy configuration files persist in the ecosystem.

**Still Used:**

| File | Purpose | Notes |
|------|---------|-------|
| `.pre-commit-config.yaml` | Git hooks | Required format |
| `tox.ini` | Multi-env testing | Can use pyproject.toml |
| `.env` | Environment variables | Development only |
| `Makefile` | Task automation | Common convention |

**Deprecated (Avoid):**

| File | Replacement |
|------|-------------|
| `setup.py` | `pyproject.toml` |
| `setup.cfg` | `pyproject.toml` |
| `MANIFEST.in` | Build backend handles |
| `requirements.txt` | `pyproject.toml` dependencies |

**Migration:**
```python
# Old: setup.py
from setuptools import setup
setup(name="my-package", version="0.1.0", ...)

# New: pyproject.toml handles everything
# Delete setup.py after migration
```

## Configuration Hierarchy
<!-- Lines 179-232 -->

Different configuration types have different purposes and locations.

**Configuration Types:**

| Type | Location | Committed? |
|------|----------|-----------|
| Project metadata | `pyproject.toml` | Yes |
| Tool settings | `pyproject.toml [tool.*]` | Yes |
| IDE settings | `.vscode/`, `.idea/` | Yes (team) |
| Secrets | `.env`, vault | No |
| CI/CD | `.github/workflows/` | Yes |

**Environment-Specific Config:**
```
config/
├── base.yaml       # Shared settings
├── development.yaml
├── staging.yaml
└── production.yaml
```

**.env Pattern:**
```bash
# .env (gitignored)
DATABASE_URL=postgresql://localhost/dev
SECRET_KEY=dev-key-not-for-production
DEBUG=true
```

**.env.example (Committed):**
```bash
# .env.example (committed, documents required vars)
DATABASE_URL=
SECRET_KEY=
DEBUG=false
```

**Loading Configuration:**
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    database_url: str
    secret_key: str
    debug: bool = False

    model_config = {"env_file": ".env"}

settings = Settings()
```
