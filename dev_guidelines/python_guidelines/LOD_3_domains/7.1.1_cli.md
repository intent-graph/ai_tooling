## Core Concept
<!-- Lines 31-54 -->

**Definition:** CLI applications accept commands and arguments from the terminal and produce output (text, files, or side effects).

**Key UX Principles:**
- Provide helpful `--help` for every command
- Use consistent flag naming (`--verbose`, `-v`)
- Return meaningful exit codes
- Support both interactive and scripted use
- Respect Unix conventions (stdin/stdout/stderr)

**Exit Codes:**
| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | General error |
| 2 | Command line usage error |
| 126 | Permission denied |
| 127 | Command not found |

## Framework Comparison

### argparse (Standard Library)
<!-- Lines 60-74 -->

```python
import argparse

parser = argparse.ArgumentParser(description="Process files")
parser.add_argument("files", nargs="+", help="Files to process")
parser.add_argument("-v", "--verbose", action="store_true")
parser.add_argument("-o", "--output", default="out.txt")

args = parser.parse_args()
```

**Pros:** No dependencies, always available
**Cons:** Verbose, manual subcommand handling

### Click
<!-- Lines 77-96 -->

```python
import click

@click.command()
@click.argument("files", nargs=-1, type=click.Path(exists=True))
@click.option("-v", "--verbose", is_flag=True)
@click.option("-o", "--output", default="out.txt")
def process(files, verbose, output):
    """Process files."""
    for f in files:
        click.echo(f"Processing {f}")

if __name__ == "__main__":
    process()
```

**Pros:** Decorators, composable, good error messages
**Cons:** Dependency, learning curve

### Typer
<!-- Lines 99-121 -->

```python
import typer

app = typer.Typer()

@app.command()
def process(
    files: list[str],
    verbose: bool = typer.Option(False, "--verbose", "-v"),
    output: str = typer.Option("out.txt", "--output", "-o"),
):
    """Process files."""
    for f in files:
        typer.echo(f"Processing {f}")

if __name__ == "__main__":
    app()
```

**Pros:** Type hints, modern, auto-completion
**Cons:** Dependency, requires Python 3.7+

### Configuration Files
<!-- Lines 197-216 -->

```python
import click
from pathlib import Path
import tomllib

def load_config():
    config_path = Path.home() / ".myapp" / "config.toml"
    if config_path.exists():
        with open(config_path, "rb") as f:
            return tomllib.load(f)
    return {}

@click.command()
@click.pass_context
def main(ctx):
    ctx.ensure_object(dict)
    ctx.obj["config"] = load_config()
```

### stdin/stdout Handling
<!-- Lines 219-231 -->

```python
@click.command()
@click.argument("input", type=click.File("r"), default="-")
@click.argument("output", type=click.File("w"), default="-")
def process(input, output):
    """Process input to output. Use - for stdin/stdout."""
    for line in input:
        output.write(line.upper())
```

### User-Friendly Errors
<!-- Lines 237-252 -->

```python
class UserError(click.ClickException):
    """Error shown to user without stack trace."""
    pass

@click.command()
def main():
    try:
        do_work()
    except FileNotFoundError as e:
        raise UserError(f"File not found: {e.filename}")
    except PermissionError:
        raise UserError("Permission denied. Try with sudo?")
```

### Exit Codes
<!-- Lines 255-270 -->

```python
import sys

def main():
    try:
        result = process()
        sys.exit(0)
    except ValueError as e:
        click.echo(f"Invalid input: {e}", err=True)
        sys.exit(1)
    except KeyboardInterrupt:
        click.echo("\nAborted.", err=True)
        sys.exit(130)  # 128 + SIGINT
```

### Verbose/Debug Modes
<!-- Lines 273-285 -->

```python
@click.command()
@click.option("-v", "--verbose", count=True, help="Increase verbosity")
def main(verbose):
    if verbose >= 2:
        logging.basicConfig(level=logging.DEBUG)
    elif verbose == 1:
        logging.basicConfig(level=logging.INFO)
    else:
        logging.basicConfig(level=logging.WARNING)
```
