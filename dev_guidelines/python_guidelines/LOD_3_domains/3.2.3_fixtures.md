## Pytest Fixtures
<!-- Lines 18-72 -->

Fixtures provide reusable test setup and teardown.

**Basic Fixture:**
```python
import pytest

@pytest.fixture
def sample_user():
    return User(id=1, name="Alice", email="alice@example.com")

def test_user_greeting(sample_user):
    assert sample_user.greeting() == "Hello, Alice!"
```

**Fixture with Setup/Teardown:**
```python
@pytest.fixture
def database():
    # Setup
    db = Database()
    db.connect()

    yield db  # Test runs here

    # Teardown
    db.disconnect()

def test_query(database):
    result = database.query("SELECT 1")
    assert result == 1
```

**Fixture Dependencies:**
```python
@pytest.fixture
def db_session(database):
    session = database.create_session()
    yield session
    session.rollback()

@pytest.fixture
def user_repository(db_session):
    return UserRepository(db_session)

def test_create_user(user_repository):
    user = user_repository.create(name="Alice")
    assert user.id is not None
```

## Fixture Scopes
<!-- Lines 75-131 -->

Scopes control fixture lifetime and reuse.

**Scope Levels:**
| Scope | Lifetime | Use For |
|-------|----------|---------|
| function | Each test | Default, most cases |
| class | Test class | Shared class setup |
| module | Test module | Expensive module setup |
| session | Entire run | Very expensive (DB schema) |

**Function Scope (Default):**
```python
@pytest.fixture  # scope="function" is default
def fresh_user():
    return User(name="Test")

# Each test gets a new User
```

**Session Scope:**
```python
@pytest.fixture(scope="session")
def database_schema():
    """Create schema once for entire test session."""
    engine = create_engine(TEST_DB_URL)
    Base.metadata.create_all(engine)
    yield engine
    Base.metadata.drop_all(engine)
```

**Module Scope:**
```python
@pytest.fixture(scope="module")
def api_client():
    """Reused across all tests in module."""
    client = APIClient()
    client.authenticate()
    yield client
    client.logout()
```

**Scope Gotcha:**
```python
# BAD: Higher-scoped fixture using lower-scoped
@pytest.fixture(scope="session")
def session_fixture(function_fixture):  # Error!
    ...

# A session fixture cannot depend on a function fixture
```

## Factories
<!-- Lines 134-208 -->

Factories create test objects with flexible defaults.

**Simple Factory Function:**
```python
def create_user(**overrides) -> User:
    defaults = {
        "name": "Test User",
        "email": "test@example.com",
        "active": True,
    }
    return User(**{**defaults, **overrides})

# Usage
def test_inactive_user():
    user = create_user(active=False)
    assert not user.can_login()
```

**Factory Class:**
```python
class UserFactory:
    _counter = 0

    @classmethod
    def create(cls, **overrides) -> User:
        cls._counter += 1
        defaults = {
            "name": f"User {cls._counter}",
            "email": f"user{cls._counter}@example.com",
        }
        return User(**{**defaults, **overrides})

# Unique users each time
user1 = UserFactory.create()  # User 1
user2 = UserFactory.create()  # User 2
```

**Factory with Relationships:**
```python
class OrderFactory:
    @classmethod
    def create(cls, user: User = None, **overrides) -> Order:
        if user is None:
            user = UserFactory.create()

        defaults = {
            "user": user,
            "status": "pending",
            "total": Decimal("0.00"),
        }
        return Order(**{**defaults, **overrides})
```

**factory_boy Library:**
```python
import factory
from factory.alchemy import SQLAlchemyModelFactory

class UserFactory(SQLAlchemyModelFactory):
    class Meta:
        model = User
        sqlalchemy_session = Session

    name = factory.Faker("name")
    email = factory.LazyAttribute(
        lambda o: f"{o.name.lower().replace(' ', '.')}@example.com"
    )
```

## conftest.py
<!-- Lines 211-267 -->

`conftest.py` shares fixtures across test files.

**File Location:**
```
tests/
├── conftest.py          # Shared by all tests
├── unit/
│   ├── conftest.py      # Shared by unit tests
│   └── test_models.py
└── integration/
    ├── conftest.py      # Shared by integration tests
    └── test_api.py
```

**Root conftest.py:**
```python
# tests/conftest.py
import pytest

@pytest.fixture
def sample_config():
    """Available to all tests."""
    return {"debug": True, "env": "test"}

@pytest.fixture(scope="session")
def database():
    """Session-scoped database."""
    engine = create_test_engine()
    yield engine
    engine.dispose()
```

**Specialized conftest.py:**
```python
# tests/integration/conftest.py
import pytest

@pytest.fixture
def api_client(database):
    """Only available in integration tests."""
    app.config["DATABASE"] = database
    with app.test_client() as client:
        yield client
```

**Pytest Plugins in conftest:**
```python
# tests/conftest.py
pytest_plugins = [
    "tests.fixtures.database",
    "tests.fixtures.users",
]
```
