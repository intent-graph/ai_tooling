## Zen of Python
<!-- Lines 16-55 -->

The Zen of Python (`import this`) captures Python's design philosophy.

**Key Principles:**
- **Beautiful is better than ugly**: Readable code matters
- **Explicit is better than implicit**: Make intent clear
- **Simple is better than complex**: Choose straightforward solutions
- **Flat is better than nested**: Avoid deep nesting
- **Readability counts**: Code is read more than written

**Practical Application:**
```python
# Ugly: Nested, unclear
if x:
    if y:
        if z:
            do_thing()

# Beautiful: Flat, clear
if not (x and y and z):
    return
do_thing()
```

```python
# Implicit: Magic behavior
def process(data):
    return data.transform()  # What transform?

# Explicit: Clear intent
def process(data: UserData) -> ProcessedData:
    return transform_user_data(data)
```

## EAFP vs LBYL
<!-- Lines 58-108 -->

Python idiomatically uses EAFP (Easier to Ask Forgiveness than Permission) rather than LBYL (Look Before You Leap).

**LBYL (Non-Pythonic):**
```python
# Check before accessing
if "key" in dictionary:
    value = dictionary["key"]
else:
    value = default

# Check before converting
if isinstance(x, str) and x.isdigit():
    num = int(x)
```

**EAFP (Pythonic):**
```python
# Just try it
try:
    value = dictionary["key"]
except KeyError:
    value = default

# Even better: use built-in
value = dictionary.get("key", default)

# Try conversion
try:
    num = int(x)
except (TypeError, ValueError):
    num = 0
```

**When LBYL is Better:**
- Expensive operations (check before database query)
- Side effects on failure
- Clear preconditions for documentation

```python
# LBYL appropriate: Don't query if invalid ID
if user_id <= 0:
    raise ValueError("Invalid user ID")
user = expensive_db_lookup(user_id)
```

## Context Managers
<!-- Lines 111-177 -->

Context managers ensure proper resource cleanup with `with` statement.

**Built-in Usage:**
```python
# File handling
with open("file.txt") as f:
    data = f.read()
# File automatically closed

# Lock management
with lock:
    shared_resource.modify()
# Lock automatically released
```

**Class-Based Context Manager:**
```python
class Timer:
    def __enter__(self):
        self.start = time.perf_counter()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.elapsed = time.perf_counter() - self.start
        return False  # Don't suppress exceptions

with Timer() as t:
    do_work()
print(f"Elapsed: {t.elapsed:.2f}s")
```

**contextlib Decorator:**
```python
from contextlib import contextmanager

@contextmanager
def timer():
    start = time.perf_counter()
    try:
        yield
    finally:
        elapsed = time.perf_counter() - start
        print(f"Elapsed: {elapsed:.2f}s")

with timer():
    do_work()
```

**Nested Context Managers:**
```python
# Multiple resources
with open("in.txt") as f_in, open("out.txt", "w") as f_out:
    f_out.write(f_in.read())

# Or using ExitStack
from contextlib import ExitStack

with ExitStack() as stack:
    files = [stack.enter_context(open(f)) for f in filenames]
```

## Decorators
<!-- Lines 180-243 -->

Decorators modify or extend function behavior without changing the function itself.

**Basic Decorator:**
```python
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        result = func(*args, **kwargs)
        print(f"Returned {result}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b
```

**Decorator with Arguments:**
```python
def retry(times: int = 3):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception:
                    if attempt == times - 1:
                        raise
        return wrapper
    return decorator

@retry(times=5)
def fetch_data():
    ...
```

**Class Decorator:**
```python
def singleton(cls):
    instances = {}
    @functools.wraps(cls)
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    return get_instance

@singleton
class Database:
    ...
```

**Common Built-in Decorators:**
- `@property`: Attribute access
- `@staticmethod`: No self parameter
- `@classmethod`: Class as first parameter
- `@functools.cache`: Memoization
- `@dataclass`: Generate methods
