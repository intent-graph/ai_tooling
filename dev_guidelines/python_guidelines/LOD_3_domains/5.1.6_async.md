## Core Concept
<!-- Lines 19-41 -->

Async programming handles thousands of concurrent I/O operations with a single thread. Instead of blocking while waiting, control returns to the event loop which runs other tasks.

**Sync vs Async:**
```python
# Sync: Waits for each request
for url in urls:
    response = requests.get(url)  # Blocks

# Async: Starts all, waits together
async with httpx.AsyncClient() as client:
    tasks = [client.get(url) for url in urls]
    responses = await asyncio.gather(*tasks)  # Concurrent
```

**Key Insight:** Async is about efficient waiting, not parallel computation. One thread, many concurrent I/O operations.

## async/await Basics
<!-- Lines 44-84 -->

**Coroutine Definition:**
```python
async def fetch_data(url):
    async with httpx.AsyncClient() as client:
        response = await client.get(url)
        return response.json()
```

**await Expression:**
```python
# await pauses coroutine until result ready
result = await some_async_function()

# Can only await inside async function
async def main():
    data = await fetch_data(url)
```

**Async Context Manager:**
```python
async with httpx.AsyncClient() as client:
    response = await client.get(url)

# Equivalent to
client = httpx.AsyncClient()
try:
    await client.__aenter__()
    response = await client.get(url)
finally:
    await client.__aexit__()
```

**Async Iterator:**
```python
async for item in async_generator():
    process(item)
```

## Running Async Code
<!-- Lines 87-131 -->

**asyncio.run (main entry point):**
```python
import asyncio

async def main():
    result = await fetch_data(url)
    return result

# Runs the coroutine
result = asyncio.run(main())
```

**Event Loop (low-level):**
```python
loop = asyncio.get_event_loop()
result = loop.run_until_complete(main())
loop.close()
```

**In Jupyter/IPython:**
```python
# Top-level await works in Jupyter
await main()

# Or use nest_asyncio
import nest_asyncio
nest_asyncio.apply()
asyncio.run(main())
```

**Creating Tasks:**
```python
async def main():
    # Create task (starts immediately)
    task = asyncio.create_task(fetch_data(url))

    # Do other work...

    # Wait for task
    result = await task
```

## Concurrent Tasks
<!-- Lines 134-184 -->

**asyncio.gather:**
```python
async def main():
    results = await asyncio.gather(
        fetch_data(url1),
        fetch_data(url2),
        fetch_data(url3),
    )
    return results  # [result1, result2, result3]
```

**Handle Exceptions in gather:**
```python
results = await asyncio.gather(
    fetch_data(url1),
    fetch_data(url2),
    return_exceptions=True  # Returns exception instead of raising
)

for result in results:
    if isinstance(result, Exception):
        print(f"Error: {result}")
    else:
        print(f"Success: {result}")
```

**asyncio.wait (more control):**
```python
tasks = [asyncio.create_task(fetch(url)) for url in urls]
done, pending = await asyncio.wait(
    tasks,
    timeout=10,
    return_when=asyncio.FIRST_COMPLETED
)
```

**Semaphore (limit concurrency):**
```python
semaphore = asyncio.Semaphore(10)  # Max 10 concurrent

async def limited_fetch(url):
    async with semaphore:
        return await fetch(url)

# Only 10 requests at a time
results = await asyncio.gather(*[limited_fetch(u) for u in urls])
```

## When to Use
<!-- Lines 187-221 -->

**Use Async When:**
- High-concurrency I/O (100+ concurrent operations)
- Web servers/APIs
- WebSocket connections
- API clients making many requests
- Web scraping at scale

**Don't Use When:**
- CPU-bound work (use multiprocessing)
- Simple scripts with few I/O operations
- Libraries don't support async
- Team unfamiliar with async patterns

**Async vs Threading:**
| Factor | Async | Threading |
|--------|-------|-----------|
| Concurrency | 1000s | 10-100s |
| Overhead | Lower | Higher |
| Complexity | Higher | Lower |
| Library support | Growing | Universal |

**Migration Strategy:**
```python
# Sync code
def fetch_all(urls):
    return [requests.get(url).json() for url in urls]

# Async equivalent
async def fetch_all_async(urls):
    async with httpx.AsyncClient() as client:
        tasks = [client.get(url) for url in urls]
        responses = await asyncio.gather(*tasks)
        return [r.json() for r in responses]
```
