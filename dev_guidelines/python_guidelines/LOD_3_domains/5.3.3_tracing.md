## Core Concept
<!-- Lines 17-35 -->

In distributed systems, a single user request might touch dozens of services. Tracing connects these fragments into a coherent picture.

**The Problem:**
```
User → API Gateway → Auth Service → User Service → Database
                  → Order Service → Payment API
                                 → Inventory Service
```
Where did the request slow down? Which service failed?

**The Solution:**
Trace IDs propagate through all services, allowing reconstruction of the full request journey.

## Tracing Concepts
<!-- Lines 38-71 -->

**Trace:**
The complete journey of one request.

**Span:**
One operation within a trace. Has:
- Name (what operation)
- Start/end time
- Attributes (metadata)
- Parent span (if nested)
- Status (success/error)

**Context:**
Metadata passed between services (trace ID, span ID).

**Trace Structure:**
```
Trace: abc123
├── Span: API Gateway (0-100ms)
│   ├── Span: Auth Service (5-20ms)
│   └── Span: Order Service (25-95ms)
│       ├── Span: Database Query (30-40ms)
│       └── Span: Payment API (50-90ms)
```

**Propagation:**
Context travels via HTTP headers:
```
traceparent: 00-abc123-def456-01
tracestate: vendor1=value1
```

## OpenTelemetry
<!-- Lines 74-125 -->

OpenTelemetry is the standard for distributed tracing.

**Installation:**
```bash
pip install opentelemetry-api opentelemetry-sdk
pip install opentelemetry-exporter-otlp
pip install opentelemetry-instrumentation-fastapi
```

**Setup:**
```python
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter

# Configure provider
provider = TracerProvider()
processor = BatchSpanProcessor(OTLPSpanExporter())
provider.add_span_processor(processor)
trace.set_tracer_provider(provider)

# Get tracer
tracer = trace.get_tracer(__name__)
```

**Manual Instrumentation:**
```python
with tracer.start_as_current_span("process_order") as span:
    span.set_attribute("order_id", order_id)
    span.set_attribute("customer_id", customer_id)

    # Nested span
    with tracer.start_as_current_span("validate_inventory"):
        validate(order)

    with tracer.start_as_current_span("charge_payment"):
        charge(order)
```

**Auto-Instrumentation:**
```python
from opentelemetry.instrumentation.fastapi import FastAPIInstrumentor

app = FastAPI()
FastAPIInstrumentor.instrument_app(app)
# All endpoints automatically traced
```

## Correlation IDs
<!-- Lines 128-173 -->

Even without full tracing, correlation IDs connect logs.

**Generate at Entry Point:**
```python
import uuid
from fastapi import Request

@app.middleware("http")
async def add_correlation_id(request: Request, call_next):
    request_id = request.headers.get("X-Request-ID", str(uuid.uuid4()))
    # Store in context for logging
    contextvars.request_id.set(request_id)

    response = await call_next(request)
    response.headers["X-Request-ID"] = request_id
    return response
```

**Include in Logs:**
```python
import contextvars

request_id_var = contextvars.ContextVar('request_id', default='-')

class RequestIdFilter(logging.Filter):
    def filter(self, record):
        record.request_id = request_id_var.get()
        return True

# Format includes request_id
format = '%(asctime)s [%(request_id)s] %(levelname)s: %(message)s'
```

**Pass to Downstream Services:**
```python
async def call_service(url: str) -> dict:
    request_id = request_id_var.get()
    headers = {"X-Request-ID": request_id}
    async with httpx.AsyncClient() as client:
        response = await client.get(url, headers=headers)
        return response.json()
```

## Analysis
<!-- Lines 176-216 -->

**Visualization:**
```
[Request] ─────────────────────────────────────────
    │
    ├── [API Gateway] ────────────────
    │        │
    │        ├── [Auth] ────
    │        │
    │        └── [Orders] ──────────────
    │                │
    │                ├── [DB] ────
    │                │
    │                └── [Payment] ─────────
```

**Tools:**
- **Jaeger**: Open source, popular
- **Zipkin**: Simple, lightweight
- **Honeycomb**: SaaS, powerful queries
- **Datadog APM**: SaaS, integrated platform

**What to Look For:**
- Long spans (bottlenecks)
- Error spans
- Span count (N+1 queries)
- Service dependencies

**Trace Sampling:**
```python
from opentelemetry.sdk.trace.sampling import TraceIdRatioBased

# Sample 10% of traces in production
sampler = TraceIdRatioBased(0.1)
provider = TracerProvider(sampler=sampler)
```

High-volume systems can't trace everything. Sample intelligently:
- Always trace errors
- Always trace slow requests
- Sample normal requests
