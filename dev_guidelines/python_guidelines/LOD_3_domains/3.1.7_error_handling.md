## Error Philosophy
<!-- Lines 18-54 -->

Errors are communication. They tell callers what went wrong and how to handle it.

**Principles:**
- **Fail fast**: Detect errors early
- **Be specific**: Use appropriate exception types
- **Provide context**: Messages should help debugging
- **Don't swallow**: Silent failures hide bugs

**Error Categories:**
| Category | Example | Handling |
|----------|---------|----------|
| Programming error | IndexError, TypeError | Fix code |
| User error | Invalid input | Validate, inform user |
| External failure | Network timeout | Retry, fallback |
| Impossible state | Logic contradiction | Assert, crash |

**Exceptions vs Return Values:**
```python
# Exceptions: Unexpected failure
def get_user(id: int) -> User:
    user = db.get(id)
    if not user:
        raise UserNotFoundError(id)  # Caller must handle
    return user

# Return value: Expected absence
def find_user(id: int) -> User | None:
    return db.get(id)  # Caller checks for None
```

## try/except Patterns
<!-- Lines 57-127 -->

Use try/except to handle anticipated failures.

**Basic Pattern:**
```python
try:
    result = risky_operation()
except SpecificError as e:
    handle_error(e)
```

**Multiple Exceptions:**
```python
try:
    data = fetch_and_parse(url)
except RequestError as e:
    log.error(f"Network error: {e}")
    return default_data()
except ParseError as e:
    log.error(f"Invalid data format: {e}")
    raise
```

**Catch Multiple Types:**
```python
try:
    value = int(user_input)
except (TypeError, ValueError) as e:
    print(f"Invalid input: {e}")
```

**else and finally:**
```python
try:
    file = open(path)
except FileNotFoundError:
    return default
else:
    # Runs only if no exception
    data = file.read()
finally:
    # Always runs
    file.close()
```

**Anti-Patterns:**
```python
# BAD: Catch everything
try:
    do_something()
except:  # Catches KeyboardInterrupt, SystemExit!
    pass

# BAD: Bare except
try:
    do_something()
except Exception:  # Better, but still too broad
    pass

# GOOD: Specific exceptions
try:
    do_something()
except (ValueError, KeyError) as e:
    handle_specific_error(e)
```

## Custom Exceptions
<!-- Lines 130-188 -->

Define custom exceptions for domain-specific errors.

**Basic Custom Exception:**
```python
class UserNotFoundError(Exception):
    """Raised when user lookup fails."""

    def __init__(self, user_id: int):
        self.user_id = user_id
        super().__init__(f"User not found: {user_id}")
```

**Exception Hierarchy:**
```python
# Base for all application errors
class AppError(Exception):
    """Base exception for application."""
    pass

class ValidationError(AppError):
    """Input validation failed."""
    pass

class NotFoundError(AppError):
    """Resource not found."""
    pass

class UserNotFoundError(NotFoundError):
    """User not found."""
    def __init__(self, user_id: int):
        self.user_id = user_id
        super().__init__(f"User {user_id} not found")
```

**Rich Exception Data:**
```python
@dataclass
class APIError(Exception):
    status_code: int
    message: str
    details: dict = field(default_factory=dict)

    def __str__(self) -> str:
        return f"[{self.status_code}] {self.message}"

# Usage
raise APIError(
    status_code=400,
    message="Invalid request",
    details={"field": "email", "error": "required"}
)
```

## Error Messages
<!-- Lines 191-243 -->

Good error messages help debugging and user communication.

**Message Components:**
1. What happened
2. Why it's a problem
3. How to fix it (if known)

**Good Error Messages:**
```python
# Informative
raise ValueError(
    f"Invalid email format: '{email}'. "
    "Expected format: user@domain.com"
)

# With context
raise ConfigError(
    f"Missing required key 'database_url' in {config_path}. "
    "See config.example.yaml for required fields."
)
```

**Bad Error Messages:**
```python
# Vague
raise ValueError("Invalid input")

# No context
raise Exception("Error")

# Technical jargon for user-facing
raise ValueError("NoneType is not subscriptable")
```

**Structured Error Information:**
```python
class ValidationError(Exception):
    def __init__(self, field: str, value: Any, reason: str):
        self.field = field
        self.value = value
        self.reason = reason
        super().__init__(
            f"Validation failed for '{field}': {reason}. "
            f"Got: {value!r}"
        )

# Provides: What (validation), Where (field), Why (reason)
raise ValidationError("age", -5, "must be positive")
```
