## VS Code Setup
<!-- Lines 16-70 -->

VS Code with Python extensions provides a lightweight, powerful development environment.

**Essential Extensions:**
- **Python** (Microsoft) — Language support
- **Pylance** — Fast type checking
- **Ruff** — Linting and formatting
- **Python Debugger** — Debug support

**Project Settings:**
```json
// .vscode/settings.json
{
    "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python",
    "python.analysis.typeCheckingMode": "basic",
    "python.analysis.autoImportCompletions": true,

    "[python]": {
        "editor.formatOnSave": true,
        "editor.defaultFormatter": "charliermarsh.ruff",
        "editor.codeActionsOnSave": {
            "source.fixAll": "explicit",
            "source.organizeImports": "explicit"
        }
    },

    "ruff.lint.args": ["--config=pyproject.toml"],
    "ruff.format.args": ["--config=pyproject.toml"],

    "files.exclude": {
        "**/__pycache__": true,
        "**/*.pyc": true,
        ".venv": true
    }
}
```

**Recommended Extensions File:**
```json
// .vscode/extensions.json
{
    "recommendations": [
        "ms-python.python",
        "ms-python.vscode-pylance",
        "charliermarsh.ruff",
        "ms-python.debugpy"
    ]
}
```

## PyCharm Setup
<!-- Lines 73-112 -->

PyCharm provides an integrated Python IDE experience with built-in tools.

**Project Interpreter:**
1. File → Settings → Project → Python Interpreter
2. Add Interpreter → Existing → Select `.venv/bin/python`

**Code Style:**
1. File → Settings → Editor → Code Style → Python
2. Set tab size: 4 spaces
3. Enable "Ensure line feed at file end"

**Inspections (Type Checking):**
1. File → Settings → Editor → Inspections
2. Enable "Type checker" inspections
3. Set severity to "Warning" or "Error"

**External Tools:**
```
# Settings → Tools → External Tools
# Add ruff for formatting

Program: ruff
Arguments: format $FilePath$
Working directory: $ProjectFileDir$
```

**Run Configuration:**
```
# Run → Edit Configurations
# Python script with environment

Script path: src/myproject/__main__.py
Python interpreter: Project Default (.venv)
Working directory: $PROJECT_DIR$
Environment variables: DEBUG=true
```

## Team Configuration
<!-- Lines 115-166 -->

Commit IDE settings for consistent team experience.

**VS Code Structure:**
```
.vscode/
├── settings.json       # Project settings
├── extensions.json     # Recommended extensions
├── launch.json        # Debug configurations
└── tasks.json         # Build tasks
```

**EditorConfig (IDE-Agnostic):**
```ini
# .editorconfig
root = true

[*]
indent_style = space
indent_size = 4
end_of_line = lf
charset = utf-8
trim_trailing_whitespace = true
insert_final_newline = true

[*.md]
trim_trailing_whitespace = false

[*.yaml]
indent_size = 2
```

**What to Commit:**

| File | Commit? | Reason |
|------|---------|--------|
| `.vscode/settings.json` | Yes | Project-specific settings |
| `.vscode/extensions.json` | Yes | Extension recommendations |
| `.vscode/launch.json` | Yes | Debug configurations |
| `.idea/` (PyCharm) | Partial | Project settings only |
| User settings | No | Personal preferences |

**gitignore Additions:**
```gitignore
# User-specific IDE settings
.vscode/settings.local.json
.idea/workspace.xml
.idea/tasks.xml
```

## Debugging Setup
<!-- Lines 169-212 -->

Configure debugging for interactive development and troubleshooting.

**VS Code Launch Configuration:**
```json
// .vscode/launch.json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "debugpy",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal",
            "justMyCode": true
        },
        {
            "name": "Python: Module",
            "type": "debugpy",
            "request": "launch",
            "module": "myproject",
            "console": "integratedTerminal"
        },
        {
            "name": "Pytest: Current Test",
            "type": "debugpy",
            "request": "launch",
            "module": "pytest",
            "args": ["${file}", "-v"],
            "console": "integratedTerminal"
        }
    ]
}
```

**Debug Tips:**
- Set breakpoints by clicking line numbers
- Use `debugpy` for remote debugging
- Conditional breakpoints: Right-click → "Add Conditional Breakpoint"
- Watch expressions: Add in Debug sidebar
