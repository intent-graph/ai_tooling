## Coverage Philosophy
<!-- Lines 16-48 -->

Coverage measures how much code tests exercise. It's a metric, not a goal.

**What Coverage Tells You:**
- Which code paths are untested
- Where to focus testing efforts
- Regression in test coverage over time

**What Coverage Doesn't Tell You:**
- If tests are correct
- If edge cases are covered
- If behavior is properly verified

**Coverage Types:**
| Type | Measures | Example |
|------|----------|---------|
| Line | Lines executed | `coverage run` |
| Branch | Decision paths | `branch = true` |
| Condition | Boolean expressions | Advanced tools |

**Branch Coverage Example:**
```python
def process(x):
    if x > 0:      # Branch: true path
        return x   # Branch: false path never tested without input ≤ 0
    return 0
```

## Configuration
<!-- Lines 51-106 -->

Configure pytest-cov for coverage collection.

**pyproject.toml:**
```toml
[tool.coverage.run]
source = ["src"]
branch = true
omit = [
    "*/tests/*",
    "*/__main__.py",
    "*/migrations/*",
]

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise NotImplementedError",
    "if TYPE_CHECKING:",
    "if __name__ == .__main__.:",
    "@abstractmethod",
]
show_missing = true
fail_under = 80

[tool.coverage.html]
directory = "htmlcov"
```

**Running Coverage:**
```bash
# With pytest
pytest --cov=src --cov-report=html

# With coverage directly
coverage run -m pytest
coverage report
coverage html
```

**CI Configuration:**
```yaml
# .github/workflows/test.yml
- name: Run tests with coverage
  run: pytest --cov=src --cov-report=xml

- name: Upload coverage
  uses: codecov/codecov-action@v3
```

## Interpreting Results
<!-- Lines 109-147 -->

Understand what coverage reports mean.

**Coverage Report:**
```
Name                      Stmts   Miss Branch BrPart  Cover
-----------------------------------------------------------
src/models.py                50      5     12      2    88%
src/services.py              80     20     24      8    72%
src/utils.py                 30      0      8      0   100%
-----------------------------------------------------------
TOTAL                       160     25     44     10    84%
```

**Reading the Numbers:**
- **Stmts**: Total executable statements
- **Miss**: Statements not executed
- **Branch**: Total branch points
- **BrPart**: Partially covered branches
- **Cover**: Overall percentage

**Identifying Gaps:**
```bash
# Show missing lines
coverage report --show-missing

# HTML report with line highlighting
coverage html
open htmlcov/index.html
```

**Common Uncovered Code:**
- Error handling paths
- Edge cases
- Configuration variants
- Debug/logging code

## Coverage Targets
<!-- Lines 150-200 -->

Set realistic coverage targets for your project.

**Target Guidelines:**
| Project Type | Target | Rationale |
|--------------|--------|-----------|
| Library | 90%+ | Public API must work |
| Application | 80%+ | Core paths tested |
| Scripts | 70%+ | Key functionality |
| Prototype | None | Speed over coverage |

**Enforcing Coverage:**
```toml
# pyproject.toml
[tool.coverage.report]
fail_under = 80
```

**Gradual Improvement:**
```yaml
# Ratchet pattern: Coverage can't decrease
- name: Check coverage didn't decrease
  run: |
    current=$(coverage report --format=total)
    if [ "$current" -lt "$MINIMUM_COVERAGE" ]; then
      exit 1
    fi
```

**When to Exclude:**
```python
# Exclude unreachable code
if TYPE_CHECKING:  # pragma: no cover
    from expensive_import import Type

# Exclude defensive code
def process(data):
    if data is None:  # pragma: no cover
        raise RuntimeError("Impossible state")
```

**Focus on Value:**
```python
# High value: Test business logic
def calculate_tax(amount: Decimal, rate: float) -> Decimal:
    ...  # 100% coverage valuable

# Low value: Test framework wrapper
def get_user(id: int) -> User:
    return db.session.get(User, id)  # Coverage less valuable
```
