## Core Concept
<!-- Lines 17-30 -->

Secrets (API keys, passwords, tokens, certificates) must never appear in:
- Source code
- Version control
- Logs
- Error messages
- Client-side code

## Environment Variables
<!-- Lines 33-79 -->

The simplest secrets approach—environment variables.

**Reading:**
```python
import os

DATABASE_URL = os.environ["DATABASE_URL"]
API_KEY = os.environ.get("API_KEY")  # Optional

# With validation
def get_required_env(name: str) -> str:
    value = os.environ.get(name)
    if not value:
        raise ValueError(f"Required env var {name} not set")
    return value
```

**.env Files (development):**
```bash
# .env (NEVER commit)
DATABASE_URL=postgresql://localhost/myapp
API_KEY=dev-key-for-testing
SECRET_KEY=local-dev-secret
```

```python
from dotenv import load_dotenv
load_dotenv()  # Loads .env into os.environ
```

**pydantic-settings:**
```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    database_url: str
    api_key: str
    debug: bool = False

    model_config = {"env_file": ".env"}

settings = Settings()
```

## Secret Managers
<!-- Lines 82-133 -->

For production, use dedicated secret management.

**AWS Secrets Manager:**
```python
import boto3
import json

def get_secret(secret_name: str) -> dict:
    client = boto3.client("secretsmanager")
    response = client.get_secret_value(SecretId=secret_name)
    return json.loads(response["SecretString"])

# Usage
secrets = get_secret("myapp/production")
database_url = secrets["database_url"]
```

**HashiCorp Vault:**
```python
import hvac

client = hvac.Client(url='https://vault.example.com')
client.token = os.environ['VAULT_TOKEN']

secret = client.secrets.kv.read_secret_version(path='myapp/database')
password = secret['data']['data']['password']
```

**Google Secret Manager:**
```python
from google.cloud import secretmanager

client = secretmanager.SecretManagerServiceClient()
name = f"projects/myproject/secrets/api-key/versions/latest"
response = client.access_secret_version(name=name)
api_key = response.payload.data.decode("UTF-8")
```

**Kubernetes Secrets:**
```yaml
apiVersion: v1
kind: Secret
metadata:
  name: myapp-secrets
type: Opaque
stringData:
  DATABASE_URL: postgresql://...
```

## Git Protection
<!-- Lines 136-185 -->

Prevent accidental commits of secrets.

**.gitignore:**
```
# Environment files
.env
.env.local
.env.*.local

# Credentials
*.pem
*.key
credentials.json
secrets.yaml
```

**Pre-commit Hook:**
```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/Yelp/detect-secrets
    rev: v1.4.0
    hooks:
      - id: detect-secrets
        args: ['--baseline', '.secrets.baseline']
```

**git-secrets:**
```bash
git secrets --install
git secrets --register-aws

# Scans for AWS keys on commit
```

**If Secret is Exposed:**
1. **Revoke immediately** (don't wait)
2. Generate new secret
3. Update all usages
4. Audit for unauthorized use
5. Remove from git history:
   ```bash
   git filter-branch --force --index-filter \
       'git rm --cached --ignore-unmatch path/to/secret' \
       HEAD
   ```

## Rotation
<!-- Lines 188-219 -->

Regular secret rotation limits exposure window.

**Rotation Strategy:**
| Secret Type | Rotation Frequency |
|-------------|-------------------|
| API keys | 90 days |
| Database passwords | 30-90 days |
| Session secrets | 30 days |
| Compromised secrets | Immediately |

**Dual-Key Rotation:**
```python
# Support both old and new keys during transition
API_KEYS = [
    os.environ["API_KEY_NEW"],
    os.environ["API_KEY_OLD"],  # Remove after transition
]

def validate_api_key(key: str) -> bool:
    return key in API_KEYS
```

**Automated Rotation:**
```python
# AWS Secrets Manager supports automatic rotation
client.rotate_secret(
    SecretId='myapp/api-key',
    RotationLambdaARN='arn:aws:lambda:...',
    RotationRules={'AutomaticallyAfterDays': 30}
)
```
