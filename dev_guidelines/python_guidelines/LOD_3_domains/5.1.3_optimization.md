## Algorithm Choice
<!-- Lines 36-74 -->

The biggest wins come from better algorithms.

**Common Improvements:**
| From | To | Improvement |
|------|-----|-------------|
| O(n²) | O(n log n) | 100x at n=1000 |
| O(n) search | O(1) lookup | 1000x at n=1000 |
| O(2^n) | O(n²) | Exponential |

**Example: Finding Duplicates**
```python
# O(n²) - Check each pair
def has_duplicates_slow(items):
    for i, a in enumerate(items):
        for b in items[i+1:]:
            if a == b:
                return True
    return False

# O(n) - Use set
def has_duplicates_fast(items):
    return len(items) != len(set(items))
```

**Example: Lookup in List vs Set**
```python
# O(n) per lookup
if item in large_list:  # Scans entire list
    ...

# O(1) per lookup
large_set = set(large_list)  # One-time O(n) conversion
if item in large_set:  # Hash lookup
    ...
```

## Data Structures
<!-- Lines 77-117 -->

Choose data structures for your access patterns.

| Structure | Good For | Bad For |
|-----------|----------|---------|
| `list` | Sequential access, append | Membership, insert at start |
| `set` | Membership, uniqueness | Order, duplicates |
| `dict` | Key-value lookup | Memory-constrained |
| `deque` | Both-ends operations | Random access |
| `heapq` | Min/max tracking | General sorting |

**Example: Frequent Membership Testing**
```python
# Slow: O(n) per test
allowed = ["admin", "user", "guest"]
if role in allowed:  # Scans list
    ...

# Fast: O(1) per test
allowed = {"admin", "user", "guest"}
if role in allowed:  # Hash lookup
    ...
```

**Example: FIFO Queue**
```python
from collections import deque

# Slow: list.pop(0) is O(n)
queue = []
queue.append(item)
item = queue.pop(0)  # Shifts all elements

# Fast: deque.popleft() is O(1)
queue = deque()
queue.append(item)
item = queue.popleft()  # No shifting
```

## Caching
<!-- Lines 120-165 -->

Store computed results to avoid recomputation.

**functools.lru_cache:**
```python
from functools import lru_cache

@lru_cache(maxsize=128)
def expensive_computation(n):
    # Complex calculation
    return result

# First call: computes
expensive_computation(42)

# Second call: returns cached
expensive_computation(42)
```

**When to Cache:**
- Pure functions (same input → same output)
- Expensive computations
- Repeated calls with same arguments

**Cache Invalidation:**
```python
@lru_cache
def get_config(path):
    return load_config(path)

# Clear when config changes
get_config.cache_clear()
```

**Manual Caching:**
```python
_cache = {}

def cached_fetch(url):
    if url not in _cache:
        _cache[url] = requests.get(url).json()
    return _cache[url]
```

## Lazy Evaluation
<!-- Lines 168-210 -->

Compute only what's needed, when it's needed.

**Generators vs Lists:**
```python
# Eager: Creates entire list in memory
data = [transform(x) for x in huge_list]

# Lazy: Computes on demand
data = (transform(x) for x in huge_list)
```

**Lazy Properties:**
```python
class DataLoader:
    def __init__(self, path):
        self.path = path
        self._data = None

    @property
    def data(self):
        if self._data is None:
            self._data = self._load()
        return self._data

    def _load(self):
        return expensive_load(self.path)
```

**functools.cached_property (3.8+):**
```python
from functools import cached_property

class DataLoader:
    @cached_property
    def data(self):
        return expensive_load(self.path)
```

**When to Use:**
- Large data that might not be needed
- Expensive initialization
- Memory-constrained environments
