## Version Selection
<!-- Lines 16-45 -->

**Default Rule:** Use the latest stable Python release for new projects.

**Version Matrix:**

| Python | Status | Use Case |
|--------|--------|----------|
| 3.12 | Current stable | New projects |
| 3.11 | Stable | Production proven |
| 3.10 | Maintenance | Legacy support |
| <3.10 | EOL/near-EOL | Avoid |

**Selection Criteria:**
1. **Production constraints**: Match deployment environment exactly
2. **Library compatibility**: Check critical dependencies support the version
3. **Team alignment**: Use same version across team

**Version Specification:**
```toml
# pyproject.toml
[project]
requires-python = ">=3.11"
```

## pyenv Setup
<!-- Lines 48-92 -->

pyenv manages multiple Python versions without modifying system Python.

**Installation (macOS/Linux):**
```bash
# macOS
brew install pyenv

# Linux
curl https://pyenv.run | bash
```

**Shell Configuration:**
```bash
# Add to ~/.zshrc or ~/.bashrc
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"
```

**Basic Usage:**
```bash
# List available versions
pyenv install --list | grep "^  3\."

# Install specific version
pyenv install 3.12.3

# Set global default
pyenv global 3.12.3

# Set local (per-directory)
pyenv local 3.12.3  # Creates .python-version file
```

**Project Setup Pattern:**
```bash
cd my_project
pyenv local 3.12.3
python -m venv .venv
source .venv/bin/activate
```

## System Python
<!-- Lines 95-129 -->

**Never use system Python for development.**

System Python exists for operating system tools. Installing packages there can break system utilities and create conflicts.

**Identifying System Python:**
```bash
# macOS
/usr/bin/python3        # System Python - don't touch

# Linux (Ubuntu/Debian)
/usr/bin/python3        # System Python - don't touch

# Your development Python (via pyenv)
~/.pyenv/versions/3.12.3/bin/python
```

**Why Isolation:**
- OS updates may change system Python
- Package conflicts break system tools
- No control over version

**Warning Signs:**
```bash
# BAD: Using system Python
which python3
/usr/bin/python3

# GOOD: Using managed Python
which python3
/Users/you/.pyenv/shims/python3
```

## Multiple Versions
<!-- Lines 132-175 -->

Testing against multiple Python versions ensures compatibility.

**pyenv for Multiple Versions:**
```bash
# Install multiple versions
pyenv install 3.11.9
pyenv install 3.12.3

# Make both available
pyenv global 3.12.3 3.11.9

# Now available as:
python3.12 --version
python3.11 --version
```

**tox for Multi-Version Testing:**
```toml
# pyproject.toml
[tool.tox]
envlist = ["py311", "py312"]

[tool.tox.env_run_base]
deps = ["pytest"]
commands = [["pytest"]]
```

**CI Matrix:**
```yaml
# .github/workflows/test.yml
jobs:
  test:
    strategy:
      matrix:
        python-version: ["3.11", "3.12"]
    steps:
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
```
