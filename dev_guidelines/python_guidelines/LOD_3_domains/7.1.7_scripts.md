## Core Concept
<!-- Lines 28-49 -->

**Definition:** Scripts are small programs that automate tasks—deployment, data migration, system administration, file processing. They're often written quickly but may run for years.

**Script vs Application:**
| Aspect | Script | Application |
|--------|--------|-------------|
| Lifetime | "Temporary" (often permanent) | Planned long-term |
| Users | You, your team | Broader audience |
| Polish | Minimal | High |
| Tests | Optional | Required |

**Key Priorities:**
1. Works reliably
2. Easy to understand later
3. Safe to re-run (idempotent when possible)
4. Logs what it did

### Basic Template
<!-- Lines 55-107 -->

```python
#!/usr/bin/env python3
"""Short description of what this script does.

Usage:
    python script.py --input data.csv --output results.csv
"""

import argparse
import logging
import sys
from pathlib import Path

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)
logger = logging.getLogger(__name__)


def main(input_path: Path, output_path: Path) -> int:
    """Main logic. Returns exit code."""
    logger.info(f"Processing {input_path}")

    try:
        data = input_path.read_text()
        result = process(data)
        output_path.write_text(result)
        logger.info(f"Wrote results to {output_path}")
        return 0
    except FileNotFoundError:
        logger.error(f"Input file not found: {input_path}")
        return 1
    except Exception as e:
        logger.exception(f"Unexpected error: {e}")
        return 1


def process(data: str) -> str:
    """Core transformation logic."""
    return data.upper()


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--input", type=Path, required=True)
    parser.add_argument("--output", type=Path, required=True)
    args = parser.parse_args()

    sys.exit(main(args.input, args.output))
```

def delete_old_files(directory: Path, days: int, dry_run: bool = False):
    cutoff = datetime.now() - timedelta(days=days)

    for path in directory.iterdir():
        if path.stat().st_mtime < cutoff.timestamp():
            if dry_run:
                logger.info(f"Would delete: {path}")
            else:
                path.unlink()
                logger.info(f"Deleted: {path}")

### Idempotency
<!-- Lines 154-168 -->

```python
def ensure_directory(path: Path):
    """Create directory if it doesn't exist (idempotent)."""
    path.mkdir(parents=True, exist_ok=True)

def copy_if_different(src: Path, dst: Path):
    """Copy only if content differs (idempotent)."""
    if dst.exists() and src.read_bytes() == dst.read_bytes():
        logger.debug(f"Skipping {dst} (unchanged)")
        return
    shutil.copy2(src, dst)
    logger.info(f"Copied {src} to {dst}")
```

### Graceful Interruption
<!-- Lines 171-191 -->

```python
import signal

shutdown_requested = False

def handle_signal(signum, frame):
    global shutdown_requested
    logger.info("Shutdown requested, finishing current item...")
    shutdown_requested = True

signal.signal(signal.SIGINT, handle_signal)
signal.signal(signal.SIGTERM, handle_signal)

for item in items:
    if shutdown_requested:
        logger.info("Exiting early")
        break
    process(item)
```

## When to Graduate
<!-- Lines 213-213 -->

### Signs You Need More Structure
<!-- Lines 216-226 -->

```markdown
When your script has:
- Multiple files sharing code → Package
- Complex configuration → Config file/class
- Users besides you → CLI framework, docs
- >200 lines → Modules
- Needs tests → pytest, proper structure
- Runs in production → Monitoring, error handling
```
