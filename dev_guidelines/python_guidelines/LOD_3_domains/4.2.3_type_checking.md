## Core Concept
<!-- Lines 17-39 -->

Type checkers verify that your type annotations are consistent. They catch bugs at development time:

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

greet(123)  # Type checker error: expected str, got int
```

**Tool Options:**
- **mypy**: Original, most widely used
- **pyright**: Microsoft, faster, better inference

Most projects use mypy; pyright is excellent for VSCode integration.

## mypy Configuration
<!-- Lines 42-87 -->

```toml
[tool.mypy]
python_version = "3.10"

# Strictness
strict = true
warn_return_any = true
warn_unused_ignores = true
warn_redundant_casts = true

# Error output
show_error_codes = true
show_column_numbers = true
pretty = true

# Plugins (optional)
plugins = ["pydantic.mypy"]

# Per-module overrides
[[tool.mypy.overrides]]
module = "tests.*"
disallow_untyped_defs = false

[[tool.mypy.overrides]]
module = "mypackage.legacy.*"
ignore_errors = true
```

**Running mypy:**
```bash
mypy src/                    # Check src directory
mypy src/ --strict           # Strict mode
mypy src/ --show-error-codes # Show error codes
```

**Key Options:**
| Option | Effect |
|--------|--------|
| `strict` | Enable all strictness flags |
| `disallow_untyped_defs` | Require type hints on all functions |
| `warn_return_any` | Warn on functions returning `Any` |
| `ignore_missing_imports` | Suppress errors for untyped packages |

## Strictness Levels
<!-- Lines 90-138 -->

**Gradual Typing Progression:**

**Level 1: Minimal (legacy code)**
```toml
[tool.mypy]
check_untyped_defs = true
```
- Checks typed code only
- Untyped functions not checked

**Level 2: Moderate**
```toml
[tool.mypy]
check_untyped_defs = true
disallow_untyped_defs = true
```
- Requires type hints on new code
- Existing untyped code causes errors

**Level 3: Strict**
```toml
[tool.mypy]
strict = true
```
- All checks enabled
- No implicit `Any`
- Full type coverage

**Per-module Configuration:**
```toml
# Strict for new code
[[tool.mypy.overrides]]
module = "mypackage.new_module"
strict = true

# Lenient for tests
[[tool.mypy.overrides]]
module = "tests.*"
disallow_untyped_defs = false

# Ignore problematic legacy
[[tool.mypy.overrides]]
module = "mypackage.legacy"
ignore_errors = true
```

## Common Patterns
<!-- Lines 141-181 -->

**Type Narrowing:**
```python
def process(value: str | None) -> str:
    if value is None:
        return "default"
    return value.upper()  # mypy knows value is str
```

**Type Ignore:**
```python
# With error code (preferred)
result = external_api()  # type: ignore[no-untyped-call]

# With explanation (best)
result = external_api()  # type: ignore[no-untyped-call] - Legacy API

# Blanket ignore (avoid)
result = external_api()  # type: ignore
```

**Cast (use sparingly):**
```python
from typing import cast

data = json.loads(response)  # dict[str, Any]
user = cast(UserDict, data)  # Trust me, it's a UserDict
```

**reveal_type (debugging):**
```python
reveal_type(result)  # mypy shows: Revealed type is "str"
```

**Type Assertions:**
```python
assert isinstance(value, str)  # mypy narrows type after this
```

## Third-party Types
<!-- Lines 184-226 -->

Many packages lack type annotations. Solutions:

**1. Type Stub Packages:**
```bash
pip install types-requests types-redis types-PyYAML
```

**2. mypy Configuration:**
```toml
[tool.mypy]
ignore_missing_imports = true  # Global (not recommended)

[[tool.mypy.overrides]]
module = "untyped_package.*"
ignore_missing_imports = true  # Per-package (better)
```

**3. Inline Stubs:**
```python
# mypackage/py.typed  # Marker file

# mypackage/stubs/untyped.pyi
def some_function(x: int) -> str: ...
```

**Finding Stubs:**
```bash
# Search for available stubs
pip search types-

# Common stubs
types-requests
types-redis
types-PyYAML
types-python-dateutil
```

**mypy Daemon (faster):**
```bash
dmypy run -- src/  # Incremental checking
dmypy stop         # Stop daemon
```
