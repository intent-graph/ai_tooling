## Directory Structure
<!-- Lines 16-62 -->

Organize tests to mirror source structure.

**Standard Layout:**
```
project/
├── src/
│   └── mypackage/
│       ├── models.py
│       ├── services.py
│       └── utils/
│           └── helpers.py
└── tests/
    ├── conftest.py
    ├── unit/
    │   ├── test_models.py
    │   ├── test_services.py
    │   └── utils/
    │       └── test_helpers.py
    └── integration/
        ├── conftest.py
        └── test_api.py
```

**Mirroring Source:**
```
src/mypackage/models.py
tests/unit/test_models.py

src/mypackage/services/user.py
tests/unit/services/test_user.py
```

**Separation by Type:**
```
tests/
├── unit/           # Fast, isolated tests
├── integration/    # Component interaction tests
├── e2e/           # End-to-end tests
└── fixtures/      # Shared test data
```

## Naming Conventions
<!-- Lines 65-122 -->

Consistent naming makes tests discoverable and descriptive.

**File Naming:**
```python
# Pattern: test_<module>.py
test_models.py
test_user_service.py
test_authentication.py
```

**Function Naming:**
```python
# Pattern: test_<unit>_<scenario>
def test_user_creation():
    ...

# More specific: test_<unit>_<scenario>_<expected>
def test_user_with_invalid_email_raises_validation_error():
    ...

def test_calculate_total_with_discount_returns_reduced_price():
    ...
```

**Class Naming:**
```python
# Pattern: Test<ClassName>
class TestUser:
    def test_creation(self):
        ...

    def test_full_name(self):
        ...

class TestUserRepository:
    def test_save(self):
        ...
```

**Descriptive Names:**
```python
# GOOD: Describes behavior
def test_expired_token_is_rejected():
def test_admin_can_delete_any_user():
def test_rate_limit_returns_429_after_threshold():

# BAD: Vague
def test_token():
def test_delete():
def test_rate_limit():
```

## Test Discovery
<!-- Lines 125-168 -->

pytest automatically discovers tests following conventions.

**Discovery Rules:**
- Files matching `test_*.py` or `*_test.py`
- Classes starting with `Test` (no `__init__`)
- Functions starting with `test_`

**pytest Configuration:**
```toml
# pyproject.toml
[tool.pytest.ini_options]
testpaths = ["tests"]
python_files = ["test_*.py"]
python_classes = ["Test*"]
python_functions = ["test_*"]
```

**Running Specific Tests:**
```bash
# All tests
pytest

# Specific file
pytest tests/unit/test_models.py

# Specific test
pytest tests/unit/test_models.py::test_user_creation

# Specific class
pytest tests/unit/test_models.py::TestUser

# Pattern matching
pytest -k "user and not slow"
```

**Collection Only:**
```bash
# Show what would run
pytest --collect-only
```

## Test Markers
<!-- Lines 171-229 -->

Markers categorize tests for selective execution.

**Built-in Markers:**
```python
import pytest

@pytest.mark.skip(reason="Not implemented yet")
def test_future_feature():
    ...

@pytest.mark.skipif(sys.platform == "win32", reason="Unix only")
def test_unix_specific():
    ...

@pytest.mark.xfail(reason="Known bug #123")
def test_known_failure():
    ...
```

**Custom Markers:**
```toml
# pyproject.toml
[tool.pytest.ini_options]
markers = [
    "slow: marks tests as slow (deselect with '-m \"not slow\"')",
    "integration: integration tests",
    "smoke: smoke tests for CI",
]
```

```python
@pytest.mark.slow
def test_large_data_processing():
    ...

@pytest.mark.integration
def test_database_connection():
    ...
```

**Running by Marker:**
```bash
# Run only slow tests
pytest -m slow

# Run everything except slow
pytest -m "not slow"

# Combine markers
pytest -m "integration and not slow"
```

**Marker Enforcement:**
```toml
# Require markers to be defined
[tool.pytest.ini_options]
addopts = "--strict-markers"
```
