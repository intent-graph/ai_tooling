## README Purpose
<!-- Lines 18-39 -->

The README is the first thing people see. It should answer:
- What is this?
- How do I install it?
- How do I use it?

**README Goals:**
- Communicate value quickly
- Enable quick start (< 5 minutes)
- Point to more resources

**Who Reads READMEs:**
- Potential users evaluating the project
- New users getting started
- Contributors looking to help
- Future you remembering how this works

## Essential Sections
<!-- Lines 42-102 -->

Every README should have these sections.

**Template:**
```markdown
# Project Name

One-line description of what the project does.

## Installation
<!-- Lines 62-66 -->

```bash
pip install project-name
```

## Quick Start
<!-- Lines 69-76 -->

```python
from project_name import main_function

result = main_function("input")
print(result)
```

## Features
<!-- Lines 79-83 -->

- Feature 1: Brief description
- Feature 2: Brief description
- Feature 3: Brief description

## Documentation
<!-- Lines 86-88 -->

Full documentation: https://project-name.readthedocs.io

## License
<!-- Lines 91-111 -->

MIT License - see [LICENSE](LICENSE) for details.
```

**Name + Description:**
- Clear, memorable name
- One sentence explaining what it does
- Who it's for (optional)

**Installation:**
- Primary method (usually pip)
- Alternative methods if relevant
- System requirements

**Quick Start:**
- Working code example
- Minimal setup
- Demonstrates core value

## Badges
<!-- Lines 163-197 -->

Badges communicate project status at a glance.

**Common Badges:**
```markdown
[![PyPI version](https://badge.fury.io/py/project-name.svg)](https://pypi.org/project/project-name/)
[![Python Version](https://img.shields.io/pypi/pyversions/project-name)](https://pypi.org/project/project-name/)
[![Tests](https://github.com/user/project/workflows/Tests/badge.svg)](https://github.com/user/project/actions)
[![Coverage](https://codecov.io/gh/user/project/branch/main/graph/badge.svg)](https://codecov.io/gh/user/project)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
```

**Badge Categories:**

| Category | Examples |
|----------|----------|
| Version | PyPI, npm, GitHub release |
| Build | GitHub Actions, Travis CI |
| Coverage | Codecov, Coveralls |
| Quality | Code Climate, Codacy |
| License | MIT, Apache, GPL |
| Downloads | PyPI downloads |

**Badge Best Practices:**
- Keep to one line if possible
- Include only meaningful badges
- Ensure badges are current
- Link badges to relevant pages

**Example Badge Line:**
```markdown
[![PyPI](https://img.shields.io/pypi/v/myproject)](https://pypi.org/project/myproject/)
[![Tests](https://github.com/user/myproject/actions/workflows/tests.yml/badge.svg)](https://github.com/user/myproject/actions)
[![Coverage](https://codecov.io/gh/user/myproject/branch/main/graph/badge.svg)](https://codecov.io/gh/user/myproject)
```
