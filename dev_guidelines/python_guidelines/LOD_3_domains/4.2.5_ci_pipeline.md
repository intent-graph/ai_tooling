## Core Concept
<!-- Lines 17-33 -->

CI (Continuous Integration) runs automated checks on every push and pull request. It's the authoritative quality gate—code that fails CI doesn't merge.

**CI Goals:**
- Catch bugs before they reach main branch
- Enforce code quality standards
- Test across Python versions/platforms
- Automate release processes

**Key Principle:** Fast feedback. Developers should know within minutes if their changes break anything.

## Pipeline Structure
<!-- Lines 36-73 -->

**Typical Pipeline Stages:**

```
Push → Lint → Type Check → Test → Build → (Deploy)
         ↓        ↓          ↓       ↓
       Fast    Medium      Slow   Optional
```

**Stage Purposes:**
| Stage | Purpose | Fails On |
|-------|---------|----------|
| Lint | Style enforcement | Formatting, style issues |
| Type Check | Type consistency | Type errors |
| Test | Correctness | Failed tests |
| Build | Packaging | Build errors |
| Deploy | Release | Upload failures |

**Job Independence:**
Run independent jobs in parallel:
```yaml
jobs:
  lint:     # Parallel
  typecheck: # Parallel
  test:     # Parallel
  build:
    needs: [lint, typecheck, test]  # Sequential
```

**Fail Fast:**
Stop the workflow immediately on first failure in PR contexts:
```yaml
strategy:
  fail-fast: true
```

## GitHub Actions
<!-- Lines 76-133 -->

**Complete CI Workflow:**
```yaml
name: CI
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v1
      - run: uv sync --dev
      - run: uv run ruff check .
      - run: uv run ruff format --check .

  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v1
      - run: uv sync --dev
      - run: uv run mypy src

  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python: ["3.10", "3.11", "3.12"]
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v1
      - run: uv python install ${{ matrix.python }}
      - run: uv sync --dev
      - run: uv run pytest --cov=src

  build:
    needs: [lint, typecheck, test]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: pip install build
      - run: python -m build
      - uses: actions/upload-artifact@v4
        with:
          name: dist
          path: dist/
```

## Test Matrix
<!-- Lines 136-182 -->

Test across Python versions and platforms.

**Version Matrix:**
```yaml
strategy:
  matrix:
    python: ["3.10", "3.11", "3.12"]
    os: [ubuntu-latest, macos-latest, windows-latest]
  fail-fast: false  # Run all combinations
```

**Exclude Combinations:**
```yaml
strategy:
  matrix:
    python: ["3.10", "3.11", "3.12"]
    os: [ubuntu-latest, macos-latest, windows-latest]
    exclude:
      - python: "3.10"
        os: windows-latest
```

**Include Special Cases:**
```yaml
strategy:
  matrix:
    python: ["3.10", "3.11"]
    include:
      - python: "3.12"
        os: ubuntu-latest
        experimental: true
```

**Conditional Steps:**
```yaml
- name: Windows-specific setup
  if: runner.os == 'Windows'
  run: choco install something

- name: Coverage upload (main only)
  if: github.ref == 'refs/heads/main'
  run: codecov
```

## Optimization
<!-- Lines 185-240 -->

**Caching Dependencies:**
```yaml
- uses: actions/cache@v4
  with:
    path: ~/.cache/uv
    key: uv-${{ runner.os }}-${{ hashFiles('uv.lock') }}
    restore-keys: |
      uv-${{ runner.os }}-
```

**Selective Runs:**
```yaml
on:
  push:
    paths:
      - 'src/**'
      - 'tests/**'
      - 'pyproject.toml'
    paths-ignore:
      - '**.md'
      - 'docs/**'
```

**Concurrency (cancel outdated runs):**
```yaml
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true
```

**Reusable Workflows:**
```yaml
# .github/workflows/reusable-test.yml
on:
  workflow_call:
    inputs:
      python-version:
        required: true
        type: string

# .github/workflows/ci.yml
jobs:
  test:
    uses: ./.github/workflows/reusable-test.yml
    with:
      python-version: "3.11"
```

**Timing Targets:**
| Stage | Target |
|-------|--------|
| Lint | < 30 seconds |
| Type check | < 2 minutes |
| Tests | < 5 minutes |
| Full pipeline | < 10 minutes |
