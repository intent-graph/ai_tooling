## Property Testing Concept
<!-- Lines 16-44 -->

Property-based testing verifies that properties hold for any valid input.

**Example-Based vs Property-Based:**
```python
# Example-based: Specific inputs
def test_sort_example():
    assert sorted([3, 1, 2]) == [1, 2, 3]

# Property-based: Any input
@given(st.lists(st.integers()))
def test_sort_property(lst):
    result = sorted(lst)
    assert len(result) == len(lst)         # Length preserved
    assert all(a <= b for a, b in zip(result, result[1:]))  # Ordered
```

**Properties to Test:**
- Invariants (length preserved, sum preserved)
- Idempotence (f(f(x)) == f(x))
- Roundtrip (decode(encode(x)) == x)
- Commutativity (f(a, b) == f(b, a))
- Associativity (f(f(a, b), c) == f(a, f(b, c)))

## Hypothesis Basics
<!-- Lines 47-105 -->

Hypothesis is Python's property-based testing library.

**Installation:**
```bash
pip install hypothesis
```

**Basic Usage:**
```python
from hypothesis import given, strategies as st

@given(st.integers())
def test_integer_property(n):
    assert abs(n) >= 0
```

**Multiple Arguments:**
```python
@given(st.integers(), st.integers())
def test_addition_commutative(a, b):
    assert a + b == b + a
```

**Controlling Generation:**
```python
from hypothesis import settings, Verbosity

@settings(max_examples=1000)
@given(st.text())
def test_with_more_examples(s):
    ...

@settings(verbosity=Verbosity.verbose)
@given(st.integers())
def test_verbose(n):
    ...
```

**Reproducing Failures:**
```python
# Hypothesis remembers failures
# Run same test to reproduce

# Or use explicit example
from hypothesis import example

@given(st.integers())
@example(0)  # Always test zero
@example(-1)  # Always test negative
def test_with_examples(n):
    ...
```

## Strategies
<!-- Lines 108-166 -->

Strategies define how to generate test data.

**Primitive Strategies:**
```python
from hypothesis import strategies as st

st.integers()               # Any integer
st.integers(min_value=0)    # Non-negative
st.floats()                 # Any float
st.floats(allow_nan=False)  # Exclude NaN
st.text()                   # Unicode strings
st.binary()                 # Bytes
st.booleans()               # True/False
```

**Collection Strategies:**
```python
st.lists(st.integers())                    # List of integers
st.lists(st.integers(), min_size=1)        # Non-empty list
st.sets(st.integers())                     # Set of integers
st.dictionaries(st.text(), st.integers())  # Dict[str, int]
st.tuples(st.integers(), st.text())        # Tuple[int, str]
```

**Composite Strategies:**
```python
# From type
@dataclass
class User:
    name: str
    age: int

st.from_type(User)  # Generates User instances

# Custom composite
@st.composite
def user_strategy(draw):
    name = draw(st.text(min_size=1, max_size=50))
    age = draw(st.integers(min_value=0, max_value=150))
    return User(name=name, age=age)

@given(user_strategy())
def test_user(user):
    ...
```

**Filtering and Mapping:**
```python
# Filter
even_integers = st.integers().filter(lambda x: x % 2 == 0)

# Map
positive_integers = st.integers(min_value=1)
user_ids = positive_integers.map(UserId)
```

## When to Use
<!-- Lines 169-214 -->

Property-based testing excels in specific scenarios.

**Good Candidates:**
- **Serialization**: `deserialize(serialize(x)) == x`
- **Sorting/Ordering**: Invariants on sorted data
- **Parsing**: Valid input produces valid output
- **Math functions**: Algebraic properties
- **Data structures**: Invariants maintained

**Examples:**
```python
# JSON roundtrip
@given(st.text())
def test_json_roundtrip(s):
    assert json.loads(json.dumps(s)) == s

# Sorting idempotent
@given(st.lists(st.integers()))
def test_sort_idempotent(lst):
    assert sorted(sorted(lst)) == sorted(lst)

# Reverse twice is identity
@given(st.lists(st.integers()))
def test_reverse_involution(lst):
    assert list(reversed(list(reversed(lst)))) == lst
```

**Not Ideal For:**
- Tests requiring specific setup
- Behavior dependent on external state
- Complex business rules (hard to express as properties)

**Combining with Example-Based:**
```python
# Use both approaches
def test_specific_case():
    """Test known edge case."""
    assert process("special") == expected

@given(st.text())
def test_general_property(s):
    """Property holds for all inputs."""
    result = process(s)
    assert is_valid(result)
```
