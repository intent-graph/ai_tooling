## Core Concept
<!-- Lines 29-49 -->

**Definition:** Data pipelines extract data from sources, transform it, and load it into destinations. They run on schedules or triggers and must be reliable.

**Key Properties:**
- **Idempotent:** Safe to re-run without duplicates
- **Observable:** Know what happened, when, why
- **Recoverable:** Handle failures gracefully
- **Testable:** Validate logic independent of I/O

**Pipeline Categories:**
| Type | Frequency | Volume | Example |
|------|-----------|--------|---------|
| Batch | Scheduled | Large | Daily ETL |
| Streaming | Continuous | Varies | Event processing |
| Micro-batch | Minutes | Medium | Near-real-time |

## Framework Comparison

### Prefect
<!-- Lines 55-80 -->

```python
from prefect import flow, task

@task
def extract(source: str) -> list[dict]:
    return fetch_data(source)

@task
def transform(data: list[dict]) -> list[dict]:
    return [clean(record) for record in data]

@task
def load(data: list[dict], target: str):
    write_data(data, target)

@flow(name="ETL Pipeline")
def etl_pipeline(source: str, target: str):
    data = extract(source)
    cleaned = transform(data)
    load(cleaned, target)
```

**Pros:** Modern, Pythonic, good local development
**Cons:** Newer ecosystem

### Data Validation
<!-- Lines 188-212 -->

```python
from pydantic import BaseModel, validator

class UserRecord(BaseModel):
    id: int
    email: str
    created_at: datetime

    @validator("email")
    def email_valid(cls, v):
        if "@" not in v:
            raise ValueError("Invalid email")
        return v.lower()

def validate_batch(records: list[dict]) -> tuple[list, list]:
    valid, invalid = [], []
    for record in records:
        try:
            valid.append(UserRecord(**record))
        except ValidationError as e:
            invalid.append({"record": record, "error": str(e)})
    return valid, invalid
```

### Logging

```python
import structlog

logger = structlog.get_logger()

@task
def process_batch(batch_id: str, records: list[dict]):
    logger.info(
        "processing_batch",
        batch_id=batch_id,
        record_count=len(records)
    )
    processed = transform(records)
    logger.info(
        "batch_complete",
        batch_id=batch_id,
        processed_count=len(processed)
    )
    return processed
```
