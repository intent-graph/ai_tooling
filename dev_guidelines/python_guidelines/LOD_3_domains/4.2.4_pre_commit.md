## Core Concept
<!-- Lines 17-31 -->

Pre-commit runs checks automatically before each git commit. It catches issues at the earliest possible point—before code enters the repository.

**Benefits:**
- Instant feedback during development
- Prevents committing broken code
- Enforces team standards automatically
- Reduces CI failures

## Setup
<!-- Lines 34-82 -->

**Installation:**
```bash
pip install pre-commit
```

**Initialize in Repository:**
```bash
# Install hooks
pre-commit install

# Run against all files (first time)
pre-commit run --all-files
```

**Basic .pre-commit-config.yaml:**
```yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.1.6
    hooks:
      - id: ruff
        args: [--fix]
      - id: ruff-format

  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.7.0
    hooks:
      - id: mypy
        additional_dependencies:
          - types-requests
          - pydantic

  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files
```

**Update Hook Versions:**
```bash
pre-commit autoupdate
```

## Hook Configuration
<!-- Lines 85-136 -->

**Hook Options:**
```yaml
hooks:
  - id: ruff
    args: [--fix, --exit-non-zero-on-fix]
    files: \.py$
    exclude: ^tests/fixtures/
    stages: [commit]
    pass_filenames: true
```

**Key Parameters:**
| Parameter | Purpose |
|-----------|---------|
| `args` | Command-line arguments |
| `files` | Regex of files to run on |
| `exclude` | Regex of files to skip |
| `stages` | When to run (commit, push, manual) |
| `pass_filenames` | Pass changed files as args |
| `additional_dependencies` | Extra packages to install |

**Stage-specific Hooks:**
```yaml
# Run slow checks only on push
- id: mypy
  stages: [push]

# Run security scan manually
- id: bandit
  stages: [manual]
```

**Running Manual Hooks:**
```bash
pre-commit run bandit --all-files
```

**Local Hooks:**
```yaml
- repo: local
  hooks:
    - id: pytest
      name: pytest
      entry: pytest
      language: system
      types: [python]
      pass_filenames: false
```

## Hook Ordering
<!-- Lines 139-175 -->

Order hooks from fast to slow, formatters before linters.

**Recommended Order:**
```yaml
repos:
  # 1. Quick fixes (formatting)
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.1.6
    hooks:
      - id: ruff-format  # Fast formatter

  # 2. Linting with auto-fix
      - id: ruff
        args: [--fix]

  # 3. General file checks
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer

  # 4. Type checking (slow)
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.7.0
    hooks:
      - id: mypy
```

**Why Order Matters:**
- Formatters may fix linter issues
- Fast checks fail early
- Slow checks run only if fast checks pass

## CI Integration
<!-- Lines 178-220 -->

Run pre-commit in CI to catch skipped hooks.

**GitHub Actions:**
```yaml
name: Pre-commit
on: [push, pull_request]

jobs:
  pre-commit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - uses: pre-commit/action@v3.0.0
```

**Caching (faster CI):**
```yaml
- uses: actions/cache@v3
  with:
    path: ~/.cache/pre-commit
    key: pre-commit-${{ hashFiles('.pre-commit-config.yaml') }}
```

**Skipping Hooks (emergencies only):**
```bash
git commit --no-verify -m "emergency fix"
```

**Troubleshooting:**
```bash
# Clear cache
pre-commit clean

# Reinstall hooks
pre-commit install --install-hooks

# Debug specific hook
pre-commit run ruff --verbose
```
