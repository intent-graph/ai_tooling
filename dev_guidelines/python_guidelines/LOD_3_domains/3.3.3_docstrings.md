## Docstring Basics
<!-- Lines 16-56 -->

Docstrings document the interface, not the implementation.

**What to Document:**
- All public modules, classes, functions, methods
- Complex private functions
- Anything with non-obvious behavior

**What NOT to Document:**
- Obvious implementations
- Internal helpers (unless complex)
- Properties that are self-explanatory

**Docstring Placement:**
```python
"""Module docstring."""

class MyClass:
    """Class docstring."""

    def method(self):
        """Method docstring."""
        pass

def function():
    """Function docstring."""
    pass
```

**One-Line Docstrings:**
```python
def square(n: int) -> int:
    """Return n squared."""
    return n * n
```

## Google Style
<!-- Lines 59-129 -->

Google style is readable and widely supported.

**Function Docstring:**
```python
def fetch_user(
    user_id: int,
    include_inactive: bool = False,
) -> User | None:
    """Fetch a user by ID.

    Retrieves a user from the database, optionally including
    inactive users in the search.

    Args:
        user_id: The unique identifier of the user.
        include_inactive: Whether to include deactivated users.
            Defaults to False.

    Returns:
        The User object if found, None otherwise.

    Raises:
        DatabaseError: If the database connection fails.
        ValueError: If user_id is negative.

    Example:
        >>> user = fetch_user(123)
        >>> user.name
        'Alice'
    """
```

**Class Docstring:**
```python
class UserRepository:
    """Repository for User persistence operations.

    Handles all database operations for User entities,
    including CRUD operations and queries.

    Attributes:
        session: SQLAlchemy session for database access.
        cache: Optional cache for read operations.

    Example:
        >>> repo = UserRepository(session)
        >>> user = repo.get(123)
    """
```

**Module Docstring:**
```python
"""User management module.

This module provides functionality for user authentication,
authorization, and profile management.

Typical usage:
    from myapp.users import UserService

    service = UserService()
    user = service.authenticate("user@example.com", "password")
"""
```

## NumPy Style
<!-- Lines 132-183 -->

NumPy style is common in scientific Python.

**Function Docstring:**
```python
def calculate_statistics(data: np.ndarray) -> dict:
    """
    Calculate descriptive statistics for input data.

    Parameters
    ----------
    data : np.ndarray
        Input array of numerical values. Must be 1-dimensional.

    Returns
    -------
    dict
        Dictionary containing:
        - 'mean': float, arithmetic mean
        - 'std': float, standard deviation
        - 'min': float, minimum value
        - 'max': float, maximum value

    Raises
    ------
    ValueError
        If data is empty or not 1-dimensional.

    See Also
    --------
    numpy.mean : Compute arithmetic mean.
    numpy.std : Compute standard deviation.

    Examples
    --------
    >>> data = np.array([1, 2, 3, 4, 5])
    >>> stats = calculate_statistics(data)
    >>> stats['mean']
    3.0
    """
```

**When to Use NumPy Style:**
- Scientific/numerical libraries
- Projects using NumPy/SciPy
- Team prefers NumPy style

## Docstring Content
<!-- Lines 186-243 -->

What to include in docstrings.

**Summary Line:**
- First line, imperative mood
- Complete sentence
- Fits on one line

```python
"""Return the user's full name."""      # Good
"""Returns the user's full name."""     # Avoid (not imperative)
"""This function returns the..."""      # Avoid (verbose)
```

**Args/Parameters:**
- Name and type
- Description of purpose
- Default value if applicable
- Constraints (must be positive, etc.)

**Returns:**
- Type of return value
- Description of what's returned
- None if applicable

**Raises:**
- Exception types that can be raised
- Conditions that cause each exception

**Examples:**
- Working code that can be tested
- Use `>>>` for interactive examples
- Show expected output

```python
def divide(a: float, b: float) -> float:
    """Divide a by b.

    Args:
        a: Numerator.
        b: Denominator. Must not be zero.

    Returns:
        Result of a / b.

    Raises:
        ZeroDivisionError: If b is zero.

    Example:
        >>> divide(10, 2)
        5.0
        >>> divide(1, 0)
        Traceback (most recent call last):
            ...
        ZeroDivisionError: division by zero
    """
    return a / b
```
