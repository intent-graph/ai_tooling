> When and how to use inheritance.

## When to Inherit
<!-- Lines 17-27 -->

```python
# Good: True "is-a" relationship
class Animal:
    def speak(self) -> str: ...

class Dog(Animal):
    def speak(self) -> str:
        return "Woof"
```

## Abstract Base Classes
<!-- Lines 30-48 -->

```python
from abc import ABC, abstractmethod

class Repository(ABC):
    @abstractmethod
    def get(self, id: int) -> Entity: ...

    @abstractmethod
    def save(self, entity: Entity) -> None: ...

class UserRepository(Repository):
    def get(self, id: int) -> User:
        return db.query(User).get(id)

    def save(self, user: User) -> None:
        db.add(user)
```

## Prefer Composition
<!-- Lines 51-63 -->

```python
# Instead of inheriting
class FileLogger(Logger): ...

# Compose
class Logger:
    def __init__(self, writer: Writer):
        self.writer = writer

logger = Logger(FileWriter())
```

## Mixin Pattern
<!-- Lines 66-76 -->

```python
class TimestampMixin:
    created_at: datetime
    updated_at: datetime

@dataclass
class User(TimestampMixin):
    name: str
```
