## Basic Mock
<!-- Lines 17-30 -->

```python
from unittest.mock import Mock

def test_send_notification():
    mock_client = Mock()
    mock_client.send.return_value = True

    result = send_notification("Hello", client=mock_client)

    mock_client.send.assert_called_once_with("Hello")
    assert result is True
```

## Patch Decorator
<!-- Lines 33-45 -->

```python
from unittest.mock import patch

@patch('mymodule.external_api.fetch')
def test_process_data(mock_fetch):
    mock_fetch.return_value = {"data": [1, 2, 3]}

    result = process_data()

    assert result == [1, 2, 3]
```

## Patch Context Manager
<!-- Lines 48-56 -->

```python
def test_current_time():
    with patch('mymodule.datetime') as mock_dt:
        mock_dt.now.return_value = datetime(2024, 1, 1)
        result = get_current_time()
        assert result.year == 2024
```

## Mock Side Effects
<!-- Lines 59-65 -->

```python
mock = Mock()
mock.fetch.side_effect = [1, 2, 3]  # Return sequence
mock.fetch.side_effect = ValueError  # Raise exception
```
