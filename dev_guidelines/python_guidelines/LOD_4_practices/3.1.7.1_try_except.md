## Basic Pattern
<!-- Lines 17-24 -->

```python
try:
    result = risky_operation()
except SpecificError as e:
    handle_error(e)
```

## Multiple Exceptions
<!-- Lines 27-37 -->

```python
try:
    data = fetch_and_parse(url)
except RequestError:
    return default_data()
except ParseError as e:
    log.error(f"Parse failed: {e}")
    raise
```

## else and finally
<!-- Lines 40-51 -->

```python
try:
    file = open(path)
except FileNotFoundError:
    return None
else:
    data = file.read()  # Only if no exception
finally:
    file.close()  # Always runs
```

## Anti-Patterns
<!-- Lines 54-70 -->

```python
# BAD: Bare except
try:
    do_something()
except:  # Catches KeyboardInterrupt!
    pass

# BAD: Too broad
except Exception:
    pass

# GOOD: Specific exceptions
except (ValueError, KeyError) as e:
    handle_error(e)
```
