## Defining Protocols
<!-- Lines 17-27 -->

```python
from typing import Protocol

class Readable(Protocol):
    def read(self) -> str: ...

class Writable(Protocol):
    def write(self, data: str) -> None: ...
```

## Using Protocols
<!-- Lines 30-42 -->

```python
def process(source: Readable) -> str:
    return source.read().upper()

# Any class with read() method works
class MyFile:
    def read(self) -> str:
        return "data"

process(MyFile())  # OK - structural match
```

## Protocol with Properties
<!-- Lines 45-54 -->

```python
class Sized(Protocol):
    @property
    def size(self) -> int: ...

class Named(Protocol):
    name: str  # Required attribute
```

## Combining Protocols
<!-- Lines 57-62 -->

```python
class ReadWrite(Readable, Writable, Protocol):
    pass
```
