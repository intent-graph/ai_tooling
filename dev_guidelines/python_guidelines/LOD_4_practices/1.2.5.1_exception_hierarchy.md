## Structure
<!-- Lines 17-26 -->

```
Exception (built-in)
└── AppError (your base)
    ├── NotFoundError
    ├── ValidationError
    ├── PermissionError
    └── StateError
```

## Base Exception
<!-- Lines 29-37 -->

```python
class AppError(Exception):
    def __init__(self, message: str, details: dict | None = None):
        super().__init__(message)
        self.message = message
        self.details = details or {}
```

## Specific Exceptions
<!-- Lines 40-50 -->

```python
class TaskNotFoundError(AppError):
    def __init__(self, task_id: UUID):
        super().__init__(
            f"Task not found: {task_id}",
            {"task_id": str(task_id)}
        )
        self.task_id = task_id
```

## When to Create New Exception
<!-- Lines 53-62 -->

✅ Create when:
- Different handling required
- Different info needed
- Callers need to catch specifically

❌ Don't create when:
- Only message differs
- Built-in works (ValueError, TypeError)
