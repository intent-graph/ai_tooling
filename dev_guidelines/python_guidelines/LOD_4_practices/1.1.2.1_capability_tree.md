## Example: Task Manager
<!-- Lines 29-43 -->

```
0: Users manage personal tasks
├── 1.1: Create and edit tasks
│   ├── 1.1.1: create_task(title, description)
│   ├── 1.1.2: update_task(id, changes)
│   └── 1.1.3: delete_task(id)
├── 1.2: Organize into projects
│   ├── 1.2.1: create_project(name)
│   └── 1.2.2: assign_task(task_id, project_id)
└── 1.3: Track completion
    ├── 1.3.1: mark_complete(task_id)
    └── 1.3.2: view_progress()
```

## Guidelines
<!-- Lines 46-50 -->

- **Level 0:** One sentence mission
- **Level 1:** 3-7 capabilities (features)
- **Level 2:** Atomic operations (testable)

## Validation
<!-- Lines 53-58 -->

Each leaf operation should:
- Have clear inputs/outputs
- Be independently testable
- Map to a function or API endpoint
