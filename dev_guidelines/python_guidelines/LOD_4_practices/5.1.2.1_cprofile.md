## Command Line
<!-- Lines 18-24 -->

```bash
python -m cProfile script.py
python -m cProfile -s cumulative script.py
python -m cProfile -o output.prof script.py
```

## Programmatic
<!-- Lines 27-43 -->

```python
import cProfile
import pstats

profiler = cProfile.Profile()
profiler.enable()

# Code to profile
main()

profiler.disable()
stats = pstats.Stats(profiler)
stats.sort_stats('cumulative')
stats.print_stats(20)
```

## Context Manager
<!-- Lines 46-65 -->

```python
from contextlib import contextmanager
import cProfile
import pstats

@contextmanager
def profile():
    pr = cProfile.Profile()
    pr.enable()
    yield
    pr.disable()
    stats = pstats.Stats(pr)
    stats.sort_stats('cumulative')
    stats.print_stats(10)

with profile():
    slow_function()
```
