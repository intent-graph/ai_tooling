## Define Protocol
<!-- Lines 19-28 -->

```python
from typing import Protocol

class Repository(Protocol):
    def get(self, id: int) -> Entity | None: ...
    def save(self, entity: Entity) -> None: ...
    def delete(self, id: int) -> None: ...
```

## Implement Protocol
<!-- Lines 31-49 -->

```python
# No inheritance needed!
class PostgresUserRepository:
    def __init__(self, session: Session):
        self.session = session

    def get(self, id: int) -> User | None:
        return self.session.get(User, id)

    def save(self, user: User) -> None:
        self.session.add(user)

    def delete(self, id: int) -> None:
        user = self.get(id)
        if user:
            self.session.delete(user)
```

## Use in Type Hints
<!-- Lines 52-64 -->

```python
def process_users(repo: Repository) -> None:
    user = repo.get(1)
    if user:
        user.process()
        repo.save(user)

# Works with any matching implementation
process_users(PostgresUserRepository(session))
process_users(InMemoryRepository())
```

## Protocol with runtime_checkable
<!-- Lines 67-79 -->

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Closeable(Protocol):
    def close(self) -> None: ...

# Now isinstance works
if isinstance(obj, Closeable):
    obj.close()
```
