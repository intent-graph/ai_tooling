## Basic Flowchart
<!-- Lines 18-27 -->

```mermaid
flowchart LR
    A[Start] --> B{Decision?}
    B -->|Yes| C[Action]
    B -->|No| D[Skip]
    C --> E[End]
    D --> E
```

## Node Shapes
<!-- Lines 30-37 -->

| Shape | Syntax | Use |
|-------|--------|-----|
| Rectangle | `[Text]` | Process |
| Diamond | `{Text}` | Decision |
| Rounded | `(Text)` | Start/End |
| Database | `[(Text)]` | Storage |

## Direction Options
<!-- Lines 40-45 -->

- `LR` = Left to Right
- `TD` = Top Down
- `RL` = Right to Left
- `BT` = Bottom to Top

## Sequence Diagram
<!-- Lines 48-56 -->

```mermaid
sequenceDiagram
    Client->>API: POST /tasks
    API->>DB: Insert
    DB-->>API: OK
    API-->>Client: 201 Created
```

## Tips
<!-- Lines 59-63 -->

- Keep diagrams focused (one flow per diagram)
- Use subgraphs for complex systems
- Link to diagram in documentation
