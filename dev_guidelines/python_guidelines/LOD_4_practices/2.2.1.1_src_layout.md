> Recommended layout for distributable Python packages.

## Structure
<!-- Lines 18-32 -->

```
project_name/
├── src/
│   └── package_name/
│       ├── __init__.py
│       ├── core.py
│       └── utils.py
├── tests/
│   ├── conftest.py
│   └── test_core.py
├── pyproject.toml
└── README.md
```

## pyproject.toml
<!-- Lines 35-48 -->

```toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[tool.hatch.build.targets.wheel]
packages = ["src/package_name"]

# Or with setuptools
[tool.setuptools.packages.find]
where = ["src"]
```

## Benefits
<!-- Lines 51-56 -->

- Forces installed imports
- Catches import errors before distribution
- Clean separation of source and config
- Standard for PyPI packages

## Development Install
<!-- Lines 59-65 -->

```bash
pip install -e .
# Now imports work correctly
from package_name import core
```
