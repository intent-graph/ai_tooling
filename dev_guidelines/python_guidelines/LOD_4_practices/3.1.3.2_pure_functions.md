> Functions with no side effects.

## Pure vs Impure
<!-- Lines 16-33 -->

```python
# Pure: Same input → same output, no side effects
def calculate_tax(amount: Decimal, rate: float) -> Decimal:
    return amount * Decimal(str(rate))

# Impure: Uses external state
TAX_RATE = 0.08  # Global state

def calculate_tax(amount: Decimal) -> Decimal:
    return amount * Decimal(str(TAX_RATE))

# Impure: Side effects
def process(data: list[int]) -> int:
    data.sort()  # Mutates input
    return sum(data)
```

## Making Functions Pure
<!-- Lines 36-48 -->

```python
# Before: Impure
config = load_config()

def process(data):
    return transform(data, config.setting)

# After: Pure
def process(data, setting):
    return transform(data, setting)
```

## Benefits of Purity
<!-- Lines 51-65 -->

```python
# Easy to test
def test_calculate_tax():
    result = calculate_tax(Decimal("100"), 0.08)
    assert result == Decimal("8.00")

# Easy to cache
from functools import cache

@cache
def expensive_pure_calculation(n: int) -> int:
    return sum(range(n))
```
