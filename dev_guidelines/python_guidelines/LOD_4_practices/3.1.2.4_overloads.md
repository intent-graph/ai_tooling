## Basic Overload
<!-- Lines 16-29 -->

```python
from typing import overload, Literal

@overload
def get(key: str, default: None = None) -> str | None: ...
@overload
def get(key: str, default: str) -> str: ...

def get(key: str, default: str | None = None) -> str | None:
    value = data.get(key)
    return value if value is not None else default
```

## Literal Types
<!-- Lines 32-45 -->

```python
@overload
def fetch(id: int, as_dict: Literal[True]) -> dict: ...
@overload
def fetch(id: int, as_dict: Literal[False]) -> User: ...
@overload
def fetch(id: int) -> User: ...

def fetch(id: int, as_dict: bool = False) -> dict | User:
    user = get_user(id)
    return user.__dict__ if as_dict else user
```

## When to Use
<!-- Lines 48-60 -->

```python
# Good use: Different return types
@overload
def process(data: str) -> str: ...
@overload
def process(data: bytes) -> bytes: ...

# Avoid: Same return type (just use Union)
# No need for @overload here
def process(data: str | int) -> str: ...
```
