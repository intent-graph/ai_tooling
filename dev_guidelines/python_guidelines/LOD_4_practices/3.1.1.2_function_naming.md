## Verb Patterns
<!-- Lines 15-38 -->

```python
# get_ - Retrieve existing
def get_user(user_id: int) -> User: ...

# create_ - Make new
def create_user(data: UserCreate) -> User: ...

# update_ - Modify existing
def update_user(user_id: int, data: UserUpdate) -> User: ...

# delete_ - Remove
def delete_user(user_id: int) -> None: ...

# calculate_ - Compute value
def calculate_total(items: list[Item]) -> Decimal: ...

# validate_ - Check validity
def validate_email(email: str) -> bool: ...

# parse_ - Convert format
def parse_date(date_str: str) -> date: ...
```

## Boolean Functions
<!-- Lines 41-52 -->

```python
# is_ - State check
def is_valid(token: str) -> bool: ...

# has_ - Possession check
def has_permission(user: User, perm: str) -> bool: ...

# can_ - Capability check
def can_edit(user: User, resource: Resource) -> bool: ...
```
