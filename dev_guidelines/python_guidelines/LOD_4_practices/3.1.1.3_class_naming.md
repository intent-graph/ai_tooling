> Name classes with nouns describing what they are.

## Class Naming Patterns
<!-- Lines 15-35 -->

```python
# Entity classes
class User: ...
class Order: ...
class Product: ...

# Service classes (suffix with role)
class UserService: ...
class PaymentProcessor: ...
class EmailSender: ...

# Repository classes
class UserRepository: ...
class OrderRepository: ...

# Exception classes (suffix with Error)
class ValidationError(Exception): ...
class NotFoundError(Exception): ...
```

## Avoid Generic Names
<!-- Lines 38-52 -->

```python
# BAD: Too generic
class Manager: ...
class Handler: ...
class Processor: ...
class Helper: ...

# GOOD: Specific purpose
class OrderManager: ...
class RequestHandler: ...
class PaymentProcessor: ...
class DateFormatter: ...
```
