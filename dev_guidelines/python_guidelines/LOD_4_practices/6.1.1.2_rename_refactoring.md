## When to Rename
<!-- Lines 20-25 -->

- Name doesn't reflect purpose
- Abbreviations cause confusion
- Domain terminology changed
- Name conflicts with new understanding

## IDE Rename (Safest)
<!-- Lines 28-35 -->

```
VS Code:  F2 on symbol
PyCharm:  Shift+F6 on symbol
```

IDEs update all references automatically.

## Variable Renaming
<!-- Lines 38-52 -->

```python
# Before: Cryptic abbreviations
def calc(d, r, t):
    return d * (1 + r) ** t

# After: Clear names
def calculate_compound_interest(
    principal: float,
    rate: float,
    periods: int
) -> float:
    return principal * (1 + rate) ** periods
```

## Function Renaming
<!-- Lines 55-73 -->

```python
# Before: Vague verb
def do_stuff(user):
    ...

# After: Specific action
def send_welcome_email(user):
    ...

# Before: Misleading name
def get_user(user_id):  # Actually creates if missing
    ...

# After: Accurate name
def get_or_create_user(user_id):
    ...
```

## Class Renaming
<!-- Lines 76-86 -->

```python
# Before: Generic
class Manager:
    def process(self, data): ...

# After: Specific
class OrderProcessor:
    def process_order(self, order): ...
```

## Safe Rename Process
<!-- Lines 89-102 -->

```bash
# 1. Use IDE refactoring (updates all references)
# 2. Run tests
pytest tests/

# 3. Search for string references IDE might miss
rg "old_name" --type py

# 4. Check dynamic references
rg "getattr.*old_name"
rg "\"old_name\""
```

## Gradual Rename (Public API)
<!-- Lines 105-122 -->

```python
# When renaming public API, keep old name temporarily
def new_name(x):
    """Process x."""
    return _implementation(x)

def old_name(x):
    """Deprecated: Use new_name instead."""
    import warnings
    warnings.warn(
        "old_name is deprecated, use new_name",
        DeprecationWarning,
        stacklevel=2
    )
    return new_name(x)
```
