## Configuration
<!-- Lines 17-35 -->

```toml
[project.optional-dependencies]
dev = [
    "pytest>=7.0",
    "ruff>=0.1",
    "mypy>=1.0",
]
postgres = [
    "psycopg[binary]>=3.0",
]
redis = [
    "redis>=4.0",
]
all = [
    "mypackage[postgres,redis]",
]
```

## Installation
<!-- Lines 38-52 -->

```bash
# Single extra
pip install mypackage[postgres]

# Multiple extras
pip install mypackage[postgres,redis]

# All optional
pip install mypackage[all]

# For development
pip install -e ".[dev]"
```

## Feature Detection
<!-- Lines 55-69 -->

```python
# Check if optional dependency available
try:
    import psycopg
    HAS_POSTGRES = True
except ImportError:
    HAS_POSTGRES = False

def get_database():
    if not HAS_POSTGRES:
        raise ImportError("Install with: pip install mypackage[postgres]")
    return psycopg.connect(...)
```
