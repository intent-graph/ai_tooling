> Closures capture variables by reference.

## The Problem
<!-- Lines 18-26 -->

```python
funcs = []
for i in range(3):
    funcs.append(lambda: i)

[f() for f in funcs]  # [2, 2, 2] - Not [0, 1, 2]!
```

## The Fix (Default Argument)
<!-- Lines 29-37 -->

```python
funcs = []
for i in range(3):
    funcs.append(lambda i=i: i)  # Capture value

[f() for f in funcs]  # [0, 1, 2]
```

## Alternative: functools.partial
<!-- Lines 40-50 -->

```python
from functools import partial

funcs = []
for i in range(3):
    funcs.append(partial(lambda x: x, i))

[f() for f in funcs]  # [0, 1, 2]
```

## In Comprehensions
<!-- Lines 53-61 -->

```python
# BAD
callbacks = [lambda: x for x in range(3)]

# GOOD
callbacks = [lambda x=x: x for x in range(3)]
```
