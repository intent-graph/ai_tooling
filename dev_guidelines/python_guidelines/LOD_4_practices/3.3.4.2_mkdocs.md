## mkdocs.yml
<!-- Lines 26-44 -->

```yaml
site_name: My Project
theme:
  name: material

plugins:
  - search
  - mkdocstrings:
      handlers:
        python:
          options:
            show_source: true

nav:
  - Home: index.md
  - API: api.md
```
