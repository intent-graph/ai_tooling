## Basic Pattern
<!-- Lines 17-27 -->

```python
# src/mypackage/__main__.py
"""Enable: python -m mypackage"""

from mypackage.cli import main

if __name__ == "__main__":
    main()
```

## With Exit Code
<!-- Lines 30-39 -->

```python
# src/mypackage/__main__.py
import sys
from mypackage.cli import main

if __name__ == "__main__":
    sys.exit(main())
```

## Usage
<!-- Lines 42-50 -->

```bash
# Run without installation
python -m mypackage input.txt

# Equivalent to console script
myapp input.txt
```

## Why Both?
<!-- Lines 53-57 -->

- `__main__.py`: Works without install
- Console scripts: Cleaner commands
- Provide both for flexibility
