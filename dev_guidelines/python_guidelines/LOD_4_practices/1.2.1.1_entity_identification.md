## Entity vs Attribute
<!-- Lines 34-48 -->

**Entity:** Has identity, lifecycle, relationships
```python
class User:  # Entity
    id: UUID
    email: str  # Attribute
```

**Value Object:** No identity, defined by values
```python
class Money:  # Value Object
    amount: Decimal
    currency: str
```
