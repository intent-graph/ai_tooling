## VSCode Setup
<!-- Lines 21-37 -->

```json
// .vscode/launch.json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "python",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal"
        }
    ]
}
```

## Setting Breakpoints
<!-- Lines 40-44 -->

- Click left of line number
- Red dot appears
- Code stops at that line

## Conditional Breakpoints
<!-- Lines 47-51 -->

1. Right-click breakpoint
2. "Edit Breakpoint"
3. Add condition: `x > 100`

## Logpoints
<!-- Lines 54-61 -->

```
Right-click → Add Logpoint
Message: "Value is {variable}"
```

Logs without stopping execution.

## Debug Console
<!-- Lines 64-69 -->

When paused:
- Inspect variables
- Evaluate expressions
- Modify state

## Watch Expressions
<!-- Lines 72-77 -->

Add expressions to watch panel:
- `len(items)`
- `user.is_active`
- Custom expressions
