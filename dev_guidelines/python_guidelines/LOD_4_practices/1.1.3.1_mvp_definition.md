## MVP Criteria
<!-- Lines 17-23 -->

An MVP must answer "yes" to all:
1. Does it solve the core problem?
2. Can users accomplish their main goal?
3. Is it usable (not just functional)?
4. Can we learn from user behavior?

## Scoping Process
<!-- Lines 26-37 -->

```
All Features → Essential → Viable Product
     │              │            │
   100%           20%         MVP
```

**Step 1:** List all desired features
**Step 2:** Mark each: Essential / Important / Nice-to-have
**Step 3:** MVP = Essential only
**Step 4:** Validate viability

## Anti-Patterns
<!-- Lines 52-56 -->

- **MLP (Minimum Lovable Product):** Nice, but not MVP
- **Prototype:** Not usable by real users
- **Feature creep:** "Just one more thing"
