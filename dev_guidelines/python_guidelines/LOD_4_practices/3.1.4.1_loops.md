> Effective iteration with for loops.

## Basic Patterns
<!-- Lines 16-30 -->

```python
# Direct iteration
for item in items:
    process(item)

# With index
for i, item in enumerate(items):
    print(f"{i}: {item}")

# Multiple iterables
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

## Loop Control
<!-- Lines 33-45 -->

```python
for item in items:
    if should_skip(item):
        continue
    if should_stop(item):
        break
    process(item)
else:
    # Runs if no break
    print("Completed all items")
```

## Avoid Anti-Patterns
<!-- Lines 48-66 -->

```python
# BAD: Manual indexing
for i in range(len(items)):
    process(items[i])

# GOOD: Direct iteration
for item in items:
    process(item)

# BAD: Modifying while iterating
for item in items:
    if bad(item):
        items.remove(item)  # Dangerous!

# GOOD: Filter instead
items = [item for item in items if not bad(item)]
```
