> Pulling code into named, reusable functions.

## When to Extract
<!-- Lines 18-23 -->

- Code block has a single purpose
- Code is duplicated
- Code needs a comment to explain
- Function is too long (>20 lines)

## Basic Pattern
<!-- Lines 26-53 -->

```python
# Before: Inline calculation
def process_order(order):
    # Calculate total with discount
    subtotal = sum(item.price * item.qty for item in order.items)
    if order.discount_code:
        discount = get_discount(order.discount_code)
        subtotal *= (1 - discount)
    tax = subtotal * 0.08
    total = subtotal + tax
    # ... rest of processing

# After: Extracted function
def calculate_order_total(order) -> float:
    """Calculate total including discounts and tax."""
    subtotal = sum(item.price * item.qty for item in order.items)
    if order.discount_code:
        discount = get_discount(order.discount_code)
        subtotal *= (1 - discount)
    tax = subtotal * 0.08
    return subtotal + tax

def process_order(order):
    total = calculate_order_total(order)
    # ... rest of processing
```

## Extract for Naming
<!-- Lines 56-72 -->

```python
# Before: Comment explains condition
def is_eligible(user):
    # Check if user can vote
    if user.age >= 18 and user.citizen and not user.felon:
        return True

# After: Name explains condition
def can_vote(user) -> bool:
    return user.age >= 18 and user.citizen and not user.felon

def is_eligible(user):
    if can_vote(user):
        return True
```

## Extract for Testing
<!-- Lines 75-96 -->

```python
# Before: Hard to test validation separately
def create_user(data):
    if not data.get("email"):
        raise ValueError("Email required")
    if "@" not in data["email"]:
        raise ValueError("Invalid email")
    # ... create user

# After: Validation testable independently
def validate_email(email: str) -> None:
    if not email:
        raise ValueError("Email required")
    if "@" not in email:
        raise ValueError("Invalid email")

def create_user(data):
    validate_email(data.get("email", ""))
    # ... create user
```

## When NOT to Extract
<!-- Lines 99-114 -->

```python
# Don't extract trivial one-liners
def get_name(user):
    return user.name  # Just use user.name directly

# Don't extract if it obscures flow
def step1(): ...
def step2(): ...
def step3(): ...
def process():
    step1()  # Reader must jump around
    step2()
    step3()
```
