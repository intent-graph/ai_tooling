## SQL Injection
<!-- Lines 18-29 -->

```python
# VULNERABLE
query = f"SELECT * FROM users WHERE id = {user_id}"

# SAFE: Parameterized query
cursor.execute("SELECT * FROM users WHERE id = %s", (user_id,))

# SAFE: ORM
User.query.filter_by(id=user_id).first()
```

## Command Injection
<!-- Lines 32-46 -->

```python
import subprocess

# VULNERABLE
subprocess.run(f"echo {user_input}", shell=True)

# SAFE: List arguments
subprocess.run(["echo", user_input])

# SAFE: shlex.quote if shell required
import shlex
subprocess.run(f"echo {shlex.quote(user_input)}", shell=True)
```

## Template Injection
<!-- Lines 49-58 -->

```python
# VULNERABLE: User controls template
template = jinja2.Template(user_input)

# SAFE: User controls data, not template
template = jinja2.Template("Hello {{ name }}")
result = template.render(name=user_input)
```

## Path Traversal
<!-- Lines 61-72 -->

```python
from pathlib import Path

def safe_join(base: str, user_path: str) -> Path:
    base = Path(base).resolve()
    target = (base / user_path).resolve()
    if not target.is_relative_to(base):
        raise ValueError("Path traversal")
    return target
```

## LDAP Injection
<!-- Lines 75-86 -->

```python
import ldap

# VULNERABLE
query = f"(uid={username})"

query = f"(uid={escape_filter_chars(username)})"
```
