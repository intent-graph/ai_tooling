> Organize code into horizontal layers with strict dependency direction.

## Structure
<!-- Lines 17-24 -->

```
Presentation  →  Application  →  Domain  →  Infrastructure
     │               │             │              │
  Routes          Services      Entities      Database
  CLI             Use Cases     Logic         APIs
```

## Rules
<!-- Lines 27-31 -->

1. Each layer depends only on layers below
2. Never skip layers
3. Domain layer has no external dependencies

## Python Directory Structure
<!-- Lines 34-47 -->

```
myproject/
├── presentation/     # HTTP, CLI
│   └── api/
├── application/      # Use cases
│   └── services.py
├── domain/           # Business logic
│   ├── entities.py
│   └── services.py
└── infrastructure/   # External systems
    └── repositories.py
```

## Example Import Pattern
<!-- Lines 50-61 -->

```python
# presentation/api/routes.py
from myproject.application.services import TaskService

# application/services.py
from myproject.domain.entities import Task

# domain/entities.py
# No imports from other layers!
```
