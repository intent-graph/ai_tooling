## Signature Anatomy
<!-- Lines 17-28 -->

```python
def create_task(
    title: str,                      # Required positional
    creator_id: UUID,                # Required positional
    *,                               # Keyword-only after this
    project_id: UUID | None = None,  # Optional keyword
    due_date: date | None = None,    # Optional keyword
) -> Task:                           # Return type
    ...
```

## Parameter Guidelines
<!-- Lines 31-37 -->

| Parameter Type | When to Use |
|----------------|-------------|
| Positional | Always required, commonly used |
| Keyword-only | Optional, rare, configurable |
| Defaults | Sensible for common case |

## Stability Tips
<!-- Lines 40-48 -->

```python
# Fragile: Adding params breaks callers
def create(title, desc, due): ...

# Stable: Keyword-only params are additive
def create(title: str, *, desc: str = "", due: date | None = None): ...
```

## Return Value Patterns
<!-- Lines 51-55 -->

- Single value: `def get(id) -> User | None`
- Multiple values: Return dataclass, not tuple
- Side effects: Return `None` or status
