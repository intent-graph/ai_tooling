## Generators vs Lists
<!-- Lines 20-28 -->

```python
# Eager: All in memory
data = [transform(x) for x in huge_list]  # Memory spike

# Lazy: One at a time
data = (transform(x) for x in huge_list)  # Constant memory
```

## Generator Functions
<!-- Lines 31-42 -->

```python
def read_large_file(path):
    with open(path) as f:
        for line in f:
            yield process(line)

# Memory-efficient iteration
for item in read_large_file('huge.txt'):
    handle(item)
```

class DataLoader:
    def __init__(self, path):
        self.path = path
        self._data = None

## cached_property (3.8+)
<!-- Lines 61-74 -->

```python
from functools import cached_property

class Report:
    @cached_property
    def summary(self):
        return expensive_computation()

# Computed once, cached
report.summary
report.summary  # Returns cached
```
