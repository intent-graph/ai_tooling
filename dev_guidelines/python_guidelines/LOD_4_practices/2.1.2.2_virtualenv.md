> Third-party virtual environment tool with more features than venv.

## Installation
<!-- Lines 18-24 -->

```bash
pip install virtualenv
# Or
pipx install virtualenv
```

## Create Environment
<!-- Lines 27-38 -->

```bash
# Basic
virtualenv .venv

# Specific Python version
virtualenv -p python3.11 .venv

# With explicit Python path
virtualenv -p /usr/local/bin/python3.12 .venv
```

## Advantages Over venv
<!-- Lines 41-48 -->

| Feature | venv | virtualenv |
|---------|------|------------|
| Speed | Slower | Faster (caches) |
| Python 2 | No | Yes |
| Discovery | None | Finds interpreters |
| Relocatable | No | Possible |

## When to Use
<!-- Lines 51-55 -->

- Need faster environment creation
- Legacy Python 2 support
- Advanced features required

## Modern Alternative
<!-- Lines 58-65 -->

For most projects, prefer `venv` or `uv venv`:

```bash
# uv is much faster
uv venv .venv
```
