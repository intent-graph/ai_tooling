> Avoid shared mutable defaults.

## The Problem
<!-- Lines 17-26 -->

```python
def append_to(item, items=[]):
    items.append(item)
    return items

append_to(1)  # [1]
append_to(2)  # [1, 2] - Unexpected!
```

## The Fix
<!-- Lines 29-40 -->

```python
def append_to(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

append_to(1)  # [1]
append_to(2)  # [2] - Correct
```

## Same Issue with Dicts
<!-- Lines 43-57 -->

```python
# BAD
def add_key(key, data={}):
    data[key] = True
    return data

# GOOD
def add_key(key, data=None):
    if data is None:
        data = {}
    data[key] = True
    return data
```

## Why It Happens
<!-- Lines 60-62 -->

Default arguments are evaluated once at function definition, not at each call.
