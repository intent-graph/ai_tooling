## Branch Naming
<!-- Lines 21-33 -->

```bash
# Pattern: type/short-description
feature/user-auth
feature/add-search
bugfix/login-timeout
bugfix/null-pointer-dashboard
hotfix/security-patch
release/v2.1.0
docs/api-reference
refactor/extract-validation
```

## Trunk-Based (Recommended for Small Teams)
<!-- Lines 36-55 -->

```bash
# Main branch is always deployable
# Feature branches are short-lived (1-2 days)

git checkout main
git pull
git checkout -b feature/add-search

# Work, commit frequently
git commit -m "feat: add search input"
git commit -m "feat: add search results display"

# Push and create PR
git push -u origin feature/add-search

# After merge, delete branch
git branch -d feature/add-search
```

## GitHub Flow
<!-- Lines 58-76 -->

```bash
# 1. Branch from main
git checkout main && git pull
git checkout -b feature/new-feature

# 2. Commit changes
git add . && git commit -m "feat: implement feature"

# 3. Open PR
git push -u origin feature/new-feature
gh pr create --title "Add new feature" --body "..."

# 4. Review and merge via GitHub
# 5. Delete branch
git checkout main && git pull
git branch -d feature/new-feature
```

## Keeping Branches Current
<!-- Lines 79-88 -->

```bash
# Rebase onto latest main (preferred)
git fetch origin
git rebase origin/main

# Or merge (creates merge commit)
git merge origin/main
```

## Handling Conflicts
<!-- Lines 91-106 -->

```bash
# During rebase
git rebase origin/main
# CONFLICT in file.py

# 1. Edit file.py, resolve conflicts
# 2. Stage resolved files
git add file.py
# 3. Continue rebase
git rebase --continue

# If stuck, abort and try again
git rebase --abort
```

## Protected Branches
<!-- Lines 109-118 -->

```yaml
# GitHub branch protection
- Require PR reviews (1+)
- Require status checks to pass
- Require up-to-date branches
- No force pushes
- No deletions
```

## Feature Flags (Alternative to Long Branches)
<!-- Lines 121-131 -->

```python
# Instead of feature branches, use flags
from myapp.features import is_enabled

def get_search_results(query):
    if is_enabled("new_search_algorithm"):
        return new_search(query)
    return old_search(query)
```

## Common Commands
<!-- Lines 134-151 -->

```bash
# List branches
git branch -a

# Delete local branch
git branch -d feature/done

# Delete remote branch
git push origin --delete feature/done

# Rename branch
git branch -m old-name new-name

# See branch graph
git log --oneline --graph --all
```
