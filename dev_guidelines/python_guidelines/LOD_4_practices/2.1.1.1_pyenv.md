## Installation
<!-- Lines 17-25 -->

```bash
# macOS
brew install pyenv

# Linux
curl https://pyenv.run | bash
```

## Shell Setup
<!-- Lines 28-35 -->

```bash
# ~/.zshrc or ~/.bashrc
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"
```

## Common Commands
<!-- Lines 38-55 -->

```bash
# List available versions
pyenv install --list | grep "^  3\."

# Install version
pyenv install 3.12.3

# Set global default
pyenv global 3.12.3

# Set per-project version
pyenv local 3.12.3  # Creates .python-version

# Check current version
pyenv version
```

## Project Workflow
<!-- Lines 58-65 -->

```bash
cd my_project
pyenv local 3.12.3
python -m venv .venv
source .venv/bin/activate
```
