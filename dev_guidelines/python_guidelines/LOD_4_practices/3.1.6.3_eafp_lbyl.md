> Python's approach to error handling.

## EAFP (Pythonic)
<!-- Lines 17-28 -->

```python
# Easier to Ask Forgiveness than Permission
try:
    value = dictionary["key"]
except KeyError:
    value = default

# Better: Use built-in
value = dictionary.get("key", default)
```

## LBYL (Less Pythonic)
<!-- Lines 31-39 -->

```python
# Look Before You Leap
if "key" in dictionary:
    value = dictionary["key"]
else:
    value = default
```

## When EAFP is Better
<!-- Lines 42-56 -->

```python
# EAFP: Handles race conditions
try:
    with open(path) as f:
        return f.read()
except FileNotFoundError:
    return None

# LBYL: Race condition possible
if os.path.exists(path):  # File might be deleted here
    with open(path) as f:
        return f.read()
```

## When LBYL is Better
<!-- Lines 59-71 -->

```python
# LBYL: When check is cheap, exception is expensive
if user_id > 0:  # Cheap check
    user = expensive_db_lookup(user_id)

# Avoid: Don't use exception for flow control
try:
    user = expensive_db_lookup(user_id)
except InvalidIdError:
    ...
```
