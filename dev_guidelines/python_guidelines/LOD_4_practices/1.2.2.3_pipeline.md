> Process data through a sequence of independent stages.

## Structure
<!-- Lines 17-26 -->

```
Input → Stage 1 → Stage 2 → Stage 3 → Output
```

Each stage:
- Receives input from previous
- Transforms data
- Passes output to next

## Python Implementation
<!-- Lines 29-47 -->

```python
def pipeline(*stages):
    def run(data):
        for stage in stages:
            data = stage(data)
        return data
    return run

# Define stages
def validate(data): ...
def transform(data): ...
def enrich(data): ...

# Compose
process = pipeline(validate, transform, enrich)
result = process(input_data)
```
