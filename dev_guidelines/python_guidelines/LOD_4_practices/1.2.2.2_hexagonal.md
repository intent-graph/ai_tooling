## Structure
<!-- Lines 17-33 -->

```
         [Driving Adapters]
              HTTP, CLI
                  │
              ┌───▼───┐
              │ Ports │  ← Interfaces
              │ ┌───┐ │
              │ │Core│ │  ← Domain + Application
              │ └───┘ │
              │ Ports │
              └───┬───┘
                  │
         [Driven Adapters]
          Database, APIs
```

## Python Example
<!-- Lines 45-62 -->

```python
# Port (interface)
class TaskRepository(Protocol):
    def save(self, task: Task) -> None: ...
    def get(self, id: UUID) -> Task | None: ...

# Core (uses port)
class TaskService:
    def __init__(self, repo: TaskRepository):
        self.repo = repo

# Adapter (implements port)
class PostgresTaskRepository:
    def save(self, task: Task) -> None: ...
    def get(self, id: UUID) -> Task | None: ...
```
