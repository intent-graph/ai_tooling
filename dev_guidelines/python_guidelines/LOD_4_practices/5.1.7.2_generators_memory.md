## List vs Generator
<!-- Lines 18-31 -->

```python
# Bad: Loads all into memory
def get_lines_list(path):
    with open(path) as f:
        return f.readlines()  # Entire file in memory

# Good: Yields one at a time
def get_lines_gen(path):
    with open(path) as f:
        for line in f:
            yield line
```

## Processing Pipelines
<!-- Lines 34-55 -->

```python
def read_data(path):
    with open(path) as f:
        for line in f:
            yield line.strip()

def parse(lines):
    for line in lines:
        yield json.loads(line)

def filter_valid(records):
    for record in records:
        if record.get('valid'):
            yield record

# Memory-efficient pipeline
pipeline = filter_valid(parse(read_data('huge.jsonl')))
for record in pipeline:
    process(record)
```

## Chunked Processing
<!-- Lines 58-74 -->

```python
def chunked(iterable, size):
    chunk = []
    for item in iterable:
        chunk.append(item)
        if len(chunk) >= size:
            yield chunk
            chunk = []
    if chunk:
        yield chunk

# Process in batches
for batch in chunked(huge_iterator, 1000):
    db.insert_many(batch)
```

## Generator Expressions
<!-- Lines 77-88 -->

```python
# List comprehension: All in memory
squares = [x**2 for x in range(10_000_000)]

# Generator expression: Lazy
squares = (x**2 for x in range(10_000_000))

# Sum without materializing
total = sum(x**2 for x in range(10_000_000))
```
