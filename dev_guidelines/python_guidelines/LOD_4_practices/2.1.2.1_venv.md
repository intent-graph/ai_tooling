## Create Environment
<!-- Lines 18-26 -->

```bash
# Standard location
python -m venv .venv

# Custom name
python -m venv my_env
```

## Activate
<!-- Lines 29-40 -->

```bash
# Unix/macOS
source .venv/bin/activate

# Windows cmd
.venv\Scripts\activate.bat

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

## Verify Activation
<!-- Lines 43-49 -->

```bash

```

## Deactivate
<!-- Lines 52-56 -->

```bash

```

## Common Options
<!-- Lines 59-70 -->

```bash
# Include system packages
python -m venv --system-site-packages .venv

# Upgrade pip on creation
python -m venv --upgrade-deps .venv

# Without pip (minimal)
python -m venv --without-pip .venv
```
