## Format
<!-- Lines 16-40 -->

```python
def calculate_distance(point_a: tuple, point_b: tuple) -> float:
    """
    Calculate Euclidean distance between two points.

    Parameters
    ----------
    point_a : tuple
        First point as (x, y) coordinates.
    point_b : tuple
        Second point as (x, y) coordinates.

    Returns
    -------
    float
        The Euclidean distance.

    Raises
    ------
    ValueError
        If points have different dimensions.
    """
```
