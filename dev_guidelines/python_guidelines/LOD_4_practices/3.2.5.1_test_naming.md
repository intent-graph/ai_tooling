> Descriptive test names.

## Function Naming
<!-- Lines 17-30 -->

```python
# Pattern: test_<unit>_<scenario>_<expected>
def test_user_with_invalid_email_raises_error():
    ...

def test_calculate_total_with_discount_returns_reduced_price():
    ...

# Simpler when obvious
def test_user_creation():
    ...
```

## Class-Based
<!-- Lines 33-46 -->

```python
class TestUser:
    def test_creation(self):
        ...

    def test_full_name(self):
        ...

class TestUserRepository:
    def test_save(self):
        ...
```

## Avoid Vague Names
<!-- Lines 49-61 -->

```python
# BAD
def test_user():
def test_it_works():
def test_1():

# GOOD
def test_user_email_is_lowercased():
def test_expired_token_rejected():
def test_empty_cart_returns_zero_total():
```

## File Naming
<!-- Lines 64-71 -->

```python
# test_<module>.py
test_models.py
test_services.py
test_authentication.py
```
