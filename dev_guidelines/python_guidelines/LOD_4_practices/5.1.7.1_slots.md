## Basic Usage
<!-- Lines 19-30 -->

```python
class Point:
    __slots__ = ('x', 'y')

    def __init__(self, x, y):
        self.x = x
        self.y = y

# ~75% less memory than regular class
```

## Memory Comparison
<!-- Lines 33-54 -->

```python
import sys

class Regular:
    def __init__(self, x, y):
        self.x = x
        self.y = y

class Slotted:
    __slots__ = ('x', 'y')
    def __init__(self, x, y):
        self.x = x
        self.y = y

regular = Regular(1, 2)
slotted = Slotted(1, 2)

# Regular: ~300 bytes (has __dict__)
# Slotted: ~70 bytes (no __dict__)
```

## With Dataclasses
<!-- Lines 57-66 -->

```python
from dataclasses import dataclass

@dataclass(slots=True)
class Point:
    x: float
    y: float
```

## Limitations
<!-- Lines 69-78 -->

```python
class Slotted:
    __slots__ = ('x', 'y')

obj = Slotted()
obj.x = 1  # OK
obj.z = 3  # AttributeError: 'Slotted' object has no attribute 'z'
```

## Inheritance
<!-- Lines 81-91 -->

```python
class Base:
    __slots__ = ('x',)

class Derived(Base):
    __slots__ = ('y',)  # Only add new attributes

# Derived has both x and y
```

## When to Use
<!-- Lines 94-98 -->

- Many instances (100,000+)
- Fixed set of attributes
- Memory-constrained environments
