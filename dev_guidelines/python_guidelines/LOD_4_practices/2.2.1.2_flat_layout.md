## Structure
<!-- Lines 18-30 -->

```
project_name/
├── package_name/
│   ├── __init__.py
│   ├── core.py
│   └── utils.py
├── tests/
│   └── test_core.py
├── pyproject.toml
└── README.md
```

## pyproject.toml
<!-- Lines 33-39 -->

```toml
[tool.setuptools.packages.find]
where = ["."]
exclude = ["tests*"]
```

## When to Use
<!-- Lines 42-47 -->

- Internal applications
- Simple scripts
- Rapid prototyping
- Won't be distributed to PyPI

## Tradeoffs
<!-- Lines 50-56 -->

| Aspect | Flat | src-layout |
|--------|------|------------|
| Simplicity | Better | More setup |
| Import safety | Risk | Protected |
| Distribution | Works | Recommended |
