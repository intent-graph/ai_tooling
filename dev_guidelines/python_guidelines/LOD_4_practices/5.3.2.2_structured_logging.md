## structlog
<!-- Lines 18-38 -->

```bash
pip install structlog
```

```python
import structlog

structlog.configure(
    processors=[
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.add_log_level,
        structlog.processors.JSONRenderer()
    ]
)

logger = structlog.get_logger()

logger.info("order_created", order_id=123, amount=99.99)
```

## Context Binding
<!-- Lines 54-62 -->

```python
# Bind context for all subsequent logs
logger = logger.bind(request_id="abc123", user_id=42)

logger.info("started")  # Includes request_id, user_id
logger.info("completed")  # Same context
```

## python-json-logger
<!-- Lines 65-78 -->

```python
from pythonjsonlogger import jsonlogger
import logging

handler = logging.StreamHandler()
handler.setFormatter(jsonlogger.JsonFormatter())

logger = logging.getLogger()
logger.addHandler(handler)

logger.info("event", extra={"user_id": 123})
```
