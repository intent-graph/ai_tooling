## Basic Dataclass
<!-- Lines 18-28 -->

```python
from dataclasses import dataclass

@dataclass
class User:
    id: int
    name: str
    email: str
```

## With Defaults
<!-- Lines 31-40 -->

```python
@dataclass
class User:
    id: int
    name: str
    email: str = ""
    active: bool = True
```

## Frozen (Immutable)
<!-- Lines 43-53 -->

```python
@dataclass(frozen=True)
class Point:
    x: float
    y: float

p = Point(1.0, 2.0)
p.x = 3.0  # Error: frozen
```

## Field Options
<!-- Lines 56-66 -->

```python
from dataclasses import dataclass, field

@dataclass
class Order:
    items: list[str] = field(default_factory=list)
    metadata: dict = field(default_factory=dict)
    _internal: str = field(repr=False, compare=False)
```

## Post-Init Validation
<!-- Lines 69-80 -->

```python
@dataclass
class User:
    name: str
    email: str

    def __post_init__(self):
        if "@" not in self.email:
            raise ValueError("Invalid email")
```
