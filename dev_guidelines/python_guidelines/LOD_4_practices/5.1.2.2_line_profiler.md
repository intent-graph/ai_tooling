## Usage
<!-- Lines 25-38 -->

```python
# Add @profile decorator (provided by kernprof)
@profile
def slow_function():
    data = load_data()      # Which line is slow?
    result = process(data)
    return save(result)
```

```bash
kernprof -l -v script.py
```

## Programmatic Usage
<!-- Lines 52-69 -->

```python
from line_profiler import LineProfiler

def target_function():
    # Function to profile
    pass

lp = LineProfiler()
lp.add_function(target_function)
lp.enable_by_count()

target_function()

lp.disable_by_count()
lp.print_stats()
```
