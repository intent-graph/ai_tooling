> Configure pytest-cov for coverage.

## pyproject.toml
<!-- Lines 18-35 -->

```toml
[tool.coverage.run]
source = ["src"]
branch = true
omit = ["*/tests/*", "*/__main__.py"]

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "if TYPE_CHECKING:",
    "raise NotImplementedError",
    "@abstractmethod",
]
show_missing = true
fail_under = 80
```

## Running Coverage
<!-- Lines 38-48 -->

```bash
# With pytest
pytest --cov=src --cov-report=html

# With coverage directly
coverage run -m pytest
coverage report
coverage html
```

## CI Configuration
<!-- Lines 51-59 -->

```yaml
- name: Run tests
  run: pytest --cov=src --cov-report=xml

- name: Upload coverage
  uses: codecov/codecov-action@v3
```
