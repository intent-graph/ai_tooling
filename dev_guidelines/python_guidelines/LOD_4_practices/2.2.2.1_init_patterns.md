## Minimal (Recommended)
<!-- Lines 17-24 -->

```python
# package/__init__.py
"""Package description."""

__version__ = "0.1.0"
```

## Explicit Exports
<!-- Lines 27-37 -->

```python
# package/__init__.py
"""Package with explicit public API."""

from package.core import process, transform
from package.models import Config

__all__ = ["process", "transform", "Config"]
```

## Lazy Loading
<!-- Lines 40-51 -->

```python
# package/__init__.py
"""Lazy-loaded for faster imports."""

def __getattr__(name: str):
    if name == "heavy":
        from package import heavy
        return heavy
    raise AttributeError(f"module {__name__!r} has no attribute {name!r}")
```

## Anti-Patterns
<!-- Lines 54-62 -->

```python
# BAD: Star imports
from package.core import *

# BAD: Heavy work at import time
DATA = load_large_file()
```
