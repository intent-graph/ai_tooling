## Function Scope (Default)
<!-- Lines 18-26 -->

```python
@pytest.fixture  # scope="function" is default
def fresh_data():
    return {"count": 0}

# New dict for each test
```

## Module Scope
<!-- Lines 29-37 -->

```python
@pytest.fixture(scope="module")
def expensive_resource():
    resource = create_expensive_resource()
    yield resource
    resource.cleanup()
```

## Session Scope
<!-- Lines 40-49 -->

```python
@pytest.fixture(scope="session")
def database():
    engine = create_engine(TEST_DB_URL)
    Base.metadata.create_all(engine)
    yield engine
    Base.metadata.drop_all(engine)
```

## Scope Hierarchy
<!-- Lines 52-59 -->

```
session  (once per test run)
    └── module (once per test file)
        └── class (once per test class)
            └── function (each test)
```

## Scope Constraint
<!-- Lines 62-69 -->

```python
# ERROR: Higher scope cannot use lower scope
@pytest.fixture(scope="session")
def session_fixture(function_fixture):  # Not allowed!
    ...
```
