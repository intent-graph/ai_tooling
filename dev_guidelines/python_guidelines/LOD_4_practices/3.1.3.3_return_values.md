## Optional Return
<!-- Lines 25-31 -->

```python
def find_user(id: int) -> User | None:
    """Return User if found, None otherwise."""
    return users.get(id)
```

## Multiple Values
<!-- Lines 34-50 -->

```python
from typing import NamedTuple

class ParseResult(NamedTuple):
    value: int
    remainder: str

def parse_int(text: str) -> ParseResult:
    ...
    return ParseResult(value=42, remainder="abc")

# Usage
result = parse_int("42abc")
print(result.value)  # 42
```

## Exception vs Return
<!-- Lines 53-66 -->

```python
# Expected absence: Return None
def find_user(id: int) -> User | None:
    return users.get(id)

# Unexpected failure: Raise exception
def get_user(id: int) -> User:
    user = users.get(id)
    if not user:
        raise UserNotFoundError(id)
    return user
```
