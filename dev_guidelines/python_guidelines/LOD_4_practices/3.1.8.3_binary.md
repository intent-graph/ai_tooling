## Pickle (Python Only)
<!-- Lines 17-31 -->

```python
import pickle

# Serialize
with open("data.pkl", "wb") as f:
    pickle.dump(obj, f)

# Deserialize
with open("data.pkl", "rb") as f:
    obj = pickle.load(f)

# WARNING: Never unpickle untrusted data!
```

## When to Use Pickle
<!-- Lines 34-38 -->

- Python-to-Python only
- Trusted data sources
- Caching computed results

## MessagePack
<!-- Lines 41-51 -->

```python
import msgpack

# Serialize
packed = msgpack.packb(data)

# Deserialize
data = msgpack.unpackb(packed)
```

## Protocol Buffers
<!-- Lines 54-70 -->

```protobuf
// user.proto
message User {
  string name = 1;
  int32 age = 2;
}
```

```python
from user_pb2 import User

user = User(name="Alice", age=30)
binary = user.SerializeToString()
user = User.FromString(binary)
```
