## Naming Guidelines
<!-- Lines 16-28 -->

```python
# Descriptive names
user_count = len(users)        # Not: n, cnt, uc
total_price = sum(prices)      # Not: tp, sum1
is_active = user.status == "active"  # Boolean prefix

# Scope-appropriate length
for i in range(10):            # Short loop var OK
for user in users:             # Readable iteration
validated_user_input = validate(raw_input)  # Module scope
```

## Good vs Bad
<!-- Lines 31-43 -->

```python
# BAD: Meaningless
d = {}
l = []
x = get_data()

# GOOD: Descriptive
user_cache = {}
pending_tasks = []
customer_data = get_data()
```

## Boolean Variables
<!-- Lines 46-54 -->

```python
# Use is_, has_, can_, should_
is_valid = validate(input)
has_permission = user.role == "admin"
can_edit = is_owner and not is_locked
should_retry = attempt < max_retries
```
