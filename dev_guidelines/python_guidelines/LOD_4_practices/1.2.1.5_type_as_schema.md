> Use types to make invalid states unrepresentable.

## Principle
<!-- Lines 17-19 -->

Types should encode valid states such that invalid data cannot exist.

## Example: Order Status
<!-- Lines 22-50 -->

```python
# Weak: inconsistent states possible
@dataclass
class Order:
    status: str  # "pending", "shipped", "delivered"
    shipped_at: datetime | None
    delivered_at: datetime | None
    # Bug: delivered_at set when status="pending"

# Strong: types enforce consistency
@dataclass
class PendingOrder:
    items: list[Item]

@dataclass
class ShippedOrder:
    items: list[Item]
    shipped_at: datetime

@dataclass
class DeliveredOrder:
    items: list[Item]
    shipped_at: datetime
    delivered_at: datetime

Order = PendingOrder | ShippedOrder | DeliveredOrder
```
