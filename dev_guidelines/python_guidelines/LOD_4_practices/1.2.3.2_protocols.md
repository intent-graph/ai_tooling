## Basic Protocol
<!-- Lines 16-35 -->

```python
from typing import Protocol

class Repository(Protocol):
    def save(self, entity: Entity) -> None: ...
    def get(self, id: UUID) -> Entity | None: ...
```

Any class with matching methods satisfies the protocol:

```python
class InMemoryRepo:
    def save(self, entity: Entity) -> None: ...
    def get(self, id: UUID) -> Entity | None: ...

def use_repo(repo: Repository) -> None:  # Accepts InMemoryRepo
    repo.save(entity)
```

## Protocol vs ABC
<!-- Lines 38-44 -->

| Aspect | Protocol | ABC |
|--------|----------|-----|
| Inheritance | Not required | Required |
| Default impl | No | Yes |
| Duck typing | ✅ | ❌ |

## When to Use
<!-- Lines 47-62 -->

- Multiple unrelated implementations
- Testing with mocks
- Decoupling modules

```python
# Testing
class MockRepo:
    def save(self, entity): self.saved = entity
    def get(self, id): return self.data.get(id)

def test_service():
    repo = MockRepo()  # Satisfies Repository protocol
    service = Service(repo)
```
