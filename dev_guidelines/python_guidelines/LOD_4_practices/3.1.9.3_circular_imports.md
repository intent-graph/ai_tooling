## The Problem
<!-- Lines 19-35 -->

```python
# models.py
from services import UserService  # Imports services

class User:
    def get_service(self) -> UserService:
        return UserService(self)

# services.py
from models import User  # Circular!

class UserService:
    def __init__(self, user: User):
        self.user = user
```

## Solution: TYPE_CHECKING
<!-- Lines 38-51 -->

```python
# services.py
from __future__ import annotations
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from models import User

class UserService:
    def __init__(self, user: "User"):
        self.user = user
```

## Solution: Import in Function
<!-- Lines 54-62 -->

```python
# services.py
class UserService:
    def get_user(self) -> "User":
        from models import User
        return User()
```

## Solution: Restructure
<!-- Lines 65-79 -->

```python
# types.py - Shared types
@dataclass
class UserData:
    id: int
    name: str

# models.py
from types import UserData

# services.py
from types import UserData
```
