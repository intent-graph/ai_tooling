## Essential Commands
<!-- Lines 30-38 -->

| Command | Action |
|---------|--------|
| `n` | Next line (step over) |
| `s` | Step into function |
| `c` | Continue to next breakpoint |
| `r` | Return from function |
| `q` | Quit debugger |

## Inspection
<!-- Lines 41-51 -->

| Command | Action |
|---------|--------|
| `p expr` | Print expression |
| `pp expr` | Pretty print |
| `l` | List source code |
| `ll` | Long list (whole function) |
| `w` | Show call stack |
| `u` | Up one stack frame |
| `d` | Down one stack frame |

## Breakpoints
<!-- Lines 54-65 -->

```python
# Conditional
if some_condition:
    breakpoint()

# In pdb
(Pdb) b module.py:42  # Set breakpoint
(Pdb) b function_name  # Break on function
(Pdb) cl 1            # Clear breakpoint 1
```
