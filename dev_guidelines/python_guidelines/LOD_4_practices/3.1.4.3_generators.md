## Generator Expression
<!-- Lines 17-25 -->

```python
# Lazy evaluation
squares = (x ** 2 for x in range(1_000_000))

# Memory efficient
total = sum(x ** 2 for x in range(1_000_000))
```

## Generator Function
<!-- Lines 28-39 -->

```python
def read_lines(path: str) -> Iterator[str]:
    with open(path) as f:
        for line in f:
            yield line.strip()

# Process without loading all into memory
for line in read_lines("large_file.txt"):
    process(line)
```

## yield from
<!-- Lines 42-50 -->

```python
def flatten(nested: list[list[T]]) -> Iterator[T]:
    for inner in nested:
        yield from inner

list(flatten([[1, 2], [3, 4]]))  # [1, 2, 3, 4]
```

## Generator Gotcha
<!-- Lines 53-63 -->

```python
# Generators exhaust after one iteration
gen = (x for x in range(3))
list(gen)  # [0, 1, 2]
list(gen)  # [] - exhausted!

# Convert to list if multiple iterations needed
items = list(x for x in range(3))
```
