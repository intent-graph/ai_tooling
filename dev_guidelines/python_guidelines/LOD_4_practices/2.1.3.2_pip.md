## Installation Commands
<!-- Lines 17-37 -->

```bash
# Install package
pip install httpx

# Specific version
pip install httpx==0.24.1

# Version range
pip install "httpx>=0.24,<0.26"

# From requirements
pip install -r requirements.txt

# Editable install
pip install -e .

# With optional deps
pip install -e ".[dev]"
```

## Useful Options
<!-- Lines 40-54 -->

```bash
# Upgrade package
pip install --upgrade httpx

# No cache (clean install)
pip install --no-cache-dir httpx

# Target directory
pip install --target ./lib httpx

# Dry run
pip install --dry-run httpx
```

## Package Info
<!-- Lines 57-71 -->

```bash
# Show package details
pip show httpx

# List installed
pip list

# List outdated
pip list --outdated

# Freeze current state
pip freeze > requirements.txt
```

## Constraints File
<!-- Lines 74-83 -->

```bash
# constraints.txt
numpy==1.26.4
pandas==2.2.0

# Install with constraints
pip install -c constraints.txt mypackage
```
