## Import Order (PEP 8)
<!-- Lines 17-32 -->

```python
# 1. Standard library
import os
import sys
from pathlib import Path

# 2. Third-party
import httpx
from pydantic import BaseModel

# 3. Local
from mypackage.core import process
from mypackage.models import Config
```

## Absolute vs Relative
<!-- Lines 35-44 -->

```python
# Absolute (recommended)
from mypackage.utils import helper

# Relative (within package)
from .utils import helper
from ..models import Config
```

## Import Styles
<!-- Lines 47-59 -->

```python
# Direct (preferred)
from mypackage.models import User, Config

# Module (many items)
from mypackage import models
user = models.User()

# Aliased
import numpy as np
```
