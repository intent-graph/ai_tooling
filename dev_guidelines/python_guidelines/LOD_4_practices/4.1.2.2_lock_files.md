> Pinning exact dependency versions for reproducibility.

## uv (Recommended)
<!-- Lines 17-39 -->

```bash
# Generate lock file
uv lock

# Install from lock
uv sync

# Fail if lock is outdated
uv sync --frozen
```

```toml
# uv.lock (partial)
[[package]]
name = "httpx"
version = "0.24.1"
dependencies = [
    { name = "certifi" },
    { name = "httpcore" },
]
```

## pip-tools
<!-- Lines 42-53 -->

```bash
# Generate requirements.lock
pip-compile pyproject.toml -o requirements.lock

# Include dev dependencies
pip-compile pyproject.toml --extra dev -o requirements-dev.lock

# Install
pip-sync requirements.lock
```

## Poetry
<!-- Lines 56-61 -->

```bash
poetry lock
poetry install --no-root
```

## When to Update
<!-- Lines 64-72 -->

```bash
# Update single package
uv lock --upgrade-package httpx

# Update all
uv lock --upgrade
```
