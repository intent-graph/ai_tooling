## List Comprehension
<!-- Lines 17-28 -->

```python
# Transform
squares = [x ** 2 for x in numbers]

# Filter
evens = [x for x in numbers if x % 2 == 0]

# Transform + Filter
even_squares = [x ** 2 for x in numbers if x % 2 == 0]
```

## Dict Comprehension
<!-- Lines 31-42 -->

```python
# From pairs
scores = {name: score for name, score in pairs}

# Transform
upper_dict = {k.upper(): v for k, v in data.items()}

inverted = {v: k for k, v in original.items()}
```

## When to Use Loops Instead
<!-- Lines 52-69 -->

```python
# TOO COMPLEX: Use a loop
result = [
    transform(x, y)
    for x in items if condition(x)
    for y in nested(x) if other(y)
]

# BETTER: Explicit loop
result = []
for x in items:
    if condition(x):
        for y in nested(x):
            if other(y):
                result.append(transform(x, y))
```
