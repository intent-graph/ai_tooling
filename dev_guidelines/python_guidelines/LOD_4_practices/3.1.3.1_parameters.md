## Parameter Order
<!-- Lines 18-29 -->

```python
def fetch_users(
    organization_id: int,         # Required
    limit: int = 100,             # Optional
    *,                            # Keyword-only after
    include_inactive: bool = False,
    sort_by: str = "created_at",
) -> list[User]:
    ...
```

## Positional-Only (`/`)
<!-- Lines 32-40 -->

```python
def pow(x, y, /):  # Must be positional
    return x ** y

pow(2, 3)      # OK
pow(x=2, y=3)  # Error
```

## Keyword-Only (`*`)
<!-- Lines 43-51 -->

```python
def connect(host: str, *, port: int = 5432):
    ...

connect("localhost", port=3306)  # OK
connect("localhost", 3306)       # Error
```

## Avoid Too Many Parameters
<!-- Lines 54-69 -->

```python
# BAD: Too many parameters
def create_user(name, email, age, city, country, phone, ...): ...

# GOOD: Use a data class
@dataclass
class UserCreate:
    name: str
    email: str
    age: int
    address: Address

def create_user(data: UserCreate) -> User: ...
```
