## Installation
<!-- Lines 18-26 -->

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# With pip (slower to install)
pip install uv
```

## Basic Commands
<!-- Lines 29-43 -->

```bash
# Create venv
uv venv

# Install package
uv pip install httpx

# Install from pyproject.toml
uv pip install -e ".[dev]"

# Install from requirements
uv pip install -r requirements.txt
```

## Lock Files
<!-- Lines 46-54 -->

```bash
# Generate lock file
uv pip compile pyproject.toml -o requirements.lock

# Install from lock file (reproducible)
uv pip sync requirements.lock
```

## Speed Comparison
<!-- Lines 57-65 -->

```bash
# pip: ~30 seconds
pip install numpy pandas scipy

# uv: ~3 seconds
uv pip install numpy pandas scipy
```

## Full Workflow
<!-- Lines 68-81 -->

```bash
# Setup
uv venv
source .venv/bin/activate
uv pip install -e ".[dev]"

# Lock dependencies
uv pip compile pyproject.toml -o requirements.lock

# CI install (fast, reproducible)
uv pip sync requirements.lock
```
