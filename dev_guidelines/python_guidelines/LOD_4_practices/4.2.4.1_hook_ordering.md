## Recommended Order
<!-- Lines 16-56 -->

```yaml
repos:
  # 1. Formatters (fastest, may fix linter issues)
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.1.6
    hooks:
      - id: ruff-format

  # 2. Linters with auto-fix
      - id: ruff
        args: [--fix, --exit-non-zero-on-fix]

  # 3. General file checks
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files
      - id: check-merge-conflict

  # 4. Type checking (slow)
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.7.0
    hooks:
      - id: mypy
        additional_dependencies:
          - types-requests
          - pydantic

  # 5. Security scanning (slowest)
  - repo: https://github.com/PyCQA/bandit
    rev: 1.7.5
    hooks:
      - id: bandit
        args: ["-c", "pyproject.toml"]
        stages: [push]  # Only on push
```

## Ordering Principles
<!-- Lines 59-64 -->

1. **Fast before slow** - Fail early
2. **Formatters before linters** - Formatting may fix issues
3. **Auto-fix before check-only** - Apply fixes first
4. **Cheap before expensive** - Save compute time

## Stage-based Hooks
<!-- Lines 67-81 -->

```yaml
# Quick checks on commit
- id: ruff
  stages: [commit]

# Slow checks on push only
- id: mypy
  stages: [push]

# Manual only
- id: bandit
  stages: [manual]
```
