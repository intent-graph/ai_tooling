## Normal Forms (Simplified)
<!-- Lines 17-23 -->

| Form | Rule | Violation Example |
|------|------|-------------------|
| 1NF | No repeating groups | `tags="a,b,c"` |
| 2NF | No partial dependencies | `Task(id, project_id, project_name)` |
| 3NF | No transitive dependencies | `Project(id, owner_id, owner_email)` |

## Quick Test
<!-- Lines 26-30 -->

**1NF:** Are all columns atomic (single values)?
**2NF:** Does every non-key column depend on the whole key?
**3NF:** Do non-key columns depend only on the key?

## When to Denormalize
<!-- Lines 33-41 -->

| Reason | Example |
|--------|---------|
| Read performance | Precomputed counts |
| Reporting | Materialized aggregates |
| Caching | Snapshot data |

**Always document** denormalization decisions.

## Python Example
<!-- Lines 44-55 -->

```python
# Normalized: tags in separate table
class Task:
    id: UUID
    title: str

class TaskTag:
    task_id: UUID
    tag_id: UUID
```
