## Quick Review Checklist
<!-- Lines 22-48 -->

```markdown
## Correctness
<!-- Lines 29-32 -->
- [ ] Does it do what the PR description says?
- [ ] Are edge cases handled?
- [ ] Are errors handled appropriately?

## Security
<!-- Lines 35-38 -->
- [ ] No SQL/command injection?
- [ ] No hardcoded secrets?
- [ ] Input validated?

## Quality
<!-- Lines 41-44 -->
- [ ] Tests included for changes?
- [ ] Code is readable?
- [ ] No obvious performance issues?

## Consistency
<!-- Lines 47-51 -->
- [ ] Follows project conventions?
- [ ] Naming is clear?
- [ ] No unnecessary changes?
```

## Detailed Checklist by Category
<!-- Lines 51-51 -->

### Functionality
<!-- Lines 54-70 -->

```python
# Check: Null/empty handling
def get_first(items):
    return items[0]  # ❌ Fails on empty list

def get_first(items):
    return items[0] if items else None  # ✅

# Check: Boundary conditions
def is_adult(age):
    return age > 18  # ❌ 18-year-olds excluded

def is_adult(age):
    return age >= 18  # ✅
```

### Error Handling
<!-- Lines 73-87 -->

```python
# Check: Specific exceptions
try:
    do_something()
except Exception:  # ❌ Too broad
    pass

try:
    do_something()
except ValueError as e:  # ✅ Specific
    logger.error(f"Invalid value: {e}")
    raise
```

### Testing
<!-- Lines 90-98 -->

```markdown
- [ ] Tests cover the happy path
- [ ] Tests cover error cases
- [ ] Tests cover edge cases (empty, null, max values)
- [ ] Test names describe the scenario
- [ ] No flaky tests (timing, ordering)
```

### Performance
<!-- Lines 101-116 -->

```python
# Check: N+1 queries
for user in users:
    orders = Order.query.filter_by(user_id=user.id).all()  # ❌

users_with_orders = User.query.options(
    joinedload(User.orders)
).all()  # ✅

# Check: Unnecessary work in loops
for item in items:
    config = load_config()  # ❌ Load once
    process(item, config)
```

### Security Quick Scan
<!-- Lines 119-133 -->

```python
# SQL injection
f"SELECT * FROM users WHERE id = {user_id}"  # ❌
cursor.execute("SELECT * FROM users WHERE id = %s", (user_id,))  # ✅

# Command injection
os.system(f"convert {filename}")  # ❌
subprocess.run(["convert", filename])  # ✅

# Secrets
API_KEY = "sk_live_..."  # ❌
API_KEY = os.environ["API_KEY"]  # ✅
```

## Review Comments Format
<!-- Lines 136-153 -->

```markdown
**Blocking (must fix)**
🔴 Security: This SQL is vulnerable to injection.

**Suggestion (should fix)**
🟡 Consider using a list comprehension here for clarity.

**Nitpick (optional)**
🔵 nit: Extra blank line can be removed.

**Question (clarification)**
❓ Why did we choose this approach over X?

**Praise (positive feedback)**
✨ Nice use of the factory pattern here!
```
