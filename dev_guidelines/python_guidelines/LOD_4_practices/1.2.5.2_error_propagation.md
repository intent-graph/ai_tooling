## Layer Strategies
<!-- Lines 16-23 -->

| Layer | Strategy |
|-------|----------|
| Domain | Raise domain exceptions |
| Application | Log, transform, or re-raise |
| Presentation | Catch all, convert to response |
| Infrastructure | Wrap external errors |

## Patterns
<!-- Lines 26-53 -->

**Bubble up:**
```python
def get_task(self, id: UUID) -> Task:
    task = self.repo.get(id)
    if not task:
        raise TaskNotFoundError(id)  # Let caller handle
    return task
```

**Transform:**
```python
try:
    task = Task.from_dict(data)
except KeyError as e:
    raise ValidationError(str(e)) from e  # Wrap
```

**Log and continue:**
```python
for item in items:
    try:
        process(item)
    except ItemError as e:
        logger.warning("Failed", item=item, error=e)
        # Continue with others
```

## Exception Chaining
<!-- Lines 56-61 -->

Always use `from` to preserve cause:
```python
raise NewError("message") from original_error
```
