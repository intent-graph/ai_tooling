## Constant Patterns
<!-- Lines 16-32 -->

```python
# Configuration constants
MAX_RETRIES = 3
DEFAULT_TIMEOUT = 30  # seconds
API_VERSION = "v1"

# Magic numbers as constants
SECONDS_PER_MINUTE = 60
BYTES_PER_KB = 1024
HTTP_OK = 200

# Feature flags
ENABLE_CACHE = True
DEBUG_MODE = False
```

## Grouped Constants
<!-- Lines 35-52 -->

```python
# Related constants in a class
class HttpStatus:
    OK = 200
    CREATED = 201
    BAD_REQUEST = 400
    NOT_FOUND = 404

# Or use Enum
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    ACTIVE = "active"
    COMPLETED = "completed"
```

## Avoid Magic Numbers
<!-- Lines 55-66 -->

```python
# BAD: Magic number
if retry_count > 3:
    raise TooManyRetries()

# GOOD: Named constant
MAX_RETRIES = 3
if retry_count > MAX_RETRIES:
    raise TooManyRetries()
```
