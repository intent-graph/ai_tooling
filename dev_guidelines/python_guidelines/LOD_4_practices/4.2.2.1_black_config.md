## Full Config
<!-- Lines 27-43 -->

```toml
[tool.black]
line-length = 88
target-version = ["py310", "py311", "py312"]

include = '\.pyi?$'

extend-exclude = '''
/(
    migrations
  | generated
  | vendor
)/
'''
```

## Running
<!-- Lines 46-53 -->

```bash
black .              # Format all
black --check .      # Check only
black --diff .       # Show changes
black src/file.py    # Single file
```

## Ruff Format Alternative
<!-- Lines 56-67 -->

```toml
[tool.ruff.format]
quote-style = "double"
indent-style = "space"
line-ending = "auto"
```

```bash
ruff format .        # 100x faster
```
