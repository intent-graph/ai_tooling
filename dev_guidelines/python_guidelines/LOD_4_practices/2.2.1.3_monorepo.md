## Structure
<!-- Lines 17-35 -->

```
monorepo/
├── packages/
│   ├── core/
│   │   ├── src/core/
│   │   │   └── __init__.py
│   │   ├── tests/
│   │   └── pyproject.toml
│   ├── api/
│   │   ├── src/api/
│   │   └── pyproject.toml
│   └── cli/
│       ├── src/cli/
│       └── pyproject.toml
├── pyproject.toml
└── README.md
```

## Workspace Configuration (uv)
<!-- Lines 38-47 -->

```toml
# Root pyproject.toml
[tool.uv.workspace]
members = ["packages/*"]

[tool.uv.sources]
core = { workspace = true }
```

## Cross-Package Dependencies
<!-- Lines 50-58 -->

```toml
# packages/api/pyproject.toml
[project]
dependencies = [
    "core",  # Workspace reference
]
```
