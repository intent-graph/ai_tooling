Certainty: grounded for the quote checks and for the node text (I fetched and read them), inferred for the max-rule judgments and severities.

Pinned:

- Decisions found to settle for the average: 2 (`ORIGIN.6.1` accepts `same-site` unconditionally where OWASP admits it only if sibling subdomains are trusted, grounded; `SECRETS.2.1` requires `exp` only "where tokens grant API access" where the OWASP REST sheet verifies `exp` by default, inferred).
- Quotes, for the 30 T1 and T2 sources behind the three composed rules and the two contested decisions: confirmed 27, not confirmed 2 (CSP3 section 6.4.2.2 "Relation to X-Frame-Options": page truncated in two fetches; Fetch Standard HTTP-redirect fetch limit of 20 and header removal: excerpt truncated, only the three redirect modes seen), contradicted 1 (OWASP CSRF sheet, SRC-394, as the source of "Fetch Metadata is defence in depth behind a token").
