# Research result: 09 RUNTIME (Node runtime behaviour and performance)

Audit group: E_quality_runtime. Extractor: sonnet. Fetch tool returned digests, not page text, for every HTML source; quotes are marked tool-extracted.

## L1 headline

Authoritative guidance for Node runtime behaviour is solid on operational facts (streams and backpressure, process lifecycle, HTTP shutdown, memory diagnosis, profiling tools), all grounded in Node.js docs, MDN and WHATWG at T1, and thin on engine-level performance and benchmarking, which rest on V8-team and academic T2 sources only and are recorded as single-source or inferred, never as measured consensus. Certainty: grounded for the facts, inferred where a rule is derived from a fact; every HTML page was read through a fetch digest, so wording is tool-extracted.

Pinned:
- Claims: 63 in total: 11 consensus, 0 majority, 0 contested, 52 single-source.
- Contested topics: none found among admitted sources.
- Register sources not read in full:
  - SRC-027 (ECMA-262 living draft): the fetch tool returned only the table of contents for the WeakRef and FinalizationRegistry processing model, so no spec wording is cited; WeakRef claims rest on SRC-203 and SRC-193.
  - SRC-305 (ASPLOS 2009 measurement bias): only the bibliographic page with its abstract was readable; full text not obtained, so claims are abstract-level.
  - SRC-079 (Node CLI): digest only, sections truncated (the --watch details, the unhandled-rejections history, default heap size text not on the pages read).
  - SRC-188 (fs), SRC-190 (http), SRC-196 (stream): digest only; some sections (fs threadpool, access caveat wording, stream default highWaterMark, which the digest stated inconsistently) were not read verbatim, and no claim states them.
  - Every other HTML register source in the working set was read through a digest, not as full page text.
  - SRC-307 was read in full (saved PDF, pdftotext).

## L2 claims

- Streams: respect backpressure (write() false then 'drain', push() false then stop), never treat highWaterMark as a memory bound, prefer pipeline to pipe, know that early exit from async iteration destroys or cancels the stream. Agreement: consensus for backpressure, highWaterMark and iteration; single-source T1 for the rest. Certainty: grounded. Claims: RUNTIME-C01 to C12.
- Buffers and fs: zero-filled alloc by default, allocUnsafeSlow for long-retained small chunks, no new Buffer(), close FileHandles in finally, callback fs only when maximal performance is required. Agreement: single-source T1. Certainty: grounded (C18 inferred). Claims: C13 to C18.
- Event loop and profiling tools: worker-pool mechanism, profile before optimizing, built-in --cpu-prof and --heap-prof, perf flame-graph flags, event-loop utilization and delay, observers cost overhead, diagnose by symptom. Agreement: single-source T1 (C21 consensus, inferred step). Certainty: grounded. Claims: C19 to C25.
- Memory model and leaks: reachability, circular references are not leaks, avoid WeakRef and FinalizationRegistry, weak collections for metadata, leak versus inefficiency, snapshot-diff, GC-trace and profiler methods, snapshot cost and exposure, heap limit, near-heap-limit snapshots, gc() is no remedy. Agreement: consensus for snapshot cost, heap limit and near-limit; single-source T1 otherwise. Certainty: grounded, C48 inferred. Claims: C26 to C29, C44 to C50, C53.
- EventEmitter: soft 10-listener leak warning, unhandled 'error' crashes, captureRejections, missed events with once, addAbortListener. Agreement: single-source T1. Certainty: grounded. Claims: C30 to C34.
- Process lifecycle: exitCode over exit(), synchronous 'exit' listeners, uncaughtException only for sync cleanup then exit, monitor event, signal listeners replace defaults, unhandled rejection throws by default. Agreement: consensus for unhandled rejection; single-source T1 otherwise. Certainty: grounded, C39 inferred. Claims: C35 to C40.
- HTTP server lifecycle: close then closeAllConnections, keep request timeouts on, clientError must close socket. Agreement: single-source T1. Certainty: grounded, C42 inferred. Claims: C41 to C43.
- Security-adjacent diagnostics: inspector never on a public address, diagnostic reports carry environment variables. Agreement: single-source T1 and consensus (C52, inferred rule). Claims: C51, C52.
- Engine-level facts (T2, V8 team): concurrent marking since Node 10, holey versus packed rarely matters, hidden classes, snapshot speed fixes, and a meta claim that these are dated single-body evidence. Agreement: single-source T2. Certainty: grounded for facts, inferred for the meta claim. Claims: C54 to C57, C63.
- Benchmarking method (T2): many runs plus a significance test, correct for multiple comparisons, isolated machine, separate start-up and steady-state, setup randomization. Agreement: consensus for the statistical-rigor claim (inferred transfer from Java and C to JavaScript), single-source T2 otherwise. Claims: C58 to C62.

Contested topics: none.

Folklore corrected by an admitted source: circular references leak in JavaScript (C27); unhandled rejections only warn (C40); holey arrays must be avoided for speed (C55).

Gaps:
- Memory leaks as an empirical question: no study found in the register (no source at any tier).
- Supervisor-side shutdown contract (SIGTERM grace, SIGKILL): origin is the supervisor's docs, not in the register; boundary with web_architecture_guidelines.
- Container memory limits and heap sizing: not on the Node CLI or memory pages read.
- Measured cost of AsyncLocalStorage, async_hooks and EventEmitter: no measured source.
- ECMA-262 WeakRef and FinalizationRegistry notes: body text unreadable through the tool.
- cluster, child_process lifecycle and process 'warning' handling: not in this slot's register rows.
