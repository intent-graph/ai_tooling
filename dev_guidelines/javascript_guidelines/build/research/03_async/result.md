- Handle every promise: return it from then, await it, or attach a catch; floating promises, missing returns, broken chains, dead promises and promise wrapping are the recurring bug classes. consensus, grounded. ASYNC-C01, C02, C03, C12, C13, C14, C15.
- Unhandled rejections are runtime errors: Node raises them as uncaught exceptions (default since Node 15), browsers fire a cancelable unhandledrejection event; uncaughtException is a last resort, not a way to resume. consensus, grounded. ASYNC-C04, C05, C06.
- async/await semantics and composition: async functions always return a promise, await pairs can leak rejections, Promise.all fails fast without cancelling the rest, independent work should run concurrently. consensus, grounded. ASYNC-C07, C08, C09, C10, C11.
- Typing and lint-checkable misuses: async functions as void callbacks, promises as conditions, async executors. consensus for the first, single-source for the others, grounded (restricted lint-rule sources, rule behaviour only). ASYNC-C11, C16, C17, C54.
- Error values and propagation: throw and reject Error objects, chain with the cause option, one failing site per cause, no silent empty catch (Google position), try/catch cannot see async callback errors, emitters need error listeners, use error.code. consensus for Error objects, cause and emitter errors; the rest single-source; grounded. ASYNC-C18 to C24.
- Cancellation and timeouts: promises are not cancellable; pass an AbortSignal, reject with its reason, check throwIfAborted, use AbortSignal.timeout and any, signals are one-shot, clean up listeners. consensus, grounded. ASYNC-C25 to C30.
- Timers and ordering: timer delays are lower bounds with different clamps per runtime, string handlers act like eval, microtasks run before the next task, prefer setImmediate to nextTick, setTimeout versus setImmediate order is undefined outside I/O. consensus for imprecision, clamps, microtasks and ordering; single-source for the rest; grounded. ASYNC-C31 to C37.
- Event-loop blocking: long callbacks are a throughput and DoS problem, ReDoS blocks a server (2018 figures), bound callback cost, partition CPU work; sync core APIs as blockers is inferred. consensus for the principle and ReDoS, grounded; C41 inferred. ASYNC-C38 to C42, C55.
- Workers: CPU-bound work only, heavy to start, structured-clone copy or transfer, handle error and exit events, cap resources. consensus for scope, data transfer and error handling, grounded. ASYNC-C43 to C47.
- Context and scheduling: AsyncLocalStorage with run(), AsyncContext only a stage 2 proposal, WICG scheduler is a draft, stage-4 feature years. single-source each, grounded. ASYNC-C48 to C51.
- History worth correcting: await cost folklore (V8, 2018) and redundant promise allocations (DrAsync). single-source, grounded. ASYNC-C52, C53.

Contested topics: none.
