# Audit result: group E_quality_runtime (slots 08 QUALITY, 09 RUNTIME)

## L1 headline

68 of 69 candidates survive, 36 of them only with a restriction. One is rejected: RUNTIME-K35, Twelve-Factor, for G3. Both areas keep T1 ground for their operational sub-topics: lint rules, CI gates, the Node test runner and assertions, streams, memory diagnosis, process lifecycle and profiling. Neither area has an admitted T1 for its normative or evidence-heavy sub-topics. In QUALITY those are formatting choice, testing strategy, property-based testing, coverage as a target, mutation testing and fuzzing. In RUNTIME they are engine-level performance claims, benchmarking method, memory-leak evidence, the supervisor shutdown contract and container heap sizing. Certainty: grounded for every verdict (each candidate re-fetched by me; HTML pages were read only through the fetch tool's model summary, PDFs in full text). Inferred for the tier calls noted in L3.

Pinned:
- Counts per slot: 08_quality: admitted 9, restricted 25, rejected 0 (34). 09_runtime: admitted 23, restricted 11, rejected 1 (35).
- Sub-topics left without an admitted T1 source, 08_quality: formatting (which formatter, and whether to use one; T1 covers only tool behaviour); testing strategy (test mix and pyramid, test size, behaviour over implementation, flakiness); property-based testing (as practice; T1 covers only fast-check's own behaviour); coverage as a quality target and numeric thresholds (none among the candidates; a T1 exists in OpenSSF Best Practices criteria levels 1 and 2, not listed by discovery); mutation testing (as practice); fuzzing for JavaScript; snapshot testing and mocking policy.
- Sub-topics left without an admitted T1 source, 09_runtime: engine-level performance claims (hidden classes, elements kinds, GC cost of allocation patterns; T2 only, V8 team); benchmarking methodology (T2 only); memory leaks as an empirical question (no source at any tier); supervisor-side shutdown contract (SIGTERM grace, SIGKILL; K35 rejected); container memory limits and heap sizing; measured cost of AsyncLocalStorage, async_hooks and EventEmitter.
