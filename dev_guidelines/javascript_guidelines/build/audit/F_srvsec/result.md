### Sub-topics left without an admitted T1 source, and what an extractor needs

Every candidate is admitted or restricted, so "without" means: no admitted T1 states the sub-topic.

- 13_srvsec G-H1 randomness and crypto:
  - Node CSPRNG function text (`randomBytes`, `randomInt`, `randomUUID`, `scrypt`): the Node crypto page is truncated in every fetch; read each section by anchor or from the project's documentation source on a tool that returns the full section.
  - `timingSafeEqual` details: confirm the version it was added (digests say 6.0.0 and 6.6.0) and the error class on unequal lengths (digest said `ERR_CRYPTO_TIMING_SAFE_EQUAL_LENGTH`, the discoverer wrote `TypeError`).
  - Password-hash parameters for Node: only OWASP's language-neutral numbers; a Node page that names `scrypt` cost parameters is needed.
  - Add ASVS 11.5.1 and 11.2.4 as positions, not mechanisms.
- 13_srvsec G-H2 query injection:
  - No T1 for raw-query behaviour of Sequelize, Knex or TypeORM.
  - No T1 on mysql2 `query()` client-side escaping versus `execute()`: the page does not say it.
  - NoSQL: K37 and K38 now ground operator injection and `$where`; the extractor reads K37 verbatim because its quotes came from a summary.
- 13_srvsec G-H3 SSRF and outbound requests:
  - A T1 statement of the pinned-connection recipe in Node: not found; the recipe stays inferred from K21, K22, K19.
  - Node `fetch` (undici) redirect semantics and whether `redirect: "manual"` returns an opaque response: SRC-066 `fetch()` section and the undici documentation must be read in full.
  - DNS rebinding for outbound requests: SRC-078's section covers only the debugging inspector; K25 covers browsers only.
- 13_srvsec G-H4 deserialization:
  - No T1 states a JavaScript safe-deserialization recipe; K27, K28, K30 give facts. A TYPES-slot source on parsing untrusted data (JSON plus schema) may supply it; check the already admitted TYPES sources before searching.
  - `v8.deserialize`: no warning on the page; do not extract a claim of safety or danger from SRC-202.
- 13_srvsec G-H5 path containment:
  - No T1 states the resolve, `realpath`, prefix-test recipe; K31 (Express `root`) and K23 give partial grounds, SRC-127 gives the `path.isAbsolute` warning.
  - `fs.realpath` and `fs.access` race caution in SRC-188: the page is truncated in every fetch; read those sections directly.
  - Symlink and permission-model facts: K34 and the already admitted SRC-130, SRC-128.
